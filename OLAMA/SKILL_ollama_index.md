## Ключевые факты, которые направление уже добыло

1. **Версия 0.34.1.** Эндпоинта `/api/tokenize` нет (404 на GET и POST) — единственный
   измеритель токенов `prompt_eval_count`, и он врёт на переполнении окна (4099 на любом
   входе длиннее ~21 тыс. символов).
2. **`think` — строка с уровнем:** `true/false/high/medium/low`. Дом долго умел только булев.
3. **`OLLAMA_LOAD_TIMEOUT` = 5m** — кандидат на причину молчаливых обрывов прогонов на
   моделях 10-15 ГБ. Разбор не проводился.
4. **`OLLAMA_MAX_LOADED_MODELS=1` в доме** — любая проверка вытесняет рабочую модель.
5. **Стенд ходит в HTTP-API напрямую**, а не через CLI. Справка CLI про API не пишет ничего —
   по API нужен `ollama.com/docs`.

## Грабли направления (кратко; полные — в телах скиллов)

- Мерить размышление вместо ответа (подмена полей) — метрологическая ошибка, стоившая
  gpt-oss трёх баллов и целой группы в отчёте.
- Поднимать `num_predict` всем: laguna-xs.2 при 2000 генерирует 2000 токенов мусора вместо
  60 — время прогона растёт, качество не меняется.
- Опрашивать длинный прогон каждые 25 с — петля (`crash_sleep-poll-loop-after-timeout`, повтор 2).
- Оценивать время прогона «на глаз» — факт двух моделей на том же лимите даёт точную оценку.
