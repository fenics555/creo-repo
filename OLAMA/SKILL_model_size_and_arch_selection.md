# ВЫБОР МОДЕЛИ ПОД КАРТУ: РАЗМЕР, АРХИТЕКТУРА, КВАНТ

> Цель: **не качать 20–80 ГБ наугад**. Сначала факты о модели, потом файл.

## §1. Три вопроса перед закачкой (порядок обязателен)

1. **Сколько параметров ВСЕГО и сколько АКТИВНЫХ?** — из vLLM-рецептов (`https://recipes.vllm.ai/<owner>`)
   или из карточки HF (поле `safetensors.parameters`). Пример: `GLM-4.7-Flash` = 31,2B, arch-тег `glm4_moe_lite`.
2. **Какой `arch` у GGUF и поддерживает ли его Ollama?** — `hf_info.py --repo …` печатает `arch=`.
   Известно-поддерживаемые: `qwen35moe`, `deepseek2`, `glm4_moe`, `llama`, `gemma3`…
   **Риск:** свежие арх. (`qwen4exp`, `glm5-next`, `inkling2_loop`) могут не грузиться (`ollama create`/run падает).
3. **Какой минимальный квант и влезает ли он?** — `hf_info.py` печатает таблицу квантов с суммой шинов
   и вердиктом `FITS / PART / HEAVY`. Правило дома (16 ГБ VRAM): брать **≤ ~22 ГБ** (`PART`, до ~30% в RAM).

## §2. Приёмы, без которых теряешь время

- **`Flash` в имени ≠ маленькая модель.** `GLM-5.3-Flash` = 321B/18B (мин. квант IQ1_S 76,8 ГБ),
  `Qwen3.8-Flash-Next` = мин. IQ1_S 66,4 ГБ. Сначала смотри параметры, потом радуйся имени.
- **`3.8`/`4.7` в имени репо ≠ новая архитектура.** Репозитории `Qwen3.8-35B-A3B-*` — дистилляты базы
  `Qwen/Qwen3.6-35B-A3B` (в тегах `qwen3.6`, `distillation`). Проверяй `base_model`/tags.
- **Шины (shards) складывать.** У больших моделей файл разбит (`-00001-of-00004`); поштучный размер врёт.
  `hf_info.py` суммирует по кванту и печатает точное имя первого шина для `hf_download.py --file`.
- **Имя файла не угадывать** — иначе `HTTPError 404`. Имя берётся из API-листинга.
- **`ollama pull hf.co/<repo>` не универсален** — на репо с кастомными именами (напр. `DavidAU`) падает
  `invalid model name`; тогда качаем GGUF (`hf_download.py`, Range-resume) + свой Modelfile.
- **Плотная ≠ быстрая.** Плотная 27B дала 12,9 t/s; MoE 35B-A3B (3B активных) — 81,4 t/s при том же классе
  качества. «TURBO» в имени плотной работает только при наличии **MTP-файла** (`…-MTP-*.gguf`).
