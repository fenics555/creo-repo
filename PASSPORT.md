# PASSPORT.md

## Описание
Паспорт дома — актуальное состояние модулей, инструментов и истории развития репозитория.
Служит «источником истины» по составу: что где лежит и зачем. Читается один раз при знакомстве.

| Закон | `MANIFEST.md` | универсальные правила для любого исполнителя |

## Данные и логи
- Данные: `data\` — база памяти, pid-файл, корни чтения, пользователи; секреты вне git.
- Логи: `D:\AI\log\<программа>\`; отчёты ног — `D:\AI\log\reports\`;
  временные файлы исполнителей — `D:\AI\log\urn\<исполнитель>\`.
- **Хранилище агента (аудит 03.10.2026).** Базы: `data\agent.sqlite` (217,9 МБ, память агента),
  `data\harvest.db` (63,6 МБ, инвентарь моделей — читают навигатор, чистильщик сирот, PDF-инструменты),
  `plm_reader\db\plm_reader.db` (реестр изделий, у своего инструмента). Все целы: `quick_check = ok`.
- **Настройки агента — один хозяин:** `data\config.json`. Остальные `*_settings.json` — по одному
  на программу, в том же месте. Расхождения, ждущие правки: `copy_port` мёртвый, `creoson_dir` с
  двумя разными дефолтами, плейсхолдеры `<WORK_ROOT>`/`<CREO_START>` в `kb_roots.txt` не разрешаются.
- **Бэкапы — две папки, две роли:** `data\backups\` (авто, каждые 6 ч, ротация по `retention`=7) и
  `data\backup\` (ручные копии «перед правкой», без ротации и вне git). Не смешивать. Уборка ручных —
  `backup.sweep_manual(days, do=False)`: сухой прогон по умолчанию, удаление только с `do=True`.
- **Индекс `chunks` пересобирается начисто:** `python index_repo.py` очищает таблицу
  (`--keep` — дописать). До 03.10.2026 индексатор писал без очистки и раздувал базу в 35 раз —
  именно из-за этого бэкап разросся до 6,38 ГБ (1 330 971 чанк при 37 372 файлах).
- **Правило редактирования конфигов:** агент читает `config.json` как `utf-8` и при ошибке молча
  возвращает `{}`. Поэтому файлы настроек править только через `settings.set_val` или python-json,
  **никогда** через PowerShell (`ConvertTo-Json` ставит BOM и обнуляет настройки).
- **Автопоиск Creo — `agent\creo_path.py`:** бат запуска → реестр PTC → диск `D:\PTC\CREO*` →
  настройки. Проверка `python agent\creo_path.py -v`. Один поиск на дом (потребители: `config_audit`,
  `creo_comb`, `creo_pdf`), при переезде или обновлении Creo дом подхватывает версию сам.
