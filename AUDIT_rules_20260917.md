## P1. КРИТИЧНО: конституция crash и skills_check расходятся в правиле имени экземпляра
Цитаты: конституция «БЛОК ИМЁН»: «name: внутри совпадает с именем файла без SKILL_» + «подпись из ключевых слов ошибки латиницей через дефис»; факты: файлы в двух стилях (SKILL_crash-editor-mismatch.md дефис / SKILL_crash_agent_corruption.md подчёркивание), check ожидает name = имя файла без SKILL_ (crash_agent_corruption), конституция — подпись через дефис (agent-corruption). Окно: каждый новый скилл гарантированно шумит; сигнал нарушений тонет (см. P3).
Варианты:
 A1 (скрипт-нормализация): единый стиль файлов SKILL_crash_<подпись-подчёркивания>.md, name: = crash_<подпись>; один ASCII-скрипт с проверкой якоря, приёмка skills_check до/после. Риск: массовое переименование = правка вне tmp → нужно прямое слово (М5); устаревшие ссылки в передачах/индексах.

 A3 (правка конституции): зафиксировать «name = имя файла без SKILL_ и .md» — сам по себе не лечит существующие файлы, комбинируется с A1.
