ОШИБКА (дословно, для grep):
Command failed: Command timed out after 30000ms
СИМПТОМ: команда с Start-Sleep 160 убита на 30-й секунде; состояние ЧАСТИЧНОЕ — шаги до
сна выполнены (задача зарегистрирована), шаги после сна не выполнены.
ПРИЧИНА: таймаут run_commands = 30 с; sleep и другие долгие ожидания не помещаются в одну
команду в принципе.
ПРОФИЛАКТИКА:
1. Одна команда <= 25 с. Ожидание нарезать чанками по 20-25 с, в каждом чанке —
   самозавершающаяся проверка условия и уборка (if done → cleanup).
2. Тяжёлые/долгие прогоны — детачем с логами в tmp (правила 4.3, 7.2), хвост читать
   одиночным Get-Content -Tail, не ждать синхронно.
3. После таймаута первым делом установить, какие шаги успели выполниться
   (частичное состояние!), и довершить только недостающее — не повторять всё заново.
