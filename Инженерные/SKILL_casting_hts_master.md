# МАСТЕР ЛИТЬЯ В ХТС (блочная структура v2)

## Суперавило
Имя блока = префикс всех его параметров. Порядок сверху вниз,
ссылок вперёд нет. Полные правила - SKILL_relations_constitution.

## Карта блоков (порядок исполнения)
INPUT_ задаёт технолог, описания обязательны
SPLAV_ паспорт сплава (IF-цепочка по INPUT_ID_SPLAVA)
CONST_ константы с метками [BOOK]/[CALC]/[EMP]
HYDRO_ напор, Торричелли, расход, тау детали, сечения ЛПС
ST_ стояк: конус, D кратно 5, минимум 15
SHL_ шлакоуловитель + вихрь Стокса (INPUT_SHL_TYPE)
PIT_ питатели: 70% площадь на прибыль, 30% на деталь
MODUL_ модули узлов отливки и время затвердевания
DEF_ усадочный дефицит, делится на число прибылей
EXO_ минимум экзогильзы D x H по дефициту - выбирает конструктор
PRIB_ прибыли: форма 1 цилиндр / 2 сфера / 3 гильза;
      шейка только при INPUT_FEED_PRIB=1
CHILL_ холодильники: материал 1 сталь / 2 медь / 3 графит
FORM_ форма ХТС: стенки, габариты, масса смеси и смолы
TAU_ полный хронометраж - ПОСЛЕ масс прибылей!
TO_ режим термообработки
AUDIT_ скорость подъёма зерна и вердикт - ПОСЛЕ габаритов FORM_!
ECO_ экономика, КИМ, доли статей, вердикт

## Сценарные ключи (INPUT_)
INPUT_KOL_PRIB_LAT 0-3 боковых прибылей (0 = нет)
INPUT_KOL_PRIB_UP 0-3 верхних прибылей (0 = нет)
оба 0 = заливка без прибылей + вердикт MODUL_ о риске рыхлоты
INPUT_FEED_PRIB 1 питание через шейку / 0 теплоузел
INPUT_PRIB_FORM 1 цилиндр / 2 сфера / 3 гильза
INPUT_PRIB_EXO 1 экзотерм / 0 песок
INPUT_SHL_TYPE 0 ламинарный / 1 вихревой

## Ключевые формулы
H = H0 - P^2/(2*C), пол 0.05 м
v = sqrt(2*g*H); Q = M*1e9/(rho*tau_det)
tau_det = ceil(A*M^0.3333); tau_приб после масс PRIB_
трапеция: H=sqrt(S/(1-tan5)); L1=S/H+H*tan5; L2=S/H-H*tan5; L2>=4
Чворинов: t_затв = K*M^2*60 сек
модуль плиты M=H*W/(2*(H+W)); обода M=W*H/(4H+2W)
прибыль: D=5.5*M, H=1.1*D; V_real<V_деф - пересчёт по кубу
EXO: D_min=cbrt(V_деф/(0.785*1.2)); H_min=1.2*D_min
дефицит: V=M_сумм*усадка*1e9*K_VOL/rho
холодильник: толщина ceil(delta*0.8) мин 10; K 0.50/0.30/0.40
форма: стенка ceil(40+0.45*M_est) мин 50; низ ceil(50+0.6*M_est) мин 60
ТО: нагрев=delta*K_heat; выдержка=delta*K_hold/60+3; охл=выдержка*K_cool
КИМ=годное/жидкое; КИМ<0.45 = ЭКОНОМ РИСК
