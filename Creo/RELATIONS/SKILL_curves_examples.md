# ГОТОВЫЕ РЕЦЕПТЫ КРИВЫХ ИЗ УРАВНЕНИЯ (НАШИ ЗАДАЧИ)

## 1. Спираль пружины (цилиндрическая) - читает мастер пружины
r = FORM_D_EQ / 2
theta = t * 360 * GEOMETRY_TURNS_TOTAL
z = t * GEOMETRY_P_WORK * GEOMETRY_TURNS_TOTAL
/* углы в градусах; шаг и витки берутся из отношений мастера */

## 2. Коническая (телескопическая) пружина (цилиндрическая)
r = FORM_D_COIL_S/2 + (FORM_D_COIL_E/2 - FORM_D_COIL_S/2) * t
theta = t * 360 * GEOMETRY_TURNS_TOTAL
z = t * GEOMETRY_P_WORK * GEOMETRY_TURNS_TOTAL

## 3. Эвольвента шестерни (декартова) - ВИДНО, ГДЕ РАДИАНЫ
rb = BASE_D / 2
ang_deg = t * 60                 /* градусы - для sin/cos */
ang_rad = ang_deg * PI / 180     /* радианы - для наката */
x = rb * (cos(ang_deg) + ang_rad * sin(ang_deg))
y = rb * (sin(ang_deg) - ang_rad * cos(ang_deg))
z = 0

## 4. Спираль Архимеда/кулачок (цилиндрическая)
r = R0 + (R1 - R0) * t
theta = t * 360 * TURNS
z = 0

## 5. Синусоида (декартова) - аргумент В ГРАДУСАХ
x = t * LENGTH
y = AMPL * sin(t * 360 * WAVES)
z = 0

## 6. Сферическая спираль/купол (сферическая)
rho = R
theta = t * 360 * TURNS
phi = 90 * t

## 7. Переходная кривая/парабола (декартова)
x = t * LENGTH
y = H * (1 - (2*t - 1)^2)
z = 0

## Чек-лист отладки кривой
- Угловые единицы модели = градусы? (иначе всё поедет в 57.3 раз)
- t реально 0..1, множители оборотов учтены.
- Выбрана нужная система координат и тот CSYS, что задуман.
- Параметры, на которые ссылаетесь, существуют (иначе ошибка регенерации).
- Нет IF/ELSE - только выражения и max/min/abs.
