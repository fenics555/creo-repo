# ПРАВИЛА ГЕНЕРАЦИИ (КРИТИЧЕСКИ ВАЖНО)
1.  **Имена параметров:** Используй ТОЛЬКО имена из блока `INPUT PARAMETERS`. Не выдумывай новые имена входов.
2.  **Префиксы:** Все внутренние переменные должны иметь префикс блока (например, `GEOMETRY_`, `LOAD_`, `OTK_`).
3.  **Структура:** Код должен быть разбит на логические блоки с комментариями `/* ... */`.
4.  **Безопасность:** Всегда проверяй деление на ноль и отрицательные значения.
5.  **Выходные данные:** В конце кода обязательно присвой значения параметрам модели (d#, d##), чтобы геометрия обновилась.

# INPUT PARAMETERS (Входы пользователя)
Эти параметры уже существуют в модели. Не создавай их, только используй.
- `DIAMETER_WIRE` (d) — Диаметр проволоки
- `DIAMETER_OUT_START` (D1) — Наружный диаметр начала
- `DIAMETER_OUT_MID` (D2) — Наружный диаметр середины
- `DIAMETER_OUT_END` (D3) — Наружный диаметр конца
- `L_FREE` (L0) — Длина в свободном состоянии
- `L_ASSEMBLY` (L1) — Длина в сборке (преднатяг)
- `L_WORK_MAX` (L2) — Максимальная рабочая длина (ход)
- `TURNS_WORK` (n) — Число рабочих витков
- `TURNS_END` (n_end) — Число опорных витков (на каждый конец)
- `MATERIAL` — Материал (строка: "Сталь 70", "65Г", "AISI 302")
- `TIP_ENDS` — Тип концов ("свободные", "поджатые", "поджатые и шлифованные", "под резьбу")

# CONSTANTS (Константы КБ)
Используй эти значения для расчетов, если пользователь не задал свои.
CONST_G_MODULUS = 78500.0  /* Модуль сдвига для стали, МПа */
CONST_SAFETY_TAU = 1.30    /* Коэффициент запаса по усталости */
CONST_C_MIN = 4.0          /* Мин индекс навивки */
CONST_C_MAX = 12.0         /* Макс индекс навивки */

# АЛГОРИТМ РАСЧЕТА (ШАГ ЗА ШАГОМ)

## ШАГ 1: Геометрия и Санитария
1. Проверь входы: если `DIAMETER_WIRE` <= 0, установи `ERR_CRITICAL = YES`.
2. Определи тип формы (`FORM_TIP`):
   - Если D1 == D2 == D3 -> "cylindrical"
   - Если D1 != D3 -> "conical"
3. Рассчитай средний диаметр витка: `D_COIL = D_OUT - DIAMETER_WIRE`.
4. Рассчитай индекс навивки: `C_INDEX = D_COIL / DIAMETER_WIRE`.
5. Проверь индекс: если `C_INDEX < CONST_C_MIN` или `> CONST_C_MAX` -> `WARN_INDEX = YES`.

## ШАГ 2: Материалы
1. Найди `G_MODULUS` и `TAU_MAX` по строке `MATERIAL`.
   - "Сталь 70" -> G=78500, TAU=800
   - "65Г" -> G=78500, TAU=750
   - "AISI 302" -> G=68000, TAU=650
   - Иначе -> G=78500, TAU=600 (Default)

## ШАГ 3: Силовой расчет
1. Жесткость пружины: `RATE = (G_MODULUS * d^4) / (8 * D_COIL^3 * n)`
2. Сила преднатяга: `F1 = RATE * (L_FREE - L_ASSEMBLY)`
3. Сила рабочая: `F2 = RATE * (L_FREE - L_WORK_MAX)`
4. Напряжение касательное (Tau): `TAU = (8 * F * D_COIL * K_WAHL) / (PI * d^3)`
   - Где `K_WAHL = (4*C - 1)/(4*C - 4) + 0.615/C`

## ШАГ 4: Проверка ОТК (ОТК)
1. Статика: Если `TAU_F2 > TAU_MAX` -> `FAIL_STATIC = YES`.
2. Усталость: Если `TAU_F2 > TAU_MAX / CONST_SAFETY_TAU` -> `FAIL_FATIGUE = YES`.
3. Смыкание: Если `L_ASSEMBLY < (n + 2*n_end) * d` -> `FAIL_BLOCK = YES` (витки сомкнулись).

## ШАГ 5: Выход в Creo (d-параметры)
Присвой значения параметрам модели для обновления геометрии:
- `d44` = Шаг витка (`PITCH`)
- `d47` = Диаметр проволоки (`DIAMETER_WIRE`)
- `d42` = Диаметр начала (`DIAMETER_OUT_START`)
- `d76` = Диаметр середины (`DIAMETER_OUT_MID`)
- `d60` = Диаметр конца (`DIAMETER_OUT_END`)
- `d75` = Длина свободная (`L_FREE`)

# ПРИМЕР КОДА (ШАБЛОН)
Используй эту структуру для генерации. Заполни вычисления согласно алгоритму выше.

creo
/* ========================================================================= /
/ RELATIONS: ПРУЖИНА СЖАТИЯ (GENERATED BY AGENT) /
/ ========================================================================= */
/* --- 0. CONSTANTS --- */
CONST_G = 78500.0
CONST_SAFETY = 1.30
/* --- 1. INPUT SANITIZATION --- */
IF DIAMETER_WIRE <= 0
ERR_MSG = "ERROR: Wire diameter must be > 0"
ERR_CRITICAL = YES
ENDIF
/* --- 2. GEOMETRY --- /
/ Определяем форму */
IF ABS(DIAMETER_OUT_START - DIAMETER_OUT_END) < 0.1
FORM_TYPE = "CYLINDRICAL"
D_COIL_AVG = DIAMETER_OUT_START - DIAMETER_WIRE
ELSE
FORM_TYPE = "CONICAL"
D_COIL_AVG = ((DIAMETER_OUT_START + DIAMETER_OUT_END) / 2) - DIAMETER_WIRE
ENDIF
C_INDEX = D_COIL_AVG / DIAMETER_WIRE
/* --- 3. MATERIAL PROPERTIES --- */
IF MATERIAL == "Сталь 70"
G_MOD = 78500.0
TAU_LIMIT = 800.0
ELSE
IF MATERIAL == "65Г"
G_MOD = 78500.0
TAU_LIMIT = 750.0
ELSE
G_MOD = 78500.0
TAU_LIMIT = 600.0
ENDIF
ENDIF
/* --- 4. FORCE CALCULATION --- /
/ Жесткость */
SAFE_TURNS = max(TURNS_WORK, 0.5)
SAFE_D_COIL = max(D_COIL_AVG, 0.1)
RATE = (G_MOD * DIAMETER_WIRE^4) / (8 * SAFE_D_COIL^3 * SAFE_TURNS)
/* Силы */
DEF_PRELOAD = L_FREE - L_ASSEMBLY
DEF_WORK = L_FREE - L_WORK_MAX
FORCE_1 = RATE * DEF_PRELOAD
FORCE_2 = RATE * DEF_WORK
/* Коэффициент Валя */
K_WAHL = ((4 * C_INDEX) - 1) / max((4 * C_INDEX) - 4, 0.1) + (0.615 / max(C_INDEX, 0.1))
/* Напряжения */
SAFE_WIRE3 = max(DIAMETER_WIRE, 0.05)^3
TAU_1 = (8 * FORCE_1 * D_COIL_AVG * K_WAHL) / (PI * SAFE_WIRE3)
TAU_2 = (8 * FORCE_2 * D_COIL_AVG * K_WAHL) / (PI * SAFE_WIRE3)
/* --- 5. OTK CHECKS --- */
VERDICT = "OK"
IF TAU_2 > TAU_LIMIT
VERDICT = "FAIL: STRESS EXCEEDED"
ENDIF
IF TAU_2 > (TAU_LIMIT / CONST_SAFETY)
VERDICT = "WARNING: FATIGUE RISK"
ENDIF
/* Проверка на смыкание */
L_SOLID = (TURNS_WORK + 2 * TURNS_END) * DIAMETER_WIRE
IF L_ASSEMBLY < L_SOLID
VERDICT = "FAIL: COIL BINDING"
ENDIF
/* --- 6. OUTPUT TO CREO PARAMETERS --- /
/ Эти параметры управляют геометрией в Creo /
PITCH_CALC = L_FREE / (TURNS_WORK + TURNS_END) / Упрощенный шаг */
/* Присваиваем d-параметрам модели /
d44 = PITCH_CALC / Шаг /
d47 = DIAMETER_WIRE / Диаметр проволоки */
d42 = DIAMETER_OUT_START
d76 = DIAMETER_OUT_MID
d60 = DIAMETER_OUT_END
d75 = L_FREE
/* Строковые параметры для отчета */
OTK_STATUS = VERDICT
MATERIAL_USED = MATERIAL
