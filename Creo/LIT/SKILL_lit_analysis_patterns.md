# SKILL_lit_analysis_patterns - Основные шаблоны для литья в Creo Parametric

## 📋 ЦЕЛЬ
Создать библиотеку проверенных Relations-шаблонов для быстрого расчета параметров литья в Creo Parametric. Файл структурирован по блокам: входные параметры, гидравлика, стояк, шлакоуловитель, прибыли, HT-форма, экономика, контроль качества.

## 🏗️ СТРУКТУРА ФАЙЛА
Файл разделен на блоки с префиксами для удобства навигации:
- `SAFE_` — защита и верификация входных данных
- `HYDRO_` — гидравлические расчеты без учета усадки
- `ST_` — расчет стояка: подбор диаметра и высоты
- `SHL_` — расчет шлакоуловителя
- `PIT_` — расчет питателей
- `PRIB_` — расчет прибылей и дефицита металла
- `FLOW_` — проверка скоростей потоков
- `HTS_` — геометрия ХТС-формы и расход смеси
- `TO_` — термообработка
- `ECO_` — экономика производства
- `QUAL_` — оценка рисков и качества

## 🔧 КАНОНИЧЕСКИЕ ПАТТЕРНЫЕ

### 1. Шаблон верификации входных параметров (SAFE_block)
```relations
/* --- SAFE_ Блок верификации входных параметров --- */
/* Проверка данных перед запуском основных расчетов */
SAFE_MASSA_OTL_KG = MASSA_OTLIVKI
IF SAFE_MASSA_OTL_KG < 0.0
    SAFE_MASSA_OTL_KG = 0.0
    message "ВНИМАНИЕ: Отрицательная масса отливки, скорректирована до 0."
ENDIF

/* --- Конец блока верификации --- */
```

### 2. Шаблон расчета standing (ST_block)
```relations
/* --- ST_ Стояк: предупредительный оптимум, подбор и постудат --- */
/* Логика подбора диаметра стояка на основе гидравлических требований */
ST_H_ABOVE_TOP_MIN_MM = CONST_ST_MIN_HEAD_MM
ST_H_ABOVE_TOP_OPT_RAW_MM = CONST_ST_MIN_HEAD_MM + (CONST_ST_WALL_HEAD_K_RATIO * SAFE_DELTA_MM)
/* ... дальнейшие расчеты диаметра и высоты ... */
```

### 3. Шаблон расчета шлакоуловителя (SHL_block)
```relations
/* --- SHL_ Шлакоуловитель без учета усадки --- */
/* Расчет геометрии шлакоуловителя с учетом типа (классический или центробежный) */
SHL_S_ONE_MM2 = HYDRO_S_SHL_MM2 / SAFE_KOL_SHL
/* ... расчет длины, ширины, диаметра центрифуги ... */
```

## ⚙️ КЛЮЧЕВЫЕ КОНСТАНТЫ (для быстрого доступа)
- `CONST_GEN_PI_RATIO = 3.14159265` — число PI
- `CONST_GEN_G_M_S2 = 9.81` — ускорение свободного падения, м/с²
- `CONST_ST_STEP_MM = 5.0` — шаг стандартного ряда стояков, мм
- `CONST_HTS_WALL_K_MM_PER_KG = 0.45` — прирост толщины стенки на кг металла
- `CONST_LPS_EST_MASS_FRAC = 0.35` — первичная оценка массы ЛПС

## 📊 ПРИМЕР ИСПОЛЬЗОВАНИЯ
```relations
/* Включение SAFE-блока в начало relations */
#include "SKILL_lit_analysis_patterns.md" /* или копирование блоков */

/* Последующие расчеты автоматически используют проверенные значения */
ST_D_NIZ_MM = ceil(sqrt(4 * HYDRO_S_ST_MM2 / CONST_GEN_PI_RATIO) / CONST_ST_STEP_MM) * CONST_ST_STEP_MM
```
