# SKILL_lit_hts_aws - Методология HTS для американских литей (AWS D10.1)

## 📋 ОПИСАНИЕ
Официальная методология расчетов системы горячего верха по стандарту American Welding Society D10.1.

## 🏗️ ГЛАВНЫЕ ПРИНЦИПЫ
1. **Детальные расчеты**: Полное использование уравнения Черворинова с Z-константами per steel grade
2. **Комprehensive коды ошибок**: E01-E05 для диагностики проблем
3. **Требования к изоляции**: 50–100 mm изоляция для_extension feeding time
4. **Комплексная экономика**: Детальный расчет MRR (металл recovery rate) и ECO_EFFICIENCY

## 📐 КЛЮЧЕВЫЕ УРАВНЕНИЯ

### Уравнение Черворинова:
```
t_s = B² / Z, где Z = mold constant (1.1–2.5, зависит от стали)
```

### Модуль рисера:
```
M_feeder ≥ k × M_casting, где k = 1.2–1.5 (сталь)
```

### Модуль охлаждения:
```
B = V / A
Z = material-specific constant from AWS tables
```

### Коэффициент отдачи металла:
```
MRR = (M_casting_delivered / M_melted_total) × 100
```

## 📊 ТИПИЧЕСКИЕ ЗНАЧЕНИЯ (улучшенная таблица)

| Параметр | Значение | remark |
|----------|----------|--------|
| Коэффициент Черворинова (k) | 1.2–1.5 | per steel grade: 1.2 (low C), 1.3–1.4 (mid), 1.5 (high C) |

## 🔧 ПРИМЕР РАСЧЕТА

Для стали grade K10205 (0.20% C):
1. Z = 1.8 (из таблицы AWS D10.1)
2. Расчет B = V/A для отливки
3. t_s = B² / 1.8 (уточненное время затверждения)
4. M_feeder ≥ 1.3 × M_casting (безопасный коэффициент)
5. Расчет диаметра рисера на основании модуля
6. Проверка MRR: ожидаемый возврат > 90%
