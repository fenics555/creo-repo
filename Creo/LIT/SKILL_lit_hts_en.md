# SKILL_lit_hts_en - Методология HTS для европейских литей (EN 1563)

## 📋 ОПИСАНИЕ
Методология расчетов HTS на основе Европейского стандарта EN 1563 с региональными ajdustments для разных стран ЕС.

## 🏗️ ГЛАВНЫЕ ПРИНЦИПЫ
1. **Баланс между точностью и упрощением**: Методы, которые являются точными Enough для производственных условий
2. **Четкие допуски и tolerances**: Четкие указания по допускам на размеры и параметры
3. **Региональные Adjustments**: Различия между странами ЕС (Германия, Франция, Италия, и т.д.)
4. **Глубокое понимание направленного затверждения**: Control of solidification sequence от периферии к центру

## 📐 КЛЮЧЕВЫЕ УРАВНЕНИЯ

### Модуль охлаждения:
```
B = V / A
```
Базовый расчет с последующими корректировками.

### Модуль рисера:
```
M_feeder ≥ k × M_casting, где k = 1.1–1.4
```
Менее консервативные значения, чем в AWS, но с четкими tolerances.

### Направленное затвердение:
```
Проверка Sequential Solidification от периферии к центру
```
Использование расстояния и модуля для определения порядка затверждения.

### ТермическиеGradients:
```
∇T = (T_pouring - T_mold) / d
```
Где d = distance from surface, используется для оценки напряжений.

## 📊 ТИПИЧЕСКИЕ ЗНАЧЕНИЯ (улучшенная таблица)

## 🔧 ПРИМЕР РАСЧЕТА

Для стальной отливки среднего размера:
1. Расчет B = V/A с учетом региональных факторов
2. Определение Z из таблицы EN 1563 (пример: Z ≈ 1.5 для среднер Stacey steel)
3. Расчет M_feeder ≥ 1.2 × M_casting (безопасный коэффициент)
4. Проверка направленного затверждения:确保 solidification starts at periphery and moves to center
5. Оценка tolerances на итоговые размеры с учетом HOT_FACTOR и USADKA_P
6. Проверка экономической эффективности с учетом европейских цен на материал и энергию

## ⚠️ Характерные особенности
- Четкие разделение на классы качества и размеров
- Акцент на.directional solidification control
- Регулярные regionales Adjustments для разных стран ЕС
- Интеграция с европейскими системами质量管理
- Учет региональных предпочтений в дизайне рисеров (form и placement)
- Меньше внимания к экономическим расчетам по сравнению с AWS, больше — на качественных tolerances
