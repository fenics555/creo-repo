# SKILL_lit_hts_turkey - Методология HTS для турецких литей

## 📋 ОПИСАНИЕ
Адаптация методологии HTS под турецкие стандарты с учетом специфики турецких сталелитей и производственных условий.

## 🏗️ ГЛАВНЫЕ ПРИНЦИПЫ
1. **Адаптация ГОСТа**: Перевод и адаптация стандартов ГОСТ 14953-80 под турецкие условия
2. **Учет специтики турецких сталей**: Учет легирующих элементов и характеристик сталей, произведенных в Турции или импортированных
3. **Сочетание метрик и традиционных единиц**: Использование метрической системы с occasional использованием традиционных единиц в документах
4. **Учет импорта оборудования**: Настройка параметров под.imported foundry equipment and furnaces

## 📐 КЛЮЧЕВЫЕ УРАВНЕНИЯ

### Модуль охлаждения (адаптированный):
```
B = V / A с коэффициентом коррекции для Turkish steel grades
```

### Модуль рисера:
```
M_feeder ≥ k × M_casting, где k = 1.3–1.6 (сталь)
```
Значения slightly выше, чем в Европе, с учетом локальных условий.

### Усадка (USADKA_P):
```
USADKA_P = 0.85–1.00% для углеродистой стали, может варьироваться в зависимости отlegering
```

### HOT_FACTOR:
```
HOT_FACTOR = 1 - (USADKA_P / 100)
```
Стандартная формула, но с Turkish material properties.

## 🔧 ПРИМЕР РАСЧЕТА

Для средней сталей отливки (пример для стали 40X23G2HSDGU):
1. Адаптация коэффициента усадки под Turkish steel grade (USADKA_P ≈ 0.9–1.1%)
2. Расчет HOT_FACTOR = 1 - (0.95/100) = 0.9905
3. Модуль рисера: M_feeder ≥ 1.45 × M_casting (безопасный коэффициент для Turkish conditions)
4. Диаметр рисера: расчет с учетом шага standing 5–12 mm
5. Изоляция: 60–100 mm для большинства приложений
6. Экономическая эффективность: расчет с Turkish material costs и energy prices
7. MRR (возврат металла): оценка > 85% для оптимального дизайна

## ⚠️ Характерные особенности
- Адаптация под Turkish steel grades и ihre свойства
- Учет типа печи (open hearth, BOF, EAF) в расчетах
- Сочетание метрических и традиционных единиц в документах
- Уconsideration of imported equipment parameters
- Баланс между традиционными Turkish foundry practices и современными методиками
- Меньше внимания к детальным экономическим расчетам по сравнению с AWS, больше — на практическом опыте
- Важность правильного выбора места расположения HTS на отливке
