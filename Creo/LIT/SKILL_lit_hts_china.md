# SKILL_lit_hts_china - Методология HTS для китайских литей

## 📋 ОПИСАНИЕ
Справочник по расчетам системы горячего верха (HTS) на основе китайских стандартов и промышленных практик.

## 🏗️ ГЛАВНЫЕ ПРИНЦИПЫ
1. **Упрощенные расчеты**: Использование approximation formulas вместо комплексных моделей
2. **Модуль шага**: Стандартные шаги 5–10 мм для standing диаметра
3. **USADKA_P диапазон**: 0.9–1.1% для углеродистой стали
4. **Единые единицы**: Primarily metric, occasional mixing with traditional units

## 📐 КЛЮЧЕВЫЕ УРАВНЕНИЯ

### Модуль рисера:
```
M_feeder = k × M_casting, где k = 1.5–1.8 (сталь)
```

### Время затверждения:
```
t_s = B² / (π × α), α ≈ 4.8 mm²/min (сталь)
```
Упрощенная версия без elaborate safety factors.

### Модуль охлаждения:
```
B = V / A
```
Базовый расчет без региональных коэффициентов Z.

## 📊 ТИПИЧЕСКИЕ ЗНАЧЕНИЯ

| Параметр | Значение |
|----------|----------|
| Коэффициент Черворинова (k) | 1.5–1.8 |
| Шаг standing (ST_STEP) | 5–10 mm |
| HOT_FACTOR | 1 - (USADKA_P/100), USADKA_P = 0.9–1.1% |
| Количество рисеров | Обычно 1–2 для малых отливок |
| Изоляция рисеров | Реже, применяется при особых условиях |

## 🔧 ПРИМЕР РАСЧЕТА (типовое)

Для отливки сталью размером 500×300×200 мм:
1. Расчет модуля: B = V/A = 48.39 mm
2. Время затверждения: t_s ≈ 155 min (упрощенно)
3. Минимальный модуль рисера: M_feeder ≥ 1.5 × 48.39 = 72.6 mm
4. Диаметр рисера: D ≈ 80–90 mm (типовое значение)
5. Экономическая эффективность: оценивается оценчиво, примерно 85–90%

## ⚠️ Характерные особенности
- Меньше внимания к изолированным рисорам
- Упрощенная проверка направленного затверждения
- Акцент на сериальном производстве
- Меньше детальных экономических расчетов
- Использование стандартных размеров рысоров из каталогов
