# ПАСПОРТ КОМПАНИИ ДЛЯ CREO
Живые значения из config.pro — в SKILL_company_config.md (корень репо, собирает passport_tools).

## Единицы и точность
- Система: MMKS (мм, кг, сек). 4 знака после запятой (default_dec_places 4).
- Допуски: ISO, класс medium.
- Y-фактор листового металла: 0.785398 (канон из config.pro).

## Шаблоны (Z:\PTC\CREO-START\НАСТРОЙКИ\ШАБЛОНЫ\)
- Деталь: mm_part.prt; сборка: sborka_mm.asm; листовой металл: mm_sheet.prt; чертёж: c_drawing.drw.
- Канон-копии с параметрами и TPL_SOURCE — в SKILL_creo_templates (templates/ в репо).

## Шифры и именование
Имя файла = имя модели = шифр без пробелов.
Шифры: БДФ.ххх.ххх, АЛ-1110-..., ПТР-401-..., МК-262, ВГМ хххх.00.00.
Папки проектов: 000_NN Название. Архив (СТАРОЕ / НЕ БРАТЬ) — не использовать.

## Обязательные параметры каждой модели (канон)
- rel_model_name (STRING) — шифр для спецификации. КАНОН КБ.
  Легаси-синонимы (в новых НЕ использовать): ОБОЗНАЧЕНИЕ, shifr.
- МАТ_MARK (STRING) — материал (пример: Ст45 ГОСТ 1050-2013).
- MASS (REAL) — масса, кг: MASS = MP_MASS. БЕЗ округления.
- ТИП (STRING) — Деталь / Сборка / Стандарт / Покупное.
- TPL_SOURCE (STRING) — свидетельство о рождении: KB_part / KB_asm / KB_sheet. Нет значения = покупное (не производим).

Отношения-минимум новой модели — в SKILL_creo_templates.

## Массовые параметры (MP_)
Анализ масс создаёт: MP_MASS (кг), MP_VOLUME, MP_COG_X/Y/Z.
Вывод на чертёж: &параметр. Для компонента сборки: &MASS@имя_компонента.

## Чертежи ЕСКД
- Дата: дд.мм.гг.
- Чертёж переименовывается вместе с моделью (rename_drawings_with_object both).
- Имя чертежа = имя модели.

## Чек перед выдачей
- имя = шифр без пробелов; обязательные параметры на месте; MASS > 0 для деталей;
- единицы mmks, 4 знака; шаблон по типу; дата дд.мм.гг; TPL_SOURCE не противоречит ТИП.
