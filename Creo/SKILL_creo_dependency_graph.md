# SKILL: Creo Dependency Graph (BOM vs Inheritance)

## ⚠️ КРИТИЧЕСКАЯ ПРИНЦИПИОЛОГИЯ
В Creo существует две принципиально разные топологии связей. Ошибка в выборе направления обхода приведет к потере данных или созданию ложных связей.

### 1. Граф "СВЕРХУ-ВНИЗ" (BOM / Composition)
**Тип:** Композиция (Assembly $\rightarrow$ Components).
**Сущность:** Сборки (`.asm`).
**Направление:** Только от Родителя к Потомку.
**Логика:**
*   Сборка «знает» свой состав (количество, ID компонентов).
*   Компоненты «не знают», в каких сборках они находятся.
*   **Задача парсера**: Извлечь дерево входимости из секций `NeuAsmSld` / `SolidPersistTable`.

### 2. Граф "СНИЗУ-ВВЕРХ" (Inheritance / Genealogy)
**Тип:** Наследование (Part $\rightarrow$ Parent).
**Сущность:** Детали (`.prt`).
**Направление:** Только от Потомка к Родителю.
**Логика:**
*   Потомок (Заготовка, Отливка, Модель) «знает» своего родителя (через `feat_id` или `Base_Part` маркер).
*   Родитель «не знает» о своих потомках.
*   **Задача парсера**: 
    1. Выявить роль детали (через `LargeText` и `FeatDefs`).
    2. При обнаружении роли "Потомок" — инициировать **Широкий Поиск** по диску для нахождения всех «Родителей» и их «Потомков».

## 🛠️ МАТРИЦА ОПРЕДЕЛЕНИЯ РОЛИ (Detection Matrix)

| Признак (Evidence) | Роль (Role) | Направление обхода |
| :--- | :--- | :--- |
| Секции `NeuAsmSld`, `FullMData` | **Сборка / CAM** | Вниз (Downwards) |
| Маркер `Base_Part`, `Inheritance` | **Конструкторская деталь** | Вверх (Upwards) |
| Параметр `Shrinkage`, `Casting` | **Деталь-отливка** | Вверх (Upwards) |
| Секции `Merge` / `Inheritance` | **Деталь-заготовка** | Вверх (Upwards) |

## 🚀 АЛГОРИТМ ОРКЕСТРАЦИИ
1.  **Scan**: Поиск всех `.prt` и `.asm` файлов.
2.  **Classify**: Запуск `detect_plm_role()`.
3.  **Branch**:
    *   IF `ASSEMBLY` $\rightarrow$ `build_bom_tree()` (Down).
    *   IF `PART` $\rightarrow$ `trace_genealogy()` (Up + Broad Scan).
4.  **Merge**: Сборка всех графов в единую PLM-матрицу.
