# ГОСТ-выдержки для карточек материалов (память дома, в гите)

**Назначение:** здесь лежат **извлечённые из ГОСТов данные по маркам** — чтобы заполнять/сверять карточки `.mtl` и **трассировать** значения (`SKILL_material_parameters.md` §6д).

**Правила:**
- Один ГОСТ = один файл: `GOST_<номер>.md` (напр. `GOST_4784-97.md`).
- Внутри — таблица по маркам: пределы (текучести / прочности / сжатия), плотность, твёрдость, класс/группа, область применения (как в ГОСТе).
- **Сам ГОСТ(ы) кладём РЯДОМ С КАРТОЧКАМИ в дерево `Z:\...\МАТЕРИАЛЫ` — ТОЛЬКО С ПОДТВЕРЖДЕНИЯ ВЛАДЕЛЬЦА** (`SKILL_material_parameters.md` §6д). Кэш загрузок — `D:\AI\ИЗУЧИТЬ\ГОСТ\<номер>\`.
- **Формат ГОСТа в дереве — HTML (`.htm`), НЕ PDF** (владелец 20.11.2026): HTML-таблицы парсятся структурно (`D:\AI\PROBA\gost_table.py`), PDF в дереве запрещён и удаляется.
- **Выжимка `GOST_<номер>.md` (читаемые таблицы) — РЯДОМ С КАРТОЧКАМИ** в дереве материалов (владелец 20.11.2026) **и** копия здесь (git-память). Собирается stdlib-парсером `D:\AI\PROBA\htm_tables_md.py`.
- Значение в карточке ОБЯЗАНО подтверждаться строкой отсюда; иначе — статус НЕТ ДАННЫХ.
- Выбор материала в Creo читает только `.mtl/.xch/...`, поэтому документация UI не засоряет.

**Связано:** `SKILL_material_parameters.md` §6б/§6в/§6г/§6д.
