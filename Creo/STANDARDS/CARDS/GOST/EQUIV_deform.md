## Где в США нормируются свойства (что реально даёт что)
- **ASTM B221 / B211 / B209 / B241** (прутки/проволока/листы/профили) — **растяжение** (Rm/σв, Rp0,2, A) — то же, что наш ГОСТ 21488 (новых полей не даёт).
- **ASTM B316** — заклёпочная проволока (для 2117/Д18) — растяжение/сдвиг.
- **MMPDS (ex MIL-HDBK-5)** — **полные расчётные допуски**: сжатие, усталость, срез, смятие. **Это и есть источник недостающих σ_сжатия/усталость, но он РАСПРОСТРАНЯЕТСЯ ОГРАНИЧЕННО (платно/подписка)** — свободного HTML нет.
- **AA «Teal Sheets»** — обозначения/состав (аналог нашего 4784), свободно.
- **MMPDS/ASM/MatWeb** — «типичные» справочные значения (только справочно).

**Вывод:** свободные американские источники дают растяжение (уже есть из ГОСТ); недостающие сжатие/усталость есть только в **MMPDS** (ограниченный доступ). Твёрдость — иногда в ASTM/AA (не для всех полуфабрикатов).
