# СВЯЗЬ МАТЕРИАЛ ↔ ШТРИХОВКА (Creo)

## 1. 🔴 ГЛАВНОЕ ПРАВИЛО: СОВПАДЕНИЕ ИМЁН ФАЙЛОВ

**Первоисточник — хелп PTC** (`creo_help_pma\russian\detail\Determining_Crosshatching_Patterns.html`, живая цитата):

> «Шаблоны штриховки могут базироваться на том материале, который назначен для детали. Например,
> при создании сечения, которое рассекает определенный материал, например, сталь, система ищет
> шаблон штриховки, **который имеет то же имя, что и назначенный материал**. При нахождении
> системой такого шаблона, она **автоматически назначает его сечению**. Если для сечения не
> определен материал, система назначает стиль штриховки по умолчанию.»

**Локальный `readme.txt`** (в самой папке `ШТРИХОВКА\`, текст в OEM-866):

> «Для связи типа штриховки с материалом **название файла штриховки должно совпадать с названием
> файла материала**, например: материал `08X18N10_mmkgs.mat` и штриховка `08X18N10_mmkgs.xch`»

**⇒ СОПОСТАВЛЕНИЕ ИДЁТ ПО ИМЕНИ ФАЙЛА (без расширения), А НЕ ПО ПАРАМЕТРУ.**
Creo сам подбирает штриховку к материалу модели по совпадению имени.

## 2. 🔴 `PTC_XHATCH_FILE` — ДОМОРОЩЕННЫЙ, Creo ЕГО НЕ ИСПОЛЬЗУЕТ

В наших `.mtl` есть параметр `PTC_XHATCH_FILE` = `'metall'` / `'steel'` / `'Латунь'` (замер: **402 из 411** файлов).
Это **наш** параметр «для человека» — Creo связь материал↔штриховка через него **не строит**.

**⇒ Заполнить `PTC_XHATCH_FILE` ≠ включить автоштриховку.** Чтобы автоштриховка заработала,
нужно **совпадение имён** `.mtl` и `.xch`.

## 3. 🔴 САМАЯ ВАЖНАЯ ГРАБЛЯ: `pro_crosshatch_dir` В `config.pro` ЗАКОММЕНТИРОВАН

Живой `Z:\PTC\CREO-START\START-STD\config.pro`, **строка 115**:

```
!pro_crosshatch_dir Z:\PTC\CREO-START\НАСТРОЙКИ\ШТРИХОВКА\
```

**Восклицательный знак = опция ВЫКЛЮЧЕНА** ⇒ Creo указанную папку **не читает**,
52 файла штриховки (`.xch`/`.lsl`) для него не существуют.
Рядом: строка 108 `pro_material_dir` — **активна** (без `!`).

**Проверять так:** открыть `config.pro` и убедиться, что строка начинается НЕ с `!`.
Правка `config.pro` — центр настройки всего Creo; бэкап файла обязателен.

## 4. ФОРМАТЫ ФАЙЛОВ ШТРИХОВКИ

| Расширение | Что это | Где живёт |
|---|---|---|
| `.xch` | шаблон штриховки XCH (основной) | `ШТРИХОВКА\` (корень + подпапки) |
| `.lsl` | файл линий/штриховки (`concrete.lsl`, `glass1.lsl`) | `ШТРИХОВКА\` |
| `.pat` | альтернативный образец (PAT) | упом. в хелпе PTC |

**Управление по умолчанию (хелп PTC, только для XCH):** если в модели есть параметры
(integer) `default_xhatch_angle` и `default_xhatch_space` (`_spacing`) — они **замещают**
любые другие определения стиля; тогда совпадение имени материала уже не важно.

## 5. ЗАМЕР 05.11.2026 — СВЯЗЬ РАЗОРВАНА ПОЛНОСТЬЮ

| Предмет | Число |
|---|---|
| Материалов `.mtl` | **409** (имена: `stal_st0`, `al_splav_amg2`, `latun_l63`…) |
| Файлов штриховки | **52** (имена: `metall_eskd`, `aluminum`, `Металлы`, `Сетка`…) |
| Материалов с одноимённой штриховкой | **0 из 409** |
| Штриховок с одноимённым материалом | **0 из 52** |

**Причина:** два несогласованных словаря имён — материалы названы по **марке/сортаменту**,
штриховки — по **типу материала**. Плюс подпапки:

```
ШТРИХОВКА\
├─ (корень)       ceramic_eskd.xch · metall_eskd.xch · no_metall_eskd.xch · concrete.lsl … (18)
├─ english_name\  beton · metal · nonmetal · grid · liquid · stone · vertical … (13)
├─ ISO\           aluminum · copper · iron · titanium · zinc · plastic · glass · electric (8)
└─ old\           Бетон · Металлы · Неметаллы · Сетка · Жидкости · Кладка_фасад … (12)
```

**Дубли по смыслу (одна штриховка — разные имена):** `metal.xch` ≡ `Металлы.xch` ≡ `metall_eskd.xch`;
`nonmetal.xch` ≡ `Неметаллы.xch` ≡ `no_metall_eskd.xch`; `beton.xch` ≡ `Бетон.xch`; `rubber.xch` ≡ `Резина`.

**Сломанное расширение:** `english_name\glass.xch.1` — Creo увидит имя `glass.xch` с расширением `.1` ⇒ **не найдёт**.

## 6. КАК ПОЧИНИТЬ (порядок)

1. **Включить путь:** убрать `!` в строке `pro_crosshatch_dir` (`config.pro`) — с бэкапом файла.
2. **Свести имена к одному уровню:** штриховки в корень `ШТРИХОВКА\`, подпапки убрать;
   дубли развести (оставить один файл на смысл, лишние — в `_УБРАНО`).
3. **Связать с материалами:** создать `.xch` с именами, **совпадающими** с именами `.mtl`
   (по значениям `PTC_XHATCH_FILE` как подсказке типа: `metall` → сталь/чугун, `nemetall` → пластик/дерево).
4. Проверка: открыть деталь в Creo → сечение → штриховка должна подставиться сама.
