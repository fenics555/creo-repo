# СПЕЦИФИКАЦИЯ ИМЕНОВАНИЯ МОДЕЛЕЙ
Имя файла = имя модели = шифр без пробелов.
Обязательные параметры КАЖДОЙ детали/сборки:
- rel_model_name (STRING) - шифр/имя для спецификации. КАНОН КБ. Легаси-синонимы (в новых моделях не использовать): ОБОЗНАЧЕНИЕ, shifr
- МАТ_MARK (STRING) - материал по справочнику (пример: Ст45 ГОСТ 1050-2013)
- MASS (REAL) - масса кг: MASS = MP_MASS
- ТИП (STRING) - Деталь / Сборка / Стандарт / Покупное
Отношения-минимум новой модели:
MASS = MP_MASS
rel_model_name = "<шифр>"
МАТ_MARK = "<материал>"
ТИП = "Деталь"
Шифры: БДФ.ххх.ххх, АЛ-1110-..., ПТР-401-..., МК-262, ВГМ хххх.00.00
Папки: 000_NN Название; архив (НЕ ПОЛЬЗОВАТЬСЯ/СТАРОЕ/НЕ БРАТЬ) не трогать.
Чертёж переименовывается с моделью (rename_drawings_with_object both).
Чек перед выдачей: имя=шифр; 4 параметра на месте; MASS>0; дата дд.мм.гг.
