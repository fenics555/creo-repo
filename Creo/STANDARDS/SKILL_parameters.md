# ПАРАМЕТРЫ МОДЕЛЕЙ (источники правды)
1. ОБОЗНАЧЕНИЕ / НАИМЕНОВАНИЕ(+1/2) — внутренние шифры КБ. Источник правды для спецификаций, чертежей, индексов; по ним выводятся детали в спецах.
2. CATALOG_NUMBER / CATALOG_NAME(+1/2) — ВНЕШНИЕ ссылки на каталоги других производств/машин. НЕ совпадают с реальными шифрами; чужие шифры в наши каталоги не вставляются. Отдельные независимые параметры.
3. NAME_1/2, NAME_1_ENG — латинские дублёры для интеграций.
4. Аудит: уникальность — по ОБОЗНАЧЕНИЕ. CATALOG_* — ТОЛЬКО для кросс-аудита коллизий (две наши детали с одним каталожным; наш шифр = чужой каталожный), не как источник шифра.
5. Русские параметры не убиваем; ISO набиваем рядом только при появлении потребителя, через отношение (синхронно).
6. ТИП — **ПРИРОДА модели**, ограниченный: деталь → «Деталь», обычная сборка → «Сборка», **производственная
   (мануфакчуринг, оснастка) → «Производство»** (она ВЫГЛЯДИТ как сборка; признак — параметр `ПАРТИЯ`).
   Подробности и правила безопасности: `Creo\STANDARDS\SKILL_creo_model_nature.md`.
7. Ограниченные параметры дома (варианты заданы файлом `НАСТРОЙКИ\ФАЙЛЫ_ОГРАНИЧЕНИЙ_ПАРАМЕТРОВ\list.lst`,
   `restricted_val_definition` включён 23.09.2026): `ТИП`, `ТИП2` (Комплекты/Технология), `ФОРМАТ`
   (А3/А4/А2/А0/БЧ/-), `РОЛЬ_В_ЛИТЕЙНОЙ_СИСТЕМЕ` (Литниковая_система/Модель/Сборка_ящика/Стержень/
   Формовочный_объем/Ящик), `GROUP`. Пустое значение такому параметру через API не поставить.
8. `ПАРТИЯ` — размер партии; встречается у производственных моделей (вместе с `ТИП = Производство`).
