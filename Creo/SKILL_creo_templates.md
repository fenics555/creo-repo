# КАНОН-ШАБЛОНЫ МОДЕЛЕЙ
Канон-копии — в templates/ репо. Рабочие — Z:\PTC\CREO-START\НАСТРОЙКИ\ШАБЛОНЫ\.
Правило: правим канон в репо → копируем в Z:\PTC. GitHub хранит версии и откат.

## Отношения-минимум (вставить в шаблон; регенерация создаст параметры)
/* МИНИМУМ КБ: не удалять, править только значения-плейсхолдеры */
rel_model_name = "<ШИФР>"
МАТ_MARK = "Ст45 ГОСТ 1050-2013"
ТИП = "Деталь"
TPL_SOURCE = "KB_part"
MASS = MP_MASS

- Для KB_asm: ТИП = "Сборка", TPL_SOURCE = "KB_asm"; для KB_sheet: TPL_SOURCE = "KB_sheet".
- Инженер меняет ТОЛЬКО <ШИФР> и <МАТ_MARK>. Плейсхолдер <ШИФР> нарочно кричит с чертежа, пока не заменён.
- TPL_SOURCE — свидетельство о рождении. Нет TPL_SOURCE = покупное (не производим: в цикле только срок поставки).

## Контроль
- ТИП противоречит TPL_SOURCE → флаг «проверь тип», не молчать.
- Спецификация: секция сначала по TPL_SOURCE, затем ТИП; покупные — по префиксу обозначения (ГОСТ/ОСТ/каталог → Стандартные изделия).
- Чек новой модели: 4 параметра + TPL_SOURCE на месте, MASS > 0, имя = шифр без пробелов.
