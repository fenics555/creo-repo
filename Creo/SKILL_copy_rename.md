# КОПИРОВАНИЕ И ПЕРЕИМЕНОВАНИЕ МОДЕЛЕЙ CREO (рабочая методика КБ)
1. Никогда не переименовывать в рабочей папке: Rename переименовывает файл на диске,
   схема «переименовать→сохранить→вернуть имя» уносит копию обратно в оригинал. Только временная папка.
2. Перед переименованием во временной папке оригиналы должны выйти из сессии,
   иначе Creo подставит их вместо временных моделей и переименование уйдёт в рабочую папку.
3. Порядок переименования семейства: экземпляры семейств (с глубоких вложенных) → generic → чертежи последними.
4. Копию generic даёт сам Backup во временную папку; model.Copy() не нужен,
   новые имена рождаются переименованием уже во временной папке.
5. Спутники детали/сборки входят в план копирования автоматически, если существуют рядом:
   <имя>_mfg.asm (чпу-обработка), <имя>_mfg.drw (карта наладки), <имя>_wp.prt (заготовка);
   чертежи одноимённые подтягиваются сами.
6. Проектное переименование: пользователь задаёт правило одной строкой вида
   A_old=A_new, и правило применяется ко всем именам плана, а не пофайлово.
   Длина префикса любая — её определяет сам пользователь в правиле.
7. Исполнения (таблицы семейств) Creo обычным копированием не переносит:
   их файлы-экземпляры включаются в план явно по пункту 3.
8. Параметры: заблокированные уравнением не перезаписываются (возвращать причину);
   ЗОНА и ПРИМЕЧАНИЕ ставятся на уровне компонента сборки, как ПОЗИЦИЯ,
   потому что деталь может быть заимствована в чужой проект.
