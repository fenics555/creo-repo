# СКИЛЛ: Анатомия на уровне битов Creo и Reverse Engineering

**Статус:** АКТИВЕН / В РАЗРАБОТКЕ
**Цель:** Полное восстановление файлов Creo `.prt` из «сырых» байт в семантические модели.

## 🧠 БАЗОВЫЕ ПРИНЦИПЫ («Золотые правила»)
1. **НИКОГДА НЕ ДОВЕРЯЙТЕ ТОЛЬКО ОГЛАВЛЕНИЮ**: Оглавление (TOC) — это карта, а файлы — местность. Всегда сверяйте смещения оглавления с реальными байтовыми шаблонами (`feat_defs_`).
2. **КЛЮЧИ ВАЖНЕЕ ОКОН**: Не ищите данные в «окнах» (например, «найди double рядом с ID»). Ищите **Ключи** (например, `type\x00`, `ref_id\x00`) и извлекайте значения, идущие сразу за ними.
3. **АНТИ-ГАЛЛЮЦИНАЦИЯ (Бинарный контекст)**: Последовательность байт выглядит как `double` только если она НЕ является частью ASCII-строки. Всегда используйте «Фильтр контекста печатаемых символов ASCII».
4. **ПОДХОД «УКАЗАТЕЛЬ В ПЕРВУЮ ОЧЕРЕДЬ»**: Каждая главная структура в Creo связана. Чтобы освоить файл, нужно освоить логику `offset` (смещения) и `pointer` (указателя).

## 🔍 ОТКРЫТАЯ АНАТОМИЯ («Таблица истинны»)

### 1. Разделители и маркеры фичей
| Шаблон | Значение | Надёжность | Примечание |
| :--- | :--- | :--- | :--- |
| `feat_defs_NNN` | Маркер определения фичи | **ВЫСОКАЯ** | Первичный якорь для всего парсинга фичей. |
| `FB E3 F7 80` | Внутренний сегментатор | **НИЗКАЯ** | **ЛОЖНЫЙ РАЗДЕЛИТЕЛЬ.** Не использовать для построения дерева. |
| `\x00` | Нулевой терминатор | **ВЫСОКАЯ** | Завершает строки и пары ключ-значение. |

### 2. Паттерны «ключ-значение» (Хирургическое извлечение)
Найденные ключи для идентификации свойств фич:
- `type\x00` / `ft_type\x00`: определяют тип фичи (например, EXTRUDE, REVOLVE).
- `AE_Type\x00`: ключ атрибута высокого приоритета для классификации.
- `ref_id\x00` / `parent_id\x00`: определяют иерархию (структуру дерева).
- `symbol_key\x00`: идентифицирует внутреннюю логику/символ, используемый для фичи.

### 3. Типы данных и фильтрация
- **Doubles (64-бит)**: находятся в записях геометрии.
    - *Правило фильтра*: Если 8–16 байт вокруг `double` — печатаемые ASCII, это **СТРОКА**, а не число.
- **Integers (32-бит)**: часто используются для ID и указателей.
    - *Формат*: проверяйте и Little-Endian (`<I`), и Big-Endian (`>I`) для надёжности.
