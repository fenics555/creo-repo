# RELATIONS В CREO — СПРАВОЧНИК
Правила оформления кода — в SKILL_relations_constitution. Python-скрипты — по SKILL_python_standard; к relations он НЕ применяется.

## Что это
Отношения (relations) — формулы и логика, связывающие размеры и параметры модели.
Запись: Tools > Relations. Пересчёт — при регенерации (Ctrl+G).

## Где живут
- Отношения детали — в детали; сборки — в сборке (читают параметры компонентов: d5@KORPUS).
- Отношения элемента — привязаны к элементу; чертежа — для основной надписи и таблиц.

## d-имена и параметры
Размерам Creo даёт имена d0, d1… Лучше задавать символьные: tolshchina, diam_otv.
Типы параметров: REAL, INTEGER, STRING, YES/NO. Строки — в двойных кавычках.
Параметр создаётся самим отношением: material = "Сталь 45".

## Операторы и логика
= присвоить; == равно; != не равно; > < >= <=
& и; | или; ! не
IF условие ... ELSE ... ENDIF — **без THEN!** Вложенные IF можно.
FOR i = 1 TO n ... ENDFOR

## Математика
sqrt, abs, ceil, floor, sin, cos, tan, asin, acos, atan, log, ln, exp, max, min
- Углы — в ГРАДУСАХ (стандарт компании). sin(30) = 0.5; asin(0.5) = 30. Перевод в радианы НЕ нужен.
- Степень: ^ (d0 = 2^3). Функции pow() НЕТ.
- ROUND НЕТ! Округление: floor(x + 0.5); до 0.1: floor(x*10 + 0.5)/10; вверх: ceil(x).
- Округляй только то, что нужно для читаемости (развёртка, диаметр, шаг). Массу и мелкие величины НЕ округлять: точность задаёт стандарт вывода (4 знака), а не отношение.
- PI — встроенная константа.

## Строки
itos(n), extract(s,start,len), search(s,p). Склейка: + (msg = "C = " + itos(c))

## Лимиты
- Имя параметра: 40 символов; имя модели: 63 (практика <= 40).
- Строковое значение: 255; описание параметра: 1023; строка <= 100 символов, одно уравнение.

## Защита деления (обязательно)
RATE = (G * d^4) / (8 * max(D^3, 0.1) * max(n, 0.5))
