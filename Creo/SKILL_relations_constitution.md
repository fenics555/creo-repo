# КОНСТИТУЦИЯ RELATIONS (обязательна для любого кода)

## Строки и синтаксис
1. Строка <= 100 символов. Длиннее - дробить на промежуточные параметры того же префикса.
2. Одно уравнение на строку. Никаких ";".
3. Степень только "^"; функции pow() НЕТ.
4. Округление до 0.1: floor(x*10+0.5)/10; целые - ceil/floor.
5. Все деления через max(знаменатель, эпсилон).
6. Логика: & | ! (не &&).

## Имена и блоки
7. Имя блока = префикс ВСЕХ его параметров (INPUT_, SPLAV_, CONST_, HYDRO_, ST_, SHL_, PIT_, MODUL_, DEF_, EXO_, PRIB_, CHILL_, FORM_, TAU_, TO_, AUDIT_, ECO_).
8. Всё, что задаётся - первым блоком в INPUT_, у КАЖДОГО параметра описание /* ... */.
9. Константы - только в CONST_.
10. Только латиница, верхний регистр, цифры, "_". Кириллица запрещена.
11. Строго: *_RASCHETN (расчёт) / *_FACT (исполнительный КД). Близнецов без нужды не плодить.
12. Мёртвые параметры удалять сразу.

## Порядок
13. Relations исполняются СВЕРХУ ВНИЗ. Блок использует только INPUT_/CONST_/префиксы РАНЕЕ идущих блоков. Ссылок вперёд нет.
14. После вставки - две регенерации подряд: значения обязаны совпасть (иначе где-то ссылка вперёд).

## Коэффициенты и вердикты
15. Происхождение помечать: [BOOK] книга / [CALC] вывод / [EMP] эмпирика. Калибровать только [EMP] по реальным отливкам/деталям.
16. Вердикты - строками *_VERDICT_TEXT, читаемы ОТК без расшифровки.
