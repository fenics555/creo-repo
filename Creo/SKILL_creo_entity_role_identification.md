# SKILL: Creo Entity Role Identification (Internal Linkage Principle)

## ⚠️ ВАЖНО: ПРИНЦИП "ИМЯ — ЭТО ЛОЖЬ"
Никогда не классифицируйте файл Creo на основе его имени (`_Z`, `_O`, `_MSTR` и т.д.). Имена могут быть любыми и не отражают суть. 
**Единственный источник истины — внутренние бинарные связи внутри UGC-контейнера.**

## 🔍 МАТРИЦА ИДЕНТИФИКАЦИИ (Detection Matrix)

Для определения роли сущности в PLM-графе, анализируйте следующие бинарные признаки:

| Роль сущности | Бинарные маркеры / Признаки (Evidence) | Где искать |
| :--- | :--- | :--- |
| **Конструкторская деталь (Base Part)** | Наличие связи `NeuPrtSld -> Base_Part` или отсутствие признаков заготовки/отливки. | `LargeText` (строковый пул) / `FeatDefs` |
| **Деталь-заготовка (Preparation/Z)** | Наличие признаков `Merge` / `Inheritance` (наследование геометрии) и наличие технологических припусков в параметрах. | `FeatDefs` (связи родителей) / `LargeText` |
| **Деталь-отливка (Casting/O)** | Наличие параметра `PTC_SHRINKAGE_FACTOR` (коэффициент усадки) или упоминание `Casting` в контексте массы/объема. | `BasFullData` / `LargeText` |
| **Мастер-модель (Master Model/MSTR)** | Наличие признаков `Parting Line`, `Draft` (уклоны) и `Core Print` (стержневые знаки) как управляющих элементов. | `AllFeatur` / `FeatDefs` |
| **Техпроцесс / Сборка ЧПУ (CAM/ASM_MFG)** | Наличие секций `FullMData`, `ASSEM_MFG` и параметров резания (скорость, подача, инструмент). | `TOC` (наличие секций) / `FullMData` |

## 🛠️ АЛГОРИТМ ПАРСЕРА

1.  **Load TOC**: Определить доступные секции.
2.  **Scan LargeText**: Вытащить все строки. Искать ключевые токены: `Base_Part`, `Shrinkage`, `Draft`, `Merge`.
3.  **Scan FeatDefs**: Проверить дерево зависимостей. Если фичер является "наследником" (Inherited) другого фичера — это признак заготовки.
4.  **Cross-Check**: Сопоставить найденные токены с найденными связями в `FeatDefs`.
5.  **Assign Role**: Присвоить статус только после подтверждения минимум одного бинарного признака.

## ❌ ЧТО НЕЛЬЗЯ ДЕЛАТЬ
*   ❌ Считать файл заготовкой, если в имени есть `_Z`.
*   ❌ Считать файл деталью, если в имени нет префиксов.
*   ❌ Доверять структуре папок на диске.
