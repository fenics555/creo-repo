# ТИПЫ ФИЧ И ДЕРЕВО ПОСТРОЕНИЙ — ЧТЕНИЕ ИЗ ФАЙЛА

## ✅ FEATTYPE ЗАКРЫТ: тип лежит в файле, на английском

Внутри записи фичи рядом с русским именем операции идёт её **внутренний код**:

```
dtmplane       DTM1
cutextrude     ВЫТЯГИВАНИЕ 1
featround      СКРУГЛЕНИЕ 1
```
Полные русские имена операций в этом же файле:
`ВЫТЯГИВАНИЕ 1`, `СКРУГЛЕНИЕ 1`, `СКРУГЛЕНИЕ 12`, `ВРАЩЕНИЕ 1`, `ОПОРНАЯ ПЛОСКОСТЬ`,
`Тело 1`, `Окно Фрезерования 1`.

Служебные поля дерева: `typed_data(TypedGrpCreateData)`, `created_groups`,
`header_id`, `feat_ids`.

**Вывод:** `CREOSON feature:list` даёт русифицированные типы (`ОПОРНАЯ ПЛОСКОСТЬ`,
`Отраженный ЗАГОЛОВОК ГРУППЫ`), а **оригинальные коды — в самом файле**.

## ✅ ДЕРЕВО ПОСТРОЕНИЙ читается текстом

Проверено на `137_011_0041.prt.1` (строка 47725 файла при чтении как текст):
```
ВРАЩЕНИЕ 1
ВЫТУП id 196
dtmplane DTM1
ОПОРНАЯ ПЛОСКОСТЬ id 199
ВЫТЯГИВАНИЕ 1
СКРУГЛЕНИЕ id 318
featround СКРУГЛЕНИЕ id 318
```

## ⛔ МАССА: значения РАЗНЫЕ В РАЗНЫХ РЕВИЗИЯХ

Это окончательный ответ на 11 опровергнутых гипотез о формате числа.
В файле лежат **три записи `PRO_MP_MASS` с РАЗНЫМИ байтами** — по одной на ревизию:
```
ревизия 1:  PRO_MP_MASS  ?8 9e 2?
ревизия 2:  PRO_MP_MASS  = 2? - a
ревизия 3:  PRO_MP_MASS  2- V } r N
```
То есть Creo **пересчитывает** массу и не хранит IEEE-754. Правила «ведущий байт
= 0x40/0x3F/0x41» не существует — потому что нет фиксированного числа.
**`volume`/`area` остаются `null` — и это не незнание формата, а отсутствие
константы в файле.**

## 📖 КАК ЧИТАТЬ: НЕ ПРОГРАММАМИ

Файл `.prt` **читается как текст** — достаточно:
```powershell
Select-String -Path <файл> -Pattern 'PRO_MP_MASS' -Encoding ascii
```
```python
# или просто
print(open(path,'rb').read()[:2048].decode('ascii','replace'))
```
`read_files` / `Get-Content` видят файл построчно и показывают кириллицу, имена фич
и типы. Это быстрее и надёжнее любых регулярок по байтам.

## ❌ ЧТО ДЕЛАТЬ НЕЛЬЗЯ

Искать фичи маркерами `E3`, `01 00`, `18 E5` по всему файлу — 11 гипотез подряд
упали именно так: захватывается **бинарная геометрия**, а не текст.
Ориентир: если в байтах есть `7F`, `CC`, `AA`, `D0 11` (невалидный UTF-8) —
это уже не текст, дальше искать бессмысленно.
