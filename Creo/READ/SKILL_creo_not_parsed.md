## 📌 ПРАВИЛА РАБОТЫ С ЭТИМ РЕЕСТРОМ
```
1. НИЧЕГО не отбрасывать: всё — в `unknown_fields` (уже собирается: 3013 полей!).
2. Разобрал пункт → УБРАТЬ из реестра + добавить читатель в сканер.
3. Приоритет: ①-② (положение/габариты — нужны ПЛМ) → ⑧ (физика) → ④⑦ (ЧПУ).
4. Проверять ТОЛЬКО сверкой с эталоном (Creo/J-Link), не подбором.
```

## 🎯 ЧТО ЭТО ДАЁТ (потенциал)
| Пункт | Ценность для ПЛМ |
|---|---|
| **matrix** | **сборка**: где какая деталь стоит (3D-положение!) |
| **outline** | **габариты** деталей (упаковка, транспорт) |
| **cg/inertia** | **физика** (расчёт, балансировка) |
| **ЧПУ (4,7)** | **технология**: операции, траектории, инструменты |
| **Xsections** | **чертёж**: сечения |
| **FamilyInf** | **исполнения** (типоразмеры) |
