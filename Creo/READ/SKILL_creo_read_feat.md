## 0.1. ВСКРЫТЫЙ ЗАКОН ПОЛЯ (это база всего разбора)

```
<tag e0…ff> <тип> <имя_поля>\0 <значение…>
```
* `тип 01` → 1 байт (id/флаги) · `тип 0a` → **строка** (имя!) · `тип 02` → число/упакованное · `тип 00` → ссылка.
* **Имя операции = строковое поле `name` / `feat_name` / `object_name` / `long_name` с типом `0a`.**
  Это и есть причина прежних «0 операций»: искали ASCII-маркеры `Extrude`/`Sketch` — их в файле **нет вовсе**,
  тип операции хранится **не текстом**.
* Парсер: `re.finditer(rb"[\xe0-\xff][\x00-\x0f]([A-Za-z][A-Za-z0-9_/\.]{1,60})\x00", chunk)`.
* ⚠️ **Баг проб, стоивший времени:** `section("FeatDefs")` матчится с `#FeatDefsIndex` → срез секции неверный.
  Искать маркер **точно**: `\n#Имя[\r\n]`. Плюс база отсчёта = маркер + `len(имя)` + 1.

## 3б. ✅ ID ОПЕРАЦИЙ ЛЕЖАТ РЯДОМ С ИМЕНЕМ (проверено на 2 моделях)
