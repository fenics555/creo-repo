# ИСТОЧНИКИ ГЕОМЕТРИИ В ФАЙЛЕ CREO (направление, v0.1, 29.10.2026)

> **Создан по слову владельца (29.10.2026):** «`SolidPrimdata` — дай в скиллах как новое направление».
> Это **карта направления**, а не результат: где искать геометрию и **какая она по точности**.

## 0. 🔴 ГЛАВНОЕ ДЕЛЕНИЕ: ДВА РАЗНЫХ КЛАССА ГЕОМЕТРИИ

| Класс | Что это | Где лежит | Точность |
|---|---|---|---|
| **ТЕССЕЛЯЦИЯ** | треугольные полосы (triangle strips) для **отображения** | **`SolidPrimdata`** | **приближение** — НЕ для размеров |
| **ПРОТОТИПЫ поверхностей** | шаблоны поверхностей, из которых ядро собирает тело | **`VisibGeom`** / `NovisGeom` / `Geomlists` / `GeomDepen` | **точная** (B-rep ядра) |

**⇒ Правило: `SolidPrimdata` = ВИЗУАЛИЗАЦИЯ. Для точных размеров/допусков НЕ использовать.**

## 1. `SolidPrimdata` — ТЕССЕЛЯЦИЯ (замер + источник)

**Статус:** в файле секция **есть** (замер: `052401-model-master.prt.1` — см. §3), назначение —
**display tessellation** («triangle-strip position arrays»).

**Что даёт:**
- быстрый **габарит** (bbox) по вершинам;
- быстрый **грубый анализ формы**, коллизии «на глазок»;
- **превью/карточка** модели (именно под это в ПЛМ уже есть `db\media\<sha>.jpg`).

**Чего НЕ даёт:**
- точных размеров (отклонение тесселяции от поверхности не контролируется);
- диаметров, радиусов, допусков;
- NURBS-параметров поверхностей.

**⚠️ ОБЯЗАТЕЛЬНО в отчётах:** если число/размер получены из тесселяции — **помечать «приближённо»**.

## 2. ТОЧНАЯ ГЕОМЕТРИЯ — где её искать

**Замер (карта секций, `SKILL_creo_tree_jlink_etalon.md`): 44 секции.** Геометрические:
```
SolidPrimdata  — тесселяция (отображение)
VisibGeom      — видимая геометрия (Sld_VisGeom → active_geom → srf_array)
NovisGeom      — НЕвидимая геометрия (Sld_NonVisGeom → inactive_geom → srf_array)
Geomlists      — списки геометрии
GeomDepen      — зависимости геометрии (topol_state, last_regen_feat_id)
AllFeatur      — топология (p_srf, srf_id, edges, contours) — «не дерево фич» (§4в)
```

**Что уже читается из `srf_array` (замер, фаза 7):**
```
geom_id · geom_type · feat_id · orient · boundary_type · next_geom_ptr
```
`geom_type` — 8 значений (34 → 882 из 1036) — **вид поверхности**, но **что за вид — не сверено с Creo**.

**⇒ Правильный путь к точной геометрии:** либо **Creo Toolkit / J-Link** (ядро отдаёт поверхности),
либо **сборка прототипов** (`VisibGeom`) — **задача открыта**.

## 3. КАК ПРОВЕРЯТЬ (команды дома)

```powershell
# есть ли секция и сколько места занимает
$p='<файл.prt.1>'
$raw=[IO.File]::ReadAllBytes($p)
[Text.Encoding]::ASCII.GetString($raw) -split "`n" | Select-String '^#SolidPrimdata'
```
**Замер для опоры:** `052401-model-master.prt.1` (2 149 680 Б) — секция `SolidPrimdata` присутствует;
для сравнения `ctkd_015_23_001_mill_turn.asm.1` (519 429 Б) — 75 секций, `SolidPrimdata` есть.

## 4. ГРАНИЦА ЗНАНИЯ (честно)

1. **Точная геометрия из байтов — НЕ читается** (не разобраны прототипы поверхностей).
2. **Размеры `dN` из байтов — НЕ читаются** (IEEE-754/float32/текст = 0 совпадений).
3. **Габарит через `pfcBBox` — недоступен** (`pfcBBox` нет в `pfcasync.jar` Creo 12/13) ⇒ Web.Link.
4. **`geom_type` → вид поверхности** — 8 значений есть, расшифровки нет.
