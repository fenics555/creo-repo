# ИЗВЛЕЧЕНИЕ ГЕОМЕТРИИ (GEOM-EXTRACTION)

Процесс получения точных инженерных данных из бинарного файла Creo.

## 1. Методы извлечения

### 1.1. Контекстный метод (Feature-Adjacent)
Самый быстрый способ получения параметров, привязанных к конкретному признаку.
1. Найти в файле строку-идентификатор (например, `feat_defs_916`).
2. Просканировать окно (порядка 512 байт) сразу после идентификатора.
3. Искать последовательности 8-байтовых IEEE 754 Double (`>d`).
4. **Важно**: Применять фильтр валидности (исключать NaN, Inf и аномально большие/малые числа).

### 1.2. Метод Geomlists (Deep Scan)
Более глубокий метод для извлечения всех геометрических координат и параметров.
1. Найти смещение секции `Geomlists` через TOC.
2. Читать данные секции.
3. Сопоставлять найденные координаты с признаками через `GeomDepen` (зависимости).

## 2. Критерии валидности (Filtering)

При парсинге чисел необходимо использовать фильтр:
- **Тип**: `float64` (Double).
- **Диапазон**: $|val| \in [10^{-12}, 10^{15}]$ (типичные инженерные значения).
- **Чистота**: Исключать `math.isnan(val)` и `math.isinf(val)`.

## 3. Инструментарий

- `creo_toc_parser.py`: Для навигации.
- `creo_geom_extractor.py`: Прототип контекстного поиска.
