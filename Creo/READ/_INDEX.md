## 📌 ИТОГ ФАЗЫ 03.10.2026 — ЧТО НАУЧЕНО (читать перед любой задачей по чтению)

### Закон поля исправлен (было неверно!)
```
<маркер e0…ff> <КОД ТИПА> <имя_поля>\0 <значение…>
```
⚠️ **Второй байт — КОД ТИПА, а НЕ длина имени.** Замер на 2 797 полях:
«код == длина имени» совпало **14 раз** (случайно), «код == длина значения» — **0 раз**.
| Код | Полей | Что за поля | Форма значения |
|---|---|---|---|
| `E0 01` | 1401 | `type`, `id`, `feat_id` | ссылки/ID: `84 <b>`, `F6`, `F8` |
| `E0 00` | 888 | `gen_info`, `matrix` | структуры/указатели |
| `E3 02` | 773 | имена записей | имена |
| `E0 02` | 437 | `local_sys`, `radius` | числа/матрицы |
| `E0 0A` | 195 | `name`, `description` | **строки** |

✅ Подтверждено на **3 моделях** — устойчивая особенность формата, не случайность.

### ⚠️ ПОЛЯ-СХЕМА ≠ ДАННЫЕ (главное открытие фазы)
Ключевые имена (`feat_name`, `ft_type`, `feat_type_ptr`, `feattype_key`, `sort_feat_ids`,
`parchild_table`) встречаются **ровно 1 раз на файл** — это **описание структур**,
а не данные фич. Данные лежат **позиционно, без имён**.

### ✅ Что читается (доказано на байтах + справкой Creo)
* Дерево верхнего уровня: `PLANES`, `QUILTS`, `SOLID`, `AXES`, `NOTES`, `DTM1…3`, `A_1…3`
* ID объектов — **2 байта**, диапазон `0x84xx`–`0x8Bxx`
* Коды категорий: `05` = база данных, `15`(21) = ось, `19`(25) = `DEFAULT`
* Имена фич: `Вытягивание`, `Эскиз`, `Отверстие`, `Сечение`, `СКРУГЛЕНИЕ`, `Габарит`
* `f8 <N>` = **счётчик элементов** (доказано 3 якорями), **НЕ** длина в байтах
