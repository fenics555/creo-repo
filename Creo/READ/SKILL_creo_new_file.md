# СОЗДАНИЕ / ПЕРЕЗАПИСЬ ФАЙЛА ДЕТАЛИ И СБОРКИ — ПОДГОТОВКА

**Статус: подготовительная карта. Ничего не создано и не перезаписано.**
Слово владельца на запуск: «готовимся к записи / перезаписи / создании с нуля нового файла детали/сборки».

## 1. ЧЕСТНЫЙ ВЕРДИКТ ПО СПОСОБУ
| Способ | Вердикт | Почему |
|---|---|---|
| **Через Creo (CREOSON/JLINK) от шаблона** | ✅ **рабочий путь** | `file:open` шаблона → правка параметров/отношений → `file:save` под новым именем; шаблоны дома уже канонизированы |
| **Копированием файла на диске + правкой в лоб** | ⚠️ **только для заполнения параметров**, длина текста та же | геометрия/фичи остаются от шаблона — это нормально для «новой детали по КБ-канону» |
| **Создание бинарника Creo с нуля** | ❌ **невозможно/не нужно** | формат не документирован; риск без отката |

**Вывод:** «новая деталь/сборка» = **копия шаблона + заполнение параметров/отношений**, а не синтез файла.

## 2. ШАБЛОНЫ ДОМА (канон)
| Канон (репо) | База | `ТИП` | Рабочий шаблон |
|---|---|---|---|
| `KB_part.prt` | `mm_part.prt` | Деталь | `Z:\PTC\CREO-START\НАСТРОЙКИ\ШАБЛОНЫ\` |
| `KB_sheet.prt` | `mm_sheet.prt` | Деталь (лист) | там же |
| `KB_asm.asm` | `sborka_mm.asm` | Сборка | там же |
| `KB_drawing.drw` | `c_drawing.drw` | — | там же |
| `MY_ESKD.dtl` | (текст) | настройка чертежа | там же |

⚠️ Шаблоны лежат на `Z:` — **только чтение**. Значит: копию шаблона сначала делаем в `PROBA`,
работаем там, готовый результат отдаём владельцу (сам он переносит в `Z:`) — либо пишем по его слову.

## 3. ОБЯЗАТЕЛЬНЫЕ ПАРАМЕТРЫ НОВОЙ МОДЕЛИ
```
rel_model_name = "<ШИФР>"     /* канон; легаси-синонимы ОБОЗНАЧЕНИЕ/shifr — не заводить */
МАТ_MARK = "Ст45 ГОСТ 1050-2013"
ТИП = "Деталь"                 /* деталь | Сборка | Стандарт | Покупное */
TPL_SOURCE = "KB_part"         /* свидетельство о рождении; нет → покупное */
MASS = MP_MASS                 /* кг, БЕЗ округления */
```
Ещё по `SKILL_naming_spec.md`: шифры `БДФ.ххх.ххх`, `АЛ-1110-…`, `ПТР-401-…`, `МК-262`, `ВГМ хххх.00.00`;
папки `000_NN Название`; чертёж переименовывается вместе с моделью.

**Проверка перед выдачей:** имя = шифр без пробелов · 4 параметра + `TPL_SOURCE` на месте · `MASS > 0` ·
`ТИП` не противоречит `TPL_SOURCE` (иначе флаг «проверь тип», не молчать) · дата дд.мм.гг, допуски ISO medium.

## 4. ПОРЯДОК СОЗДАНИЯ (план)
1. Скопировать шаблон в `PROBA\<имя>\` под **уникальным** именем.
2. Поднять Creo через `CREO-START.bat` (CREOSON подключается **только** к сессии, запущенной через него).
3. `connection:is_creo_running` → `connection:connect` → `creo:cd {dirname}` → **`file:erase`** (обязательно!)
   → `file:open` → **сверить `data.dirname`** (иначе писали не туда).
4. `parameter:set` по одному параметру с паузой ≈1.5 с (батч → `Pro/TOOLKIT General Error`).
5. `file:relations_set` (минимум отношений — `SKILL_relations_constitution.md`) → `file:regenerate` (×2 подряд,
   значения должны совпасть — иначе ссылка вперёд) → `file:save`.
6. Чертёж: `drawing:create`/копия → `drawing:regenerate` → сохранить **после** модели.
7. **Приёмка:** перечитать сохранённый файл «в лоб» (`plm_reader --folder PROBA\<имя>`) и убедиться, что
   параметры/объём/история на месте.
