## 🔴 ГЛАВНОЕ: МАССА ЛЕЖИТ НЕ В `PRO_MP_MASS`!

**`PRO_MP_MASS` — «схемное» значение** (не совпадает с реальным: даёт `0.00023` вместо `0.0234`).

**Реальные свойства — в секции:**
```
mass_prop_data → p_mp_report_data → mass_prop:
   type · density · init_dens · rel_density · aver_density · vrevnum
   volume · cg · inertia · eps · surfarea · csys_id
```

## 🔑 ФОРМУЛА (доказана)

```
<имя поля>\x00 [байт-тип] <7 байт>   →   double = lead + 7 байт

   volume   00 2D <7 байт>  →  lead 0x40  →  мм³       (пример: 71302.31634914603)
   surfarea 00 2D <7 байт>  →  lead 0x40  →  мм²       (пример: 13515.773731477759)
   density  00 23 <7 байт>  →  lead 0x3E  →  кг/мм³    (пример: 7.85e-06 = СТАЛЬ)
```

**АЛГОРИТМ:** перебрать `lead ∈ {0x40, 0x3E, 0x3F, 0x41, 0x3D}` → взять попадающее в диапазон:
- объём/площадь: `1 … 1e8`
- плотность: `1e-9 … 0.1` (кг/мм³)

## 🔴 МАССА НЕ ХРАНИТСЯ — ВЫЧИСЛЯЕТСЯ

```
МАССА = volume × density
```
**Проверка (`ctkd_015_23_001.prt.1`):**
```
volume  = 23440.87646024 мм³
density = 7.85e-06 кг/мм³  →  ×1e3 = 7.85 г/см³
МАССА   = 23440.87646024 × 7.85e-06 = 0.0234408764602364  кг
★ ЭТАЛОН J-Link #PARAM MASS = 0.0234408764602364  — СОВПАЛО 16/16 ✅
```

## 🔴 ПОЧЕМУ `PRO_MP_MASS` «РАБОТАЕТ В CREO», НО НЕ ЧИТАЕТСЯ ИЗ ФАЙЛА

**Владелец (30.10.2026):** «`PRO_MP_MASS` — я через неё во всех файлах массу вывожу в Creo!»

**Разгадка (замер):** в записи `PRO_MP_MASS` **НЕТ значения массы**:
```
PRO_MP_MASS\x00 = f5 eb 7e d5 28 00
   e3 32 f7 2e  6c e9 40 97 e8 60 1c  f7 1d    ← «схемные» числа (0.7891 / 51716) — НЕ масса
   e3 32 6c e9 40 97 e8 60 1c         f7 1e    ← дубль
   f8 01 f7 20 fb e3 f7 21 06 e3 88 00 00 e1   ← ★ ССЫЛКА (как §65: `*_ptr` = ссылка!)
```
**⇒ `PRO_MP_MASS` в файле — ССЫЛКА/СХЕМА**, а не число (ровно как `mass_prop.mass` в §65).

**Почему в Creo работает:** Creo **ВЫЧИСЛЯЕТ** `PRO_MP_MASS` из `mass_prop` (объём × плотность)
**при выводе** — параметр **производный**, в файле хранится только **вход**.

**⇒ ЕДИНСТВЕННЫЙ источник массы в файле = `mass_prop.volume × mass_prop.density`.**
