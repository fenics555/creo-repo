# SKILL: ИЗОЛИРОВАННАЯ РАСПАКОВКА (CREO TO TREE)

## 1. НАЗНАЧЕНИЕ
Этот скилл предназначен для создания **полной, неизменной карты байтов** файла Creo в формате JSON. В отличие от классических парсеров, этот инструмент не пытается "угадать" значения, если они не доказаны, а сохраняет всё содержимое (включаing неразгаданные теги вроде `f6`) в виде `raw_hex`.

## 2. ИНСТРУМЕНТ
`D:\AI\PROBA\creo_to_tree.py`

## 3. ПРИНЦИПЫ РАБОТЫ
1. **Секционирование:** Файл разбивается на физические секции `#SectionName` на основе `uint16` длин.
2. **Покрытие 100%:** Все байты между маркерами (gaps) или внутри секций, не попавшие в известные типы, сохраняются как `raw_block`.
3. **Типизация (строго доказанная):**
   - `e1 e0` $\to$ Словарь полей (dict_entry).
   - `e1 f1` $\to$ Граница схемы (boundary).
   - `e1 e1` $\to$ Конец записи (end).
   - `f7 <idx>` $\to$ Связка индекса (index_link).
   - `ed <double>` $\to$ Число (double).
   - `e3` $\to$ Разделитель (separator).
   - `f6` $\to$ Технический тег (tag).
4. **Безопасность:** Скрипт работает в изолированном режиме и не меняет исходный файл.

## 4. ПРИМЕР ВЫВОДА (JSON)
```json
{
  "name": "VisibGeom",
  "offset": 12345,
  "len": 500,
  "content": [
    {
      "type": "dict_entry",
      "tag": "e1e0",
      "field_type": "0xe0",
      "name": "color_prop",
      "offset": 12345,
      "len": 12
    },
    {
      "type": "tag",
      "tag": "f6",
      "offset": 12357,
      "len": 1,
      "raw_hex": "f6"
    }
  ]
}
```

## 5. КОГДА ИСПОЛЬЗОВАТЬ
- Когда текущий парсер (inspector) выдает ошибки смещения.
- Когда нужно увидеть "грязные" байты (f6, технические маркеры), которые мешают логике.
- Для верификации целостности файла (сумма длин секций должна быть $\approx$ размеру файла).
