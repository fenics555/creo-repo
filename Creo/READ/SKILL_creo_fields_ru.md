## 🔥 ЗНАЧЕНИЯ ФИЗИЧЕСКИХ ПОЛЕЙ ЧИТАЮТСЯ (замер 30.10.2026)

### `matrix` — **МАТРИЦА ПОЛОЖЕНИЯ КОМПОНЕНТА В СБОРКЕ**
```
matrix\x00  f9 04 04   c2 d8 82 3f 3a f2 24 28 b3 33 3b 75 3d 8e ee 4b …
↑ маркер    ↑↑↑↑↑↑↑
            f9 = маркер массива
            04 04 = 4 × 4 (матрица 4×4!)
            далее — ЗНАЧЕНИЯ (float/двойные)
```
**⇒ ПОЛОЖЕНИЕ + ПОВОРОТ детали в сборке — ЧИТАЕТСЯ!**
Тот же формат, что `cg`/`inertia` в `mass_prop` (`f9 03 …` — 3 значения).

### `outline` — **ГАБАРИТ (мин/макс по X, Y, Z)**
```
outline\x00  f9 02 03   48 3e 00 e4 | 2e 33 ff 2f 3e 00 e4 …
↑ маркер     ↑↑↑↑↑↑↑
             f9 = маркер · 02 03 = 2 × 3 (две тройки: min и max!)
```

### `view_id` · `page_id` — **ЧЕРТЁЖ (вид/лист)**
```
view_id\x00 00        ← ID вида
page_id\x00 00        ← ID листа
```

### ФОРМАТ МАССИВОВ `f9 <строк> <столбцов>`
| Маркер | Что |
|---|---|
| **`f9 04 04`** | матрица **4×4** (положение/поворот) |
| **`f9 02 03`** | **2×3** (габарит: min + max) |
| **`f9 03 …`** | вектор из 3 (cg, inertia, coord) |
| **`f9 04 …`** | …

**⇒ `f9 <N> [<M>]` — размерность массива ЧИТАЕТСЯ → значения извлекаются точно.**

**В ПОЛЯХ — САМОЕ ЦЕННОЕ.** Нельзя отбрасывать «непонятное поле»:
`matrix`, `outline`, `view_id` — это **положение, габариты, чертежи** (данные ПЛМ!).
**Все поля — в `unknown_fields`, с переводом и разбором.**

### ТЕКСТ ОПЕРАЦИИ ЧПУ
```
cl_text\x00 e3 e0\ncl_text\x00 e1 f2 f7 03 e3 0e "CENTROVKA"\x00
custom_cl_text\x00  ← пользовательский
```
**⇒ `cl_text` = ИМЯ (произвольное!)** — «CENTROVKA», «T0011» и т.п.
