## 🔑 МОДЕЛЬ УНИКАЛЬНОСТИ (3 уровня)

```
┌─ ИЗДЕЛИЕ (item_key = folder + '\' + model)   ← УНИКАЛЬНЫЙ КЛЮЧ
│     └─ ВЕРСИЯ (version = .prt.N → N)          ← история (.prt.1/.2/.3)
│           └─ ФАЙЛ (path, полный)              ← .prt / .asm / .drw (представления)
```

| Уровень | Ключ | Пример |
|---|---|---|
| **ИЗДЕЛИЕ** | `folder + model` | `...\CTKD-PSB-04\ctkd-psb-04-01` |
| **ВЕРСИЯ** | `version` | 2, 3, 4, 5 |
| **ФАЙЛ** | `path` | `...ctkd-psb-04-01.prt.3` |

## 📐 ЧТО ДОБАВЛЕНО В СХЕМУ
```
items (НОВАЯ):
   item_key TEXT PRIMARY KEY   -- folder + '\' + model (УНИКАЛЬНО)
   model · folder · n_files · n_versions · exts · last_mtime

ВО ВСЕ таблицы добавлено:
   folder   -- папка (РАЗНЫЕ ПАПКИ = РАЗНЫЕ ФАЙЛЫ!)
   version  -- номер версии (.prt.2 → 2)
   ext      -- тип (.prt/.asm/.drw/.mfg)
```

### 🔑 МОДЕЛЬ (уточнённая)
```
ИЗДЕЛИЕ (folder + base_name)  ← ОДНО!
   ├─ ПРЕДСТАВЛЕНИЯ: .prt · .asm · .drw · .pdf   ← разные файлы, ОДНО изделие
   ├─ ВАРИАНТЫ:      _old · _tmp · -z · _mfg-psb ← суффиксы (входят в имя!)

   └─ ДРУГИЕ ФОРМАТЫ: .dsn · .stk · .tph         ← НЕ Creo (но рядом!)
```
