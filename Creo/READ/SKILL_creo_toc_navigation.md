# НАВИГАЦИЯ ПО СТРУКТУРЕ CREO (TOC)

Для работы с любыми версиями Creo (от 6 до 12+) необходимо использовать динамический поиск смещений через таблицу содержания (TOC).

## 1. Основной механизм

В начале каждого файла Creo (.prt, .asm, .drw) содержится заголовок, включающий строку `#UGC_TOC`. Эта строка и последующие за ней записи определяют адреса ключевых блоков данных.

### 1.1. Алгоритм парсинга
1. Найти строку, начинающуюся с `#UGC_TOC`.
2. Читать последующие строки до первого маркера `#` или конца блока.
3. Каждая запись имеет формат: `[Имя_Секции] [Смещение_в_HEX] [Дополнительные_параметры...]`.
4. Сохранить результат в словарь `{ name: int_offset }`.

## 2. Ключевые секции

При поиске данных ориентироваться на следующие имена:
- `FeatDefsIndex`: Смещение начала записей признаков.
- `Geomlists`: Основной репозиторий геометрических данных.
- `GeomDepen`: Зависимости геометрии.
- `AllFeatur`: Список всех признаков.
- `BasFullData`: Полные данные базовых объектов.

## 3. Реализация (Python)

Используйте модуль `creo_toc_parser.py`:

```python
from creo_toc_parser import parse_creo_toc

toc = parse_creo_toc("path_to_file.prt")
geom_offset = toc.get("Geomlists")
if geom_offset:
    print(f"Geomlists starts at: {hex(geom_offset)}")
```

## 4. Важные замечания
- **НЕ ИСПОЛЬЗОВАТЬ** жестко заданные смещения (hardcoded offsets).
- **ВЕРСИОННОСТЬ**: Смещения меняются между версиями, но формат TOC остается стабильным.
- **ОШИБКИ**: Если TOC не найден, файл может быть поврежден или иметь нестандартную структуру (редко).
