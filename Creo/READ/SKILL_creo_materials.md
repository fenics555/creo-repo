# SKILL: МАТЕРИАЛЫ Creo 7.0+ — ВНУТРЕННИЙ `PTC_SYSTEM_MTRL_PROPS` (открытие 30.10.2026)

> **§176 в `SKILL_GRABLI.md`** · основано на **скриншотах владельца** (Creo 13) + замер 8 файлов
> **Слово владельца:** «нужно понимать, что **новый Creo завёл какой-то свой внутренний материал**
> и можно его **подхватить**».

## 🔴 ГЛАВНОЕ: У КАЖДОЙ ДЕТАЛИ Creo 7.0+ ДВА МАТЕРИАЛА

**Предупреждение Creo (скриншот):**
> *«Начиная с версии **Creo 7.0**, у любой детали имеется **материал контейнера со свойствами
> по умолчанию**. Он будет назначаться **во всех случаях, когда не назначен фактический материал**.
> О системном материале по умолчанию **не сообщается** в ведомости материалов, 3D-ведомостях».*

**Что видно в окне «Материалы» (модель `PTR-401-MT-01-02.PRT`):**
```
Материалы в модели:
   1. V-CH_50 (тел: 1)           ← ФАКТИЧЕСКИЙ материал (ВЧ-50 ГОСТ 7293-85)
      Плотность: 0.00001 кг/мм³
   2. PTC_SYSTEM_MTRL_PROPS      ← ⚠️ ВНУТРЕННИЙ (системный), плотность-пустышка
```

## 🔑 ФАКТЫ (замер)

| Факт | Значение |
|---|---|
| **`PTC_SYSTEM_MTRL_PROPS`** | есть в **КАЖДОМ** файле (10–15 вхождений) — Creo 7.0+ |
| **Имя фактического материала** (`V-CH_50`) | **в байтах файла ОТСУТСТВУЕТ** |
| **Плотность фактическая** | ✅ **в файле** (`mass_prop.density` = `7.85e-06` кг/мм³) |
| **Плотность системного** | **0.00001 кг/мм³** (пустышка) |

## 📐 СТРУКТУРА БЛОКА МАТЕРИАЛОВ (формат)

```
e3 <ИМЯ ПАРАМЕТРА>\x00  e2 3 <ЗНАЧЕНИЕ>\x00  f6 02 e1 e1 [f5 <ссылка-на-материал>]

PTC_MASTER_MATERIAL        = "65G_MMKGS"       ← ЕДИНИЦЫ (НЕ материал!)
PTC_UNITS_LENGTH/MASS/...  = "mm" · "kg" · ...
PTC_MATERIAL_TYPE          = 9 (i_val)
PTC_MATERIAL_SUB_TYPE      = "LINEAR"
PTC_FAILURE_CRITERION_TYPE = "NONE" · PTC_FATIGUE_TYPE = "NONE"
PTC_ASSIGNED_MATERIAL      = "PTC_MASTER_MATERIAL"   ← ★ ССЫЛКА (не имя!)
PTC_MATERIAL_DESCRIPTION   = "" (пусто) + ссылка PTC_SYSTEM_MTRL_PROPS
```

## 🔴 ПОЧЕМУ ИМЯ МАТЕРИАЛА НЕ В ФАЙЛЕ
**Материал живёт в БИБЛИОТЕКЕ Creo** (`Material Directory` → `Материалы общего вида` → `Сортамент`).
В файл пишется **только ссылка** (`PTC_ASSIGNED_MATERIAL → PTC_MASTER_MATERIAL` → id).

**⇒ Из файла читается:**
- ✅ **плотность** (реальная)
- ✅ **объём · площадь · масса** (вычисляется)
- ✅ **тип материала** (`PTC_MATERIAL_TYPE` = 9)
- ❌ **имя материала** — НЕТ (только в библиотеке или в пользовательском параметре)

## 📌 ЧТО ЭТО МЕНЯЕТ В ПЛМ
| Было | Стало |
|---|---|
| «материал = `PTC_MASTER_MATERIAL`» | ⚠️ это **ЕДИНИЦЫ** (`65G_MMKGS`), НЕ материал! |
| «материал не читается» | **плотность читается**, имя — из библиотеки/параметра |
| «плотность неизвестна» | ✅ **`mass_prop.density`** (7.85e-06 = сталь) |
| — | ⚠️ **`PTC_SYSTEM_MTRL_PROPS` — ФИЛЬТРОВАТЬ** (не материал!) |

## 🔴 ПРАВИЛА ФИЛЬТРАЦИИ (обязательно)
```
1. PTC_SYSTEM_MTRL_PROPS — НЕ материал (внутренний контейнер Creo 7.0+). Пропускать.
2. Плотность 0.00001 кг/мм³ (= 1e-05) — «пустышка» системного материала. НЕ брать как реальную.
3. Реальная плотность: 2.7e-06 (алюминий) · 7.85e-06 (сталь) · 7.2e-06 (чугун) · 8.5e-06 (латунь).
4. Имя материала — если в файле нет, брать из пользовательского параметра (если заведён).
```
