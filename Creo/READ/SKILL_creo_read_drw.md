# ЧЕРТЁЖ `.drw` — ЧТЕНИЕ «В ЛОБ»

Ядро — `SKILL_creo_read_core.md`.

## 1. ЖИВАЯ ПРИЁМКА (03.10.2026, `PROBA\23-1017GRI`, без Creo)
| Что | Факт |
|---|---|
| История | ✅ ревизия, дата, пользователь, компьютер, версия Creo |
| Число записей | ✅ бывает 0 (честно: копия без пересчёта), бывает 1200+ |
| Объём | ❌ **0 %** — и это **законно**: у чертежа своего объёма нет |
| Материал / наименование | ❌ 0 % (параметров в чертеже нет) |
| Обозначение | ❌ 0–7 «мусорных» — **обозначение живёт в штампе/формате**, не параметр (**долг №3**) |

Версии Creo встречаются от `4.0` до `Creo 12.4.2.0` — чертежи самые старые файлы в проектах.

## 2. ЧТО ВИДНО ВНУТРИ ЧЕРТЕЖА
`view_id`, `format_info`, `Dwg_Models`, `Dwg_MasterRep`, `model_name`, `sheet`, секция `DwgData`.
Связь **чертёж → модель** = `Dwg_Models` / `drawing:list_models` (нужна открытая модель в CREOSON).

## 3. РИТУНА «PDF РЯДОМ С ЧЕРТЕЖОМ»
Правило дома: рядом с `X.drw[.N]` лежит `X.pdf` **той же папки**; если PDF нет или он **старше** чертежа →
обновить. (Масштаб по `harvest.db`: 24 607 пар, 8 687 помечены «устарел».)
⚠️ **Зона:** на `Z:\PTC` — только чтение, значит **перепечать PDF там запрещена**;
инструмент `creo_pdf` запускать только с выгрузкой в `PROBA`.
Приёмка: `creo_pdf.bat scan <папка>` — отчёт без Creo; `export` — пишущая операция (нужен живой Creo + согласие).

## 4. ГРАБЛИ (из прыжков JLINK/CREOSON)
* **PDF/DXF/DWG/2D — только с ЧЕРТЕЖА.** На детали: `XToolkitInvalidType` / `XToolkitGeneralError`.
* PDF вдобавок требует `Model.Display()`, иначе `XToolkitNotDisplayed`.
* **Сборочный чертёж** (`X.drw` при наличии `X.asm`) по имени не открывается — `XToolkitNotFound`.
  Лечение: сначала поднять сборку `RetrieveModel(MDL_ASSEMBLY, "X")`, потом чертёж.
* Версионированное имя (`X.drw.1`) JLINK **не принимает** — открывать по базовому имени.
* После экспорта чертёж убирать из сессии (`Model.Erase()`), иначе окна Creo копятся.
* Creo **дописывает суффикс версии** к экспортам (`name.pdf` → `name.pdf.1`) — проверять по префиксу.
