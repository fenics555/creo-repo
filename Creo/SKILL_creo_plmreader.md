### 🔑 ТРИ ЖЕЛЕЗНЫХ ПРАВИЛА
1. **Каждый пишет ТОЛЬКО в свои таблицы.** Чужие — **только чтение**.
2. **Схему меняет ТОЛЬКО Database.** Остальные просят миграцию.
3. **Источник правды — ФАЙЛ (Z:).** База — производная, **пересобирается с нуля**.

**Почему:** если двое пишут в одну таблицу — **гонка, дубли, порча**. Это и была причина,
почему раньше «что-то доделывали отдельные скрипты» — **не было границы ответственности**.

### 🚩 ПРАВИЛО ДВУХ СКАНЕРОВ (переходный период)
Пока `engine.py` жив **и** новый сканер работает — **пишет в базу ТОЛЬКО ОДИН**.
Иначе — та же гонка. Переключение — **одним решением** (флаг в настройках).

### 📖 ЧТЕНИЕ `#UGC_TOC` (карта файла)
- **КАРТ `#UGC_TOC` ОТ 2 ДО 3** у каждого файла (грабля №6).
- Формат строки: `NN:0:<ИМЯ>:1 <off> <len> …` — **читается ТЕКСТОМ**.
- Парсить **по именам полей**, а не подбором чисел (§164: подбор дал 4 ложных вывода).

### 🔢 ЧИСЛА: три разных формата (не путать!)
| Формат | Где | Как читать |
|---|---|---|
| **`e3 32 [тип] [7 байт]`** | масса · объём · площадь · COG · инерция | double без старшего байта; lead по плотности металла (§167) |
| **`2F B1 B2`** | номиналы размеров | double `40 B1 B2 00 00 00 00 00` (§173) |
| **`f8 <N>`** | массивы | **N слов по 2 байта** (не байт!) |

### 🔤 КОДИРОВКИ
- **Текст** (имена моделей, параметры-строки) — **UTF-8** (кириллица читается).
- **Версия Creo** — `((?:Creo )?[0-9][0-9.]*)` (бывает `4.0`, `Creo 11.0.2.0`).
- **Раскладка A/B/C** — зависит от версии файла (см. `READ\SKILL_creo_read_core.md`).

### 6.2. БЕСШОВНОСТЬ: НОВЫЙ КОД — ОТДЕЛЬНЫМ БЛОКОМ
```python
# ═══ [V141-ВРЕМЕННО] ЧТО ЭТО ═══
# УДАЛИТЬ, когда <условие>. Причина, почему пока здесь: <...>.
# Куда переедет: <файл>.
```
**НЕ врезать в середину функции.** Новый код — **отдельным блоком / разделом / В КОНЦЕ файла**,
с меткой **что это** и **почему потом можно удалить**. ⇒ легко удалить = легко обновлять.

#### СЛОВАРЬ ТИПОВ — ВПИСАН В КОД (образец)
```python
# СЛОВАРЬ ТИПОВ ЭЛЕМЕНТОВ Creo (pfcFeatureType) — 314 значений. §171
# ИСТОЧНИК: pfcFeature.h (Creo 13.4.1.0, otk_cpp\include) — снято 30.10.2026.
# Словарь ВПИСАН В КОД: в рантайме файлы Creo НЕ читаются (ПЕРЕНОСИМОСТЬ!).
```

**Почему:** работает **без установленного Creo**, **мгновенно**, **переносимо**.
**Правило:** справочные данные (словари, таблицы, enum) — **в код**, с пометкой **ОТКУДА снято**.

### 6.7. ГРАБЛИ ПРАВКИ КОДА (мои, 30.10.2026)
