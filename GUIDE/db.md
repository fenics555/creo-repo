# БАЗЫ ДАННЫХ АГЕНТА
Четыре хранилища знаний плюс служебные; sqlite — data\agent.sqlite, трейлы и кэши — на диске.
1. Файловый индекс (таблица files): опись путей, дат, размеров всего просканированного.
   Пополняется: /scan («Скан 3D-моделей»), ночная задача scan. Проверяется: models_stats, models_find, db_state.
2. База знаний (чанки + векторы): справка Creo, скиллы, конвенции, нарезка ~900 символов,
   векторы nomic-embed-text (model_index). Пополняется: /rescan, ночная index.
   Проверяется: search_kb, index_state.
3. База связей (usage): пары «сборка → деталь» для where-used и полос состава.
   Пополняется: usage_build full=1 («Пересобрать где используется»), ночная usage.
   Проверяется: usage_state, models_where, /children. Ноль имён или корней при живых связях = ТРЕБУЕТ ПЕРЕСБОРА.
4. Трейлы: журналы сессий Creo на диске (trail_dirs) + TRAIL_JOURNAL.md в репо.
   Пополняются самим Creo; агент читает и сводит. Проверяется: trail_problems, trail_diagnose.
Служебные: история и feedback (метрики качества), users/config/prefs, pdfcache (миниатюры), backups (копии sqlite, глубина 7).
Одна команда обо всём: db_state (verbose=1 — полная выгрузка). В витрине — пространство «🗄 Базы данных»: состояние плюс три кнопки индексаций.
Болезни: «нет чертежа» у PDF-глаз = чертёж зовётся m-<имя>-… (m-префикс); латынь в поиске = чанки устарели; связи живы, корней ноль = пересбор.
