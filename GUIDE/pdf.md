# PDF-ГЛАЗА
pdf_pages name=<имя> — число страниц и свежесть: pdf_mtime против drw_mtime.
pdf_img name=<имя> page=N — миниатюра страницы, кэш data\pdfcache (ключ — mtime, dpi 80).
pdf_status — вердикт: актуален / УСТАРЕЛ / нет чертежа / нет pdf.
pdf_refresh — перепечать PDF из чертежа через CREOSON export_pdf; ПИШУЩАЯ, только [СОГЛАСОВАНИЕ].
Поиск пары: pdf по точному stem; чертёж по stem ИЛИ m-<stem>-… (m-префикс сборок).
В витрине: имена .prt/.asm/.drw в ответе становятся строкой миниатюр 84x60, бейджем вердикта,
кнопкой «🔄 Обновить PDF», лайтбоксом 3x (закрытие кликом мимо и ✕) и полосой состава сборки через /children.
Реестр: /pdfregistry — все пары drw/pdf с вердиктами, устаревшие первыми, лимит 500;
пространство «📄 PDF-РЕЕСТР»: таблица, фильтр «только устаревшие», пакетное обновление по сухому плану с подтверждением.
Болезни: «нет чертежа» = не нашёлся ни точно, ни по m-префиксу; кэш миниатюр самоинвалидируется по mtime;
Creo выключен = pdf_refresh недоступен, страницы и бейджи работают из файлов.
