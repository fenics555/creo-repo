## 2. Каркас — он действительно один
_03.10.2026, Cline_

Везде одна и та же пятёрка (проверено по 14 файлам):
```
class Win(App):  def __init__(self, root):
    root.title("V1 — <ЧТО ДЕЛАЕТ>")
    root.geometry("1020x620")
    root.minsize(900, 560)          # есть не везде
    self._style()                   # только в больших
    …сборка…
if __name__ == "__main__":
    r = tk.Tk(); App(r); r.mainloop()
```
Заголовок всегда с версией: `V1 — …` у большинства, `V2` у cmnm_scan и creo_export,
`V7 … дизайн 2` у creo_pdf. То есть **версия окна видна пользователю** — это осознанно.


## 3. Потоки — главный закон окон дома
_03.10.2026, Cline_

- Долгая работа **никогда** не идёт в главном потоке: `threading.Thread(target=work, daemon=True).start()`.
- Обратно в GUI — **только** через `self.root.after(0, …)` (десятки мест по дому).
  Пример из `dup_scan\gui.py`: `eng.find_dups(..., progress=lambda s: self.root.after(0, self.log, s))`.
- Вывод внешнего процесса качается очередью: `self.q = queue.Queue()` + поток `pump`,
  который перекладывает в виджет и крутит `root.after(900, self.refresh_state)` (copy-сервис).
- Исключения показываются в GUI, а не роняют окно: `root.after(0, lambda: messagebox.showerror(...))`.

**Вывод:** правило есть и соблюдается; но оно нигде не записано как закон для окон.

теме Windows. То есть дизайн дома = **системная тема + собственные константы цветов**,
и это де-факто стандарт, который никто не записал.

## 5. Обязательные элементы окна
_03.10.2026, Cline_

1. **Кнопка `README`** — во всех 15 окнах, одна и та же функция `show_readme()`: читает
   `README.md` рядом и выводит в лог окна построчно; при ошибке пишет «README не прочитан: …».
   Это проверка шаблона инструмента из дома — дёшево и работает.
2. **Кнопка `СТОП`** — где окно запускает процесс: `tk.Button(btns, text="СТОП", width=10,
   state="disabled", …)` (виден в `creo_pdf`, `creo_export`, `navigator`, `creo_comb`);
   состояние `disabled` включается только на время работы.
3. **Плашка состояния** — «готов»/«идёт…»/«ошибка» жёлтой подложкой `#fff1c7`.
4. **Поле лога/вывода** — `tk.Text`, только чтение для пользователя.
5. **Настройки — файлом** (правило дома, соблюдается): `settings\<имя>_settings.json`,
   версионируются `settings_version`, битый файл = `{}` без падения; миграция со старого имени
   файла — с копией в `backup_settings\` (см. `_load()` в `creo_pdf_gui.py`).
6. **Время работы и код возврата** пишутся в лог: `=== код возврата: %s за %.1f с ===`.
