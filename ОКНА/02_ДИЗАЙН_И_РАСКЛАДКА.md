белый/светло-серый = фон и логи. Ни одного «зелёного успеха» в доме нет — **пробел**.

## Рамки и отступы
- секции — `ttk.LabelFrame(text=" НАСТРОЙКИ ", padding=10)` — заголовок в ПРОБЕЛАХ (символ дома);
- кнопки — `st.configure("TButton", padding=(8, 4))` (только `creo_pdf`), отступы `padx=6..10, pady=4..6`;
- окно — `padding` задаётся точечно у виджетов, не корневым фреймом.

## Тема
- дом: **системная тема Windows**; `vista` включается только в `creo_pdf_gui.py::_style()`
  через `ttk.Style().theme_names()` с проверкой и `try/except`.
- Внешние GUI-библиотеки **не используются** (только tkinter из стандартной библиотеки) —
  это плюс: окно переносится копированием папки, без установки.

## Типы полей (как дома)
| Что | Виджет |
|---|---|
| один путь | `ttk.Entry` + кнопка «Обзор…» |
| список известных путей | `ttk.Combobox(values=…)` (`config_audit`) |
| число | `ttk.Entry(width=4..5)` |
| флажок | `ttk.Checkbutton` / `tk.Checkbutton` |
| таблица результатов | `ttk.Treeview(show="headings")` с `tag_configure` для цветов |
| лог | `tk.Text` (иногда `state="disabled"` + разблокировка на запись) |

## Смешивание tk и ttk
Дом **смешивает**: `tk.Label` для плашек с собственным цветом, `ttk.*` для остального.
Это работает, но в одном фрейме с `ttk.LabelFrame` внутри `tk` выглядит несогласованно
(разные шрифты заголовков). Правило на будущее: **внутри `ttk.LabelFrame` — только ttk**,
а `tk.Label` оставлять для плашек-статусов.

## Тексты в интерфейсе
- Заголовок окна: `V<номер> — <ЧТО ДЕЛАЕТ>` (версия видна пользователю);
- секции заглавными с пробелами: ` НАСТРОЙКИ `, ` ИСПОЛНИТЕЛИ `, ` ОТЧЁТ `;
- кнопки глагольные/командные: `Обзор…`, `Найти Creo`, `Применить`, `СТОП`, `README`;
- пояснения серым мелким: `«(столько же строк отдаёт поиск по фильтру)»`,
  `«(старые версии — в бэкап, удаления нет)»` — **пояснение всегда рядом с опасной кнопкой**.
