## ЧЕГО ДОМА НЕТ БЕЗ ЭТОГО СКИЛЛА
Ни одного скилла про окна в репо нет. Всё ниже — **выписано из живого кода** (факт),
а не придумано: каркас, цвета, шрифты и состав кнопок уже повторяются в 14 окнах,
просто это не записано. Скилл фиксирует практику и добавляет проверки.

## КАРКАС (обязателен)
1. bat-вход рядом: `cd /d "%~dp0"` + `start "" pythonw.exe gui.py`.
2. `if __name__ == "__main__": r = tk.Tk(); App(r); r.mainloop()`.
3. `root.title("V<номер> — <ЧТО ДЕЛАЕТ>")` — **версия видна пользователю**.
4. `root.geometry("WxH")` + **`root.minsize(...)`** (сейчас есть только у 2 окон из 14 — долг).
5. Порядок блоков: НАСТРОЙКИ → ИСПОЛНИТЕЛИ (кнопки + СТОП) → ОТЧЁТ (плашка + лог).

## ДИЗАЙН-КОНСТАНТЫ (факт из кода)
- логи: `tk.Text(font=("Consolas", 9), bg="#f8f9fa")` (второй вариант `#fbfbfb`);
- плашка состояния/предупреждения: `tk.Label(anchor="w", bg="#fff1c7", padx=8, pady=4)`;
- рамки-секции: `ttk.LabelFrame(text=" НАСТРОЙКИ ", padding=10)` — **заголовок в пробелах**;
- дерево: `ttk.Treeview(show="headings")` + `tag_configure`: сирота `#ffe3e3`,
  «в другом месте» `#fff8dc`;
- приглушённый текст: `foreground="#555"`/`"#666"`;
- сильное предупреждение: `bg="#fff1c7", fg="#856404", font=("Arial",10,"bold")`;
- тема: `ttk.Style()` + `vista`, если есть в `theme_names()`; `TButton padding=(8,4)`.
- **Смешение:** `tk.Label` — только для плашек со своим цветом; внутри `ttk.LabelFrame` — ttk.
- Размер окна: ориентир 1000×640; малые 820×520, большие 1320–1560 × 680–820.

## ЗАКОН ПОТОКОВ (главное)
1. Долгая работа — **только** в `threading.Thread(daemon=True)`.
2. В GUI — **только** `root.after(0, …)`. Прямое обращение к виджетам из потока — дефект.
3. Вывод процесса — `queue.Queue` + поток-насос (`pump`), опрос `root.after(900, …)`.
4. В лог — код возврата и время: `=== код возврата: 0 за 3.3 с ===`.
5. Исключение — в `messagebox` внутри `after(0, …)`, окно не падает.

## ОБЯЗАТЕЛЬНЫЕ ЭЛЕМЕНТЫ
- **README-кнопка** — в 14 окнах из 15 (это уже стандарт): читает `README.md` рядом,
  печатает в лог построчно, при ошибке пишет «README не прочитан: …».
- **Кнопка `СТОП`** — обязательна, если окно запускает процесс дольше секунды
  (`tk.Button(text="СТОП", width=10, state="disabled")`; `disabled` только на время работы).
- **Настройки — файлом**: `settings\<имя>_settings.json` + `settings_version`; битый файл = `{}`;
  миграция со старого имени — с копией в `backup_settings\`.
