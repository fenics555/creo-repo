# 01. СТРОЕНИЕ ОКНА ДОМА (по слоям)

_03.10.2026, Cline. Слои — снизу вверх; каждый слой можно заменить, не трогая остальные._

## Слой 0. Вход (bat)
Файл `<инструмент>_gui.bat` рядом с папкой инструмента. Два варианта, оба живут:
- `start "" pythonw.exe gui.py` — без консоли (у большинства);
- `title …` + `python …` + `if errorlevel 1 pause` — с паузой при ошибке (у `creo_pdf`).
Правило: bat только запускает, ничего не знает о логике.

## Слой 1. Точка входа Python
```
if __name__ == "__main__":
    r = tk.Tk(); App(r); r.mainloop()
```
Тот же `class App/Win`, что и везде. Имя класса в доме скачет (`App` / `Win`) — **это мелочь,
называть надо одинаково** (см. идеи).

## Слой 2. Каркас окна
`title` (с версией!) → `geometry` → `minsize` (для больших) → `_style()` → сборка блоков.

## Слой 3. Блоки интерфейса
Порядок сверху вниз (соблюдается везде):
1. **НАСТРОЙКИ** — `ttk.LabelFrame` с путями/полями и кнопками «Обзор…», «Найти»;
2. **ИСПОЛНИТЕЛИ** — кнопки действий + `СТОП`;
3. **ВЫВОД** — плашка состояния + `tk.Text` (или `ttk.Treeview` для таблиц).

## Слой 4. Данные
- Настройки — `settings\<имя>_settings.json`, `settings_version`, миграция с копией;
- настройки читаются **до** сборки интерфейса, значения кладутся в `tk.StringVar/BooleanVar`;
- битый JSON = `{}` и никакого падения (правило дома).

## Слой 5. Работа (потоки)
- `threading.Thread(daemon=True)` на всё, что дольше секунды;
- в GUI — только через `root.after(0, …)`;
- вывод процесса — `queue.Queue` + поток-насос `pump`;
- отмена — `terminate()`/`kill()` процесса + статус «процесс остановлен по кнопке СТОП»;
- в лог — код возврата и время: `=== код возврата: 0 за 3.3 с ===`.

## Слой 6. Отчёт и обратная связь
- лог в окне (Text) + копирование в буфер (`_clip_via_powershell` → запасной `_clip_tk`);
- отчёт на диск пишет **движок**, окно только показывает путь;
- ошибки — `messagebox`, а не traceback в консоль.

## Слой 7. Документация внутри окна
Кнопка **README** — обязательна: читает `README.md` программы и печатает в лог.
Фактически это «схема окна по нажатию».

## Что НЕ должно попадать в окно
- логика (она в движке `*.py`/`*.bat` — окно зовёт движок, а не делает работу);
- пути Creo в коде окна (ищет `creo_path.py` / `creo_pdf_env.py`);
- хардкод настроек (только через файл настроек).
