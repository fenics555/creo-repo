# ГРАНИЦЫ WEB И ВИЗИИ (честно, чтобы не выдумывать)

## WEB (web_fetch) — умеет
- Читает СТАТИЧЕСКИЕ HTML-страницы (документация, ГОСТ, справочники, форумы).
- gzip, кодировки utf-8 и cp1251, редиректы.
- Отдаёт текст без скриптов/стилей, до 6000 символов (save=1 — копия в repo/Web). Сырой ответ — до 2 МБ.

## WEB — НЕ умеет
- SPA на JS (React/Vue/Angular) — вернёт пустую страницу.
- Страницы за авторизацией/капчей (живой пример: Яндекс.Диск, логин GitHub).
- PDF/бинарники по прямой ссылке.
- «Страница пустая» — это не ошибка, а SPA: попросить сохранить локально, НЕ выдумывать.

## ВИЗИЯ — умеет
- Разбирает скриншоты через Ollama (qwen2-vl:7b) или llamacpp (8081).
- Скриншоты по юзерам: images/<login>, старше image_days (7 дней) удаляются.
- Разбирает ТОЛЬКО свой последний скриншот.

## ВИЗИЯ — правила и НЕ умеет
- НЕ выдумывать: визия недоступна → прямо сказать об этом.
- Не читать чужие скриншоты.
- Мелкий текст/сложные чертежи — с оговоркой, не утверждать категорично.

## Маршрутизация
- Ссылка http → web_fetch; пусто → попросить локальный файл, НЕ выдумывать.
- Картинка/скриншот → vision; недоступна → пометить, НЕ выдумывать.
