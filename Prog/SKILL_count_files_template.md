# ПОИСК ПО ДЕРЕВУ И ПОДСЧЁТ — ШАБЛОН (не считать глазами!)

## 0. МЕТОД РЕКУРСИВНОГО ПОИСКА (общий, для ЛЮБОЙ задачи по дереву)

> 🔴 **Правило дома: вопрос о дереве (`дом`, `репозиторий`, `папка`, `найти`, `все`) — это ЛЮБОЙ уровень
> вложенности.** По умолчанию считаем/ищем **рекурсивно** (`-Recurse`). Искать только в корне — ошибка.

| задача | флаг | почему |
|---|---|---|
| «сколько файлов в папке X» | **`-Recurse`** | дерево = все подпапки |
| «найти скилл/файл в доме» | **`-Recurse`** | файлы лежат в подпапках направлений |
| «показать содержимое папки X» (ровно корень) | без `-Recurse` | явно сказано «в корне» |

**Живая разница (замер дома):** `D:\AI\repo\Creo` — **65 файлов с `-Recurse`** против **5 без него**.
Разница в **13 раз**. Забыл `-Recurse` → число неверно, хотя команда «сработала».

**Если сомневаешься — используй `-Recurse` и в ОТВЕТЕ скажи:** «искал рекурсивно по всему дереву».

## 0.5. 🔴 ГЛАВНОЕ: ЧТО СЧИТАТЬ — ОБЪЕКТЫ НА ДИСКЕ, А НЕ УПОМИНАНИЯ В КАРТЕ

**Правило дома (владелец, 16.10.2026): если просят «сколько файлов / скиллов / моделей / сборок» —
это РЕАЛЬНЫЕ объекты. Их СЧИТАЮТ ИНСТРУМЕНТОМ, а НЕ вычитывают из карты/индекса/списка.**

| Что просят | ЧЕМ считать | ЧЕГО НЕ делать |
|---|---|---|
| **сколько ФАЙЛОВ / скиллов** (реальные) | `(Get-ChildItem '<папка>' -Recurse -File -Filter '<маска>').Count` | ❌ `Select-String SKILL_index.md` — это КАРТА, в ней упоминания ≠ файлы |
| **сколько СТРОК в файле** | `(Get-Content '<файл>').Count` | ❌ не путать с файлами |
| **сколько СОВПАДЕНИЙ в файле/дереве** | `(Select-String -Path '<файл>' -Pattern '<шаблон>' | Measure-Object).Count` | ❌ не считать папки (`-File`) |
| **сколько ПАПОК** | `(Get-ChildItem '<папка>' -Recurse -Directory).Count` | ❌ без `-Directory` попадут файлы |

**ЖИВОЙ ФАКТ (16.10.2026, тест 3):** модель на вопрос «Сколько скиллов в направлении Creo?»
выполнила `Select-String -Path 'SKILL_index.md' -Pattern 'Prog\SKILL_'` → посчитала **УПОМИНАНИЯ В КАРТЕ** → «20»,
а **на диске 18 файлов**. Вердикт `COUNT_WRONG` — и это **правильно**: спросили про файлы, ответила про карту.

**Признак карты:** файл-карта (`SKILL_index.md`, `INDEX.md`, `*.map`, README-список). Карта — **навигация**,
а не источник чисел. **Число — только из файловой системы.**

**Формулировка для ответа:** «посчитал файлы на диске: `<команда>` → N» (а не «нашёл в карте N упоминаний»).

## 1. ЗАКОН ПОДСЧЁТА В ОДНУ СТРОКУ

**Число берётся ТОЛЬКО счётчиком (`.Count` / `Measure-Object`). Считать строки в выводе ЗАПРЕЩЕНО —
вывод инструмента УСЕЧЁН (48 000 символов), и число будет неверным.**

## 2. ЖИВОЙ ФАКТ (16.10.2026, gpt-oss:20b, стенд)

Задача: «Сколько файлов `SKILL_*.md` в `D:\AI\repo\Creo`?» — **в Creo 65 файлов.**

| что сделала модель | что получила |
|---|---|
| `Get-ChildItem -Path '...\Creo' -Recurse -Filter 'SKILL_*.md'` (**без счётчика**) → считала строки глазами | ❌ **«86»** — неверно (вывод усечён, строки ≠ файлы) |
| `Get-ChildItem ... \| Measure-Object \| Select -ExpandProperty Count` (со счётчиком) | ✅ **верно** |

**Разброс был у ОДНОЙ модели в одном прогоне.** Причина — нет шаблона в скиллах.
Правило дома: **инструмент (способ) — в скилле, а не в догадке модели.**

## 3. ПРАВИЛЬНЫЙ ШАБЛОН (копировать как есть)

```powershell
# ВСЕГДА: -File (только файлы!), -Recurse, маска, и СЧЁТЧИК .Count
(Get-ChildItem -Path 'D:\AI\repo\Creo' -Filter 'SKILL_*.md' -Recurse -File).Count
```
Вывод: **одно число**. Ничего не усекается.

**Равнозначные варианты:**
```powershell
(Get-ChildItem -Path '<папка>' -Recurse -File -Filter '<маска>').Count
Get-ChildItem -Path '<папка>' -Recurse -File -Filter '<маска>' | Measure-Object | Select-Object -ExpandProperty Count
```

**Другие счётные задачи (тот же принцип — счётчик, не глаза):**
```powershell
# строк в файле
(Get-Content '<файл>').Count
# совпадений в файле/дереве
(Select-String -Path '<файл>' -Pattern '<шаблон>' | Measure-Object).Count
# файлов в дереве по расширению
(Get-ChildItem '<папка>' -Recurse -File -Filter '*.py').Count
```

## 4. ЧТО ЗАПРЕЩЕНО (и почему)

| ЗАПРЕТ | почему |
|---|---|
| Считать строки вывода глазами | вывод усечён до 48 000 символов → число неверно |
| `Get-ChildItem` **без `.Count`/`Measure-Object`** | вернёт СПИСОК, а не число |
| Без `-File` | вернёт и ПАПКИ (число раздуется) |
| Без `-Recurse` | считает только корень (в 13 раз меньше) |
| Хардкод числа в ответе | числа дома меняются (тесты создают файлы) |

## 5. ПРОБА (проверка скилла)

1. Сколько файлов `SKILL_*.md` в `D:\AI\repo` (рекурсивно)? **Ответ: `(Get-ChildItem 'D:\AI\repo' -Recurse -File -Filter 'SKILL_*.md').Count`**
2. Почему подсчёт строк дал 86 вместо 65? **Вывод усечён, строки ≠ файлы.**
3. Что обязательно в команде? **`-File` + `-Recurse` + `.Count`.**

## 6. 🔴 ДВЕ МАСКИ — ДВА РАЗНЫХ ЭТАЛОНА (живой факт 16.10.2026)

**Грабля:** посчитал «файлы в направлении» с маской `*.md` — и получил число, которое
**не совпадает** с эталоном теста стенда. Обе команды «сработали», оба числа «верны» —
но отвечают они на РАЗНЫЕ вопросы.

**Живой замер (16.10.2026, `D:\AI\repo\Creo`):**

| маска | что считает | Creo | Prog | где используется |
|---|---|---|---|---|
| **`SKILL_*.md`** | только СКИЛЛЫ | **65** | **17** | **тест 3 стенда** (`check_3_skills_avail.ps1:145`) |
| `*.md` | ВСЕ документы | **83** | 17 | «сколько .md вообще» |

Разница в Creo = **18 файлов** (83 − 65). Это не ошибка счёта, а **разные вопросы**:
«сколько скиллов» ≠ «сколько markdown-файлов».

**ГРАБЛЯ В ГРАБЛЕ:** утром 16.10 я снял эталон маской `*.md` (creo=83) и весь день сверял
с ним вердикты теста 3, который считает `SKILL_*.md` (creo=65) → рождались ложные
`COUNT_WRONG` и подозрения «что-то сломалось». Причина — **мой эталон**, не модель и не код.

**ПРАВИЛО (обязательное):**
1. Эталон для сверки берётся **ТОЙ ЖЕ командой**, что и в тесте — не «похожей».
2. Перед сравнением открой код теста и выпиши его маску:
   `Select-String -Path '<тест>.ps1' -Pattern "Filter|Get-ChildItem"`.
3. Число без маски — не число. Всегда пиши маску рядом: «считал `SKILL_*.md`: 65».
4. Если маска тебе неизвестна — **не сравнивай**, сначала выясни.

**Формулировка для ответа:** «посчитал `-Filter 'SKILL_*.md'` рекурсивно → 65» (с маской!),
а не «в Creo 65 файлов» (непонятно, чего именно).
