# МАРШРУТИЗАЦИЯ ИНСТРУМЕНТОВ

## ГЛАВНОЕ ПРАВИЛО 0: СНАЧАЛА НАЙДИ ИНСТРУМЕНТ, ПОТОМ ДЕЛАЙ (правило владельца 02.10.2026)
Инструмент дома не перечислен в голове модели — он **лежит на диске и ищется**. Прежде чем
«сделать руками», ответь себе на три вопроса и только потом зови инструмент:
1. **Направление?** → `D:\AI\repo\SKILL_index.md`, затем вход направления (`.clinerules`, п.3).
2. **Инструмент в доме или его нет?** → поиск по скилам и по `D:\AI\tools\agent\`:
   `Select-String -Path D:\AI\tools\agent\*.py -Pattern '<намерение>'` и
   `Get-ChildItem D:\AI\tools\agent -Directory`.
3. **Куда пишет и что у него настраивается?** → его `README.md` и `settings\<имя>_settings.json`.
Где инструмент уже описан: `SKILL_tool_routing.md` (намерение → инструмент),
`Prog\SKILL_tool_template.md` (состав любого инструмента дома),
`D:\AI\tools\agent\AGENT_MAP.md` (карта строения агента).
**Запрет:** не изобретать путь и окно заново, если инструмент уже есть (`SKILL_creostart_fleet.md`,
запрет «не изобретать окна и пути заново»). Найди → прочти README → запусти.
**Запрет:** выдумывать путь к инструменту или программе. Не нашёл — так и скажи
(`НЕТ ДАННЫЙ: путь неизвестен`), либо найди фактически (`Test-Path`, `Select-String`, `dir`).

## ГЛАВНОЕ ПРАВИЛО 0а: ГДЕ ЛЕЖИТ САМА ПРОГРАММА (02.10.2026)
Имя папки установки задаёт **человек**; внутреннюю структуру создаёт **программа установки**.
Пример (живая проверка 02.10.2026): человек называет `D:\PTC\CREO13`, программа создаёт
`Creo 13.4.1.0\Parametric\bin\parametric.exe` + `Common Files\`.
Значит искать программу надо **по признаку-файлу, а не по имени папки**: рекурсивно, на всех
локальных дисках. Порядок источников для Creo — `Creo\INFRA\SKILL_creostart_fleet.md`
(живой `CREO-START.bat` на Z: → реестр → рекурсивный поиск `Parametric\bin\parametric.exe`).
Общее правило для любых программ — `Prog\SKILL_tool_template.md`, раздел «АВТОНОМНОСТЬ ИНСТРУМЕНТА».

## Принцип выбора

1. Сначала пойми намерение пользователя, потом выбирай инструмент.
2. Нормализуй запрос в короткую рабочую команду.
3. Если данных не хватает — уточни, не гадай.
4. Если инструментов подходит несколько — выбери самый безопасный (чтение вместо записи).
5. После результата проверь: отвечает ли он исходному намерению.

## Уточнение при нехватке данных

Если критических данных нет, уточни одним вопросом. Не гадай.

- «посмотри деталь» → «Какую деталь: активную в Creo или по имени?»
- «проверь файл» → «Какой файл? Укажи путь.»

## Многозадачные запросы

Если запрос содержит несколько действий:
1. Разбей на этапы в [THINK].
2. Выполни один этап за ход.
3. После результата проверь: нужен ли следующий этап.

Пример: «найди корпус_А, проверь где используется и посмотри параметры»
→ Этапы: 1) models_find, 2) models_where, 3) creo_get_params, 4) итог.
