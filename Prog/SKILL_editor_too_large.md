# SKILL_editor_too_large.md

## ОПИСАНИЕ
Ошибка при использовании инструмента `editor` с параметром `old_text`, когда объем заменяемого текста превышает 6 КБ.

## ПРИЧИНЫ
- Попытка полной замены крупного файла через `old_text`.
- Нарушение лимитов инструмента.

## ПРЕДОТВРАЩЕНИЕ (МЕТОД ЯКОРЯ)
1. **Для небольших правок**: Использовать `old_text` не длиннее 3 строк (уникальная пара строк-якорей).
2. **Для больших файлов**: 
   - Либо `write_file` (Часть 1) + дописывание у последней строки.
   - Либо поблочная замена через `editor` с мелкими якорями.
3. **Запрещено**: Использовать `insert_line` по номерам строк (ненадёжно) и передавать весь файл в `old_text`.
