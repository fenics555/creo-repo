# ВЫЖИВАНИЕ ЛОКАЛЬНОГО ИИ В CLINE (VS Code)

**Кому:** локальным моделям (`gemma4:26b`, `gpt-oss:20b`, `qwen3.6-35b` и др.) при работе в Cline.
**Главный закон среды:** `D:\AI\.clinerules` (подставляется в системный промпт автоматически).
*(Примечание: `D:\AI\repo\MANIFEST.md` — расширенный закон для автономного Python-агента, для Cline-задач читать его не требуется).*

## 2. РЕЖИМЫ ИСПОЛНЕНИЯ И АРХИТЕКТУРА МИКРО-СУБАГЕНТОВ
### §2.1 Пошаговый (ПОШАГОВО)
Логика: 1 действие -> краткий отчёт -> пауза до подтверждения.
### §2.2 Автономный (АВТОНОМНО)
Логика: Непрерывный цикл. При достижении окном ≥ 70% или 1-м сжатии — принудительное торможение (Downshift) и подготовка эстафеты.
### §2.3 Диспетчерский (ДИСПЕТЧЕР) и автоопределение среды
**Ветка А (spawn_agent доступен):**
- Регламент 4 ролей: **Библиотекарь** (поиск), **Разведчик** (анализ), **Арбитр** (контроль), **Тестировщик** (проверка).
- Формат ответа субагента: `SUMMARY ≤ 12 строк`.
- Обязательный вызов **Арбитра** при промахе Библиотекаря или сомнительном ответе Разведчика.
**Ветка Б (spawn_agent недоступен — VS Code Cline / внутри субагента):**
- Режим **Solo-Chunked**.
- Поиск через `Select-String`, чтение `≤ 80` строк.
- Ранний порог сдачи эстафеты при заполнении 55–60% окна.

1. **Завершение хода:** сообщение заканчивается либо вызовом инструмента, либо явным маркером «ПАУЗА: жду слова пользователя». Тихо закончить рассуждением без действия нельзя (`crash_agent_silence`).
2. **План — не шаг:** если план готов — сразу вызывай инструмент. Не повторяй один и тот же план 3 раза подряд без исполнения (`crash_plan-loop-replan-no-exec`).
3. **Экономия контекста:** читай только нужные файлы (1–2 за раз). Большие файлы читай диапазонами строк по якорям, не загружай весь файл целиком без необходимости.

**Необязательный приём для гигантских выводов (> 100 строк):** если скрипт или поиск выдаёт огромную таблицу, которую консоль обрезает или которая забьёт окно, можно (по усмотрению, не обязательно) сбросить её во временный файл `D:\AI\log\urn\cline\scan_<тема>.json`, прочитать нужную сводку и сразу удалить файл. Для обычных ответов субагент возвращает сжатый текст напрямую без файлов.
4. **Контроль усталости ноги:** следи за количеством вызовов инструментов по правилам `D:\AI\repo\SKILL_noga_health.md` (пороги внимания: 40, 55, 70 вызовов; при двух признаках деградации — передача эстафеты).
