# КОНТРОЛЬ PDF: ПАРЫ, ДУБЛИ, «НЕ РЯДОМ», PDF БЕЗ МОДЕЛИ

## 1. ЧТО СЧИТАЕТСЯ НОРМОЙ, А ЧТО ОШИБКОЙ
| Случай | Как читать |
|---|---|
| `X.drw[.N]` + `X.pdf` рядом, PDF не старше | **порядок** |
| `X.pdf` без `X.drw` рядом, но чертёж есть **в другой папке** | **ОШИБКА вывода** («PDF уехал») — перевыпустить рядом, лишний убрать |
| `X.pdf` есть **и рядом, и в другой папке** (копий несколько) | **ДУБЛЬ** — лишние копии не нужны |
| PDF без одноимённого чертежа **нигде** (каталог, руководство, скан) | **ДОКУМЕНТАЦИЯ — норма** (но при желании убирается) |
| PDF без чертежа, но модель `.prt/.asm` с тем же именем есть в другой папке | «PDF от модели» — присмотреться |

## 2. ИНСТРУМЕНТЫ (оба — без Creo, быстрые)
- `creo_pdf_misplaced.py <папка> [--limit N] [--doc]` — **дубли и «не рядом»** (в окне кнопка
  «Искать дубли ПДФ и не рядом»). `--apply` — перемещение лишнего в корзину инструмента.
- `creo_pdf_orphans.py <папка> [--limit N]` — **PDF без модели рядом** (кнопка «Искать ПДФ без модели»).
  `--apply` — перемещение сирот в корзину.
Как считает: обход выбранной ветки по **имени файла** + справка по **домашнему индексу**
(`agent.sqlite: models` ≈ 44 тыс. имён; `harvest.db: models_raw` ≈ 93 тыс.) → ловятся и **кросс-веточные** случаи.
Скорость: обход ветки — секунды (3 846 файлов ≈ 0 с), справка по базе — миллисекунды на имя.

## 4. КОРЗИНА ИНСТРУМЕНТА — БЕЗВОЗВРАТНОГО УДАЛЕНИЯ НЕТ
- лишние копии → `D:\AI\tools\agent\creo_pdf\_trash\<дата>\`
- PDF без модели → `_trash\<дата>_nomodel\`
- **что НЕ трогается:** единственная копия, у которой нет пары рядом (сначала «СОЗДАТЬ/ОБНОВИТЬ ПДФ»,
  потом уборка); PDF, чья модель есть в другой папке (это чертёж, а не документация);
  при уборке дублей — документация.
- Вернуть = скопировать из корзины обратно руками.

## 6. ГРАБЛИ
1. В домашних базах `name` = **полное** имя с расширением и версией (`x.prt.1`) → искать **по префиксу**
   (иначе ложные «сироты»: было 0 находок, стало 5).
2. «Документация» — не ошибка: не всякий PDF в папке чертёж (каталоги, туториалы, сканы).
3. Метка `(!)` — копия **свежее** той, что рядом: сначала перевыпустить правильную, потом убирать.
4. Уборку запускать только галочкой «перемещать в корзину инструмента» — и это всегда `_trash`, не удаление.
5. Прогресс-строки печатаются не чаще раза в 5 секунд (не засоряют отчёт).
