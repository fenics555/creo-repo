# SPEC 104 «ПЕРЕПЕЧАТЬ УСТАРЕВШИХ PDF ПАЧКОЙ» (3 руки, 3 ноги)
ШАПКА: слово пользователя = создание инструмента тремя руками; --execute по живым корням только отдельным словом под щитом; dirname = папка чертежа всегда, чужие папки запрещены; CREOSON-сессию перед экспортом сверять pwd с папкой чертежа.

НОГА 1 — Ф0 + Ф1 (библиотека и CLI):
Ф0. ЦИТАТЫ: откуда глаз берёт пары и вердикты (имя базы: harvest.db или agent.sqlite);
SELECT пар с вердиктом «устарел» (модель свежее своего pdf); счётчик устаревших;
есть ли уже обёртка над interface:export_pdf в коде дома; цитата инструмента.
Ф1. БИБЛИОТЕКА И CLI: pdf_refresh_batch.py в agent\ (один write_file ≤8 КБ или часть 1 + дописывание у последней строки, НЕ одним new_text): CLI --dry-run по умолчанию, --execute, --root, --limit, --report; библиотека читает пары с вердиктом «устарел», для каждой вызывает interface:export_pdf {file: X.drw, dirname: <папка чертежа>, use_drawing_settings:true, sheet_range:"all"}; после экспорта mtime pdf обновляется — единственный источник свежести; лог в D:\AI\log\pdfrefresh\, отчёт last_refresh.json (было устаревших, стало актуальных, ошибки списком с причиной).
ПРОБА: --dry-run на D:\AI\ПРОБА словом шапки — цитата таблицы превью; --execute НЕ здесь.

НОГА 2 — Ф2 (окно, рука человека):
ОКНО pdf_refresh_gui.py (tkinter, дизайн Давыдовки из DESIGN_davydovka_tokens.md):
список устаревших пар таблицей (имя, было, станет); чекбокс выбора подмножества;
кнопка «ПЛАН» = сухая таблица; кнопка «ПЕРЕПЕЧАТЬ» неактивна до плана, по клику диалог
подтверждения со счётчиком «будет перепечатано N», потом execute; панель ОТЧЁТ из last_refresh.json;
настройки (корень, лимит, авто-выбор устаревших) в data\pdf_refresh_settings.json с round-trip; статусы: идёт = жёлтый #fff1c7, готово = зелёный #dff2df, ошибка = красный домовой тон. Окно работает без агента (питонится само, детачем поднимает библиотеку).
ПРОБА: импорт без mainloop, round-trip настроек, сухой план на PROBA.

НОГА 3 — Ф3 (витрина, рука ИИ под щитом) + Ф4 (бумаги):
БЛОК ВИЗАРДА: в http_handlers.py якорями /wiz_pdfrefresh_preview {root, limit} =
JSON-таблица превью без записи; /wiz_pdfrefresh_execute = подъём библиотеки детачем ТОЛЬКО через щит
согласования, ответ ссылкой на last_refresh.json; в app.js блок «ПЕРЕПЕЧАТЬ PDF» в МАСТЕРЕ
ОПЕРАЦИЙ с кнопками «План» и «Перепечатать» под щитом.
После КАЖДОЙ правки app.js/index.html — dev\ui_check.py и цитата чистой консоли ДО
отчёта о фазе (крах №3, подпись уже повтор №1).
Ф4. БУМАГИ: py_compile; GIT_SYNC обоих корней; отчёт-файл в D:\AI\log\reports\;
строка «ждёт слова: --execute по живым корням под щитом; следующий = кэш параметров».

ГРАБЛИ (для каждой ноги): лимит 20 вызовов, 15+ = HANDOFF в прогресс-файл и передача
следующей ноге в НОВОМ окне (крах №2); бумаги сразу по фазе; большие файлы частями;
два отказа одного хода = смена метода со строкой «ПОПЫТКА N:»; одна спека = одно окно, не копить две спеки в одном окне.
