## Массовые свойства — ЧТЕНИЕ (проверено 04.10.2026)

Масса, объём и площадь поверхности хранятся в `.prt` и читаются прямо из сырых байт.

**Раскладка записи**
```
PRO_MP_MASS   00  f8 01 f7 38 fb e3 f7 39 0e   e3 32  [тип]  [7 байт]  f1
PRO_MP_VOLUME ...                                   e3 32  2D    [7 байт] f1
PRO_MP_AREA   ...                                   e3 32  2D    [7 байт] f1
```
- `e3 32` — маркер «далее идёт значение»
- `[тип]` — `28` для MASS, `2D` для VOLUME/AREA
- 7 байт — big-endian IEEE-754 **double со срезанным ведущим байтом экспоненты**
- `f1` — терминатор

**Восстановление срезанного байта.** В файле его нет. Два проверенных способа:
1. `VOLUME` / `AREA` — ведущий байт восстанавливается из порядка величины; проверены `0x40` и `0x41`.
2. `MASS` — восстанавливается из **плотности**: `MASS / VOLUME` должно лежать в 6..9.5 г/см³
   (сталь 7.85). Проверено: `0x3F` → 0.21461530730689607 (7.8500 г/см³),
   `0x40` → 6.6861510413184719 (7.9000 г/см³).

**Приёмка:** 6 из 6 значений совпали с эталоном JLINK до 17 значащих цифр
(масса + объём + площадь, две разные модели).

**Эталон — через JLINK, не CREOSON.** CREOSON не отдаёт `PRO_MP_*`.
`D:\AI\tools\agent\creo_export\mass_probe.bat` делает это:
```
call .\mass_probe.bat Z:\PTC\Work\00080\00080-03.prt
-> 00080-03.prt  MASS=0,21461530730689607  VOLUME=27339,529593235176  AREA=13275,370841291067
```
Требует запущенного Creo; оставляет его живым.

## Быстрый старт
1. Склонировать репозиторий, держать `MANIFEST.md` в корне базы знаний.
2. Скопировать `.clinerules` в корень агента (по умолчанию `D:\AI`) — подхватывается на старте сессии.
3. Поставить задачу: агент читает манифест, скилл выживания и вход нужного направления.

## Соглашения
- Verbatim-русский входит в файлы только через редактор; консоль кириллицу не несёт.
- Каждая необратимая правка — после бэкапа; внешние дампы — сырыми близнецами с размером и хешем.
- Крах не бывает тихим: отчёт в задаче, затем скилл в `crash/` со счётчиком повторов.
