# Репозиторий знаний (Knowledge Base)

Централизованное хранилище знаний, стандартов и документации.

## Состав
- **Паспорт (PASSPORT.md)**: Главный документ, определяющий состояние и историю системы.
- **Скиллы (Skills)**: Описания компетенций агента.
- **Чек-листы визии**: Протоколы проверки соответствия целям.

## Структура
- SKILL_*: Справочники компетенций.
- D:\AI\tools\agent\data\drafts: Черновики новых знаний.
- drafts_approve: инструмент агента для утверждения знаний.

## Поиск
Для поиска информации используйте:
- search_kb: Поиск по текстовому индексу знаний.
- ind_similar: Поиск семантически похожих записей.

## Жизненный цикл скилла
Новые знания рождаются в D:\AI\tools\agent\data\drafts, проходят проверку через инструмент drafts_approve после утверждения.

---
**Внимание**: Основным источником истины является PASSPORT.md.
