
## `creo-repo/README.md`

```markdown
# creo-repo — база знаний АГЕНТА v12

Markdown-скиллы, по которым отвечает ИИ-агент напарника Creo.
Один скилл = одна зона знания; домены не дублируют друг друга.

## Домены
- **Creo**: relations (справочник + железные правила), паспорт компании
  (единицы MMKS, шифры, обязательные параметры, ЕСКД), канон-шаблоны с
  «свидетельством о рождении» TPL_SOURCE, карта API CREOSON, пружины, кривые.
- **Python**: стандарт расчётных скриптов (блочная архитектура, суффиксы
  единиц, аудит A1–A15).
- **Инженерные**: материалы, сопромат, тепло/гидравлика, литьё в ХТС.
- **Производство**: зеркало срезов 1С (склад, входящие, запуск, отгрузки,
  составы; якорь сборки и время цикла, термообработка batch).
- **Общее**: протокол инженера-напарника, границы WEB/визии, стратегия КБ.

## Навигация
`SKILL_index.md` — карта всех скиллов и правила маршрутизации.

## Правила
- Автогенерируемые файлы (`SKILL_company_config.md`, `Трейлы/TRAIL_JOURNAL.md`,
  `Ошибки/ERR_*.md`, `Избранное/`) руками не правятся.
- Новый скилл: `SKILL_<имя>.md` с шапкой (name/description/when/priority)
  + строка в `SKILL_index.md`.
- Живые данные (Creo, файлы, 1С) агент берёт только инструментами;
  скиллы — справочник, не источник живых данных.

## Связанный репозиторий
`creo-agent` — код агента. Этот репо — его справочники.
