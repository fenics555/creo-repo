# ПРОИЗВОДСТВЕННЫЙ КОНТУР (зеркало срезов 1С)
1С — территория бухгалтерии, агент её НЕ трогает. Зеркало — локальная БД из файлов-срезов.

## Приём данных
- Первичная полная загрузка истории — один раз; дальше суточные файлы в data/orders_inbox/, обработанные → orders_done/.
- Upsert по номеру документа: дубли и перекрытия безопасны.
- Поля среза 1:1 как в 1С + служебные: guid_1c, synced_at, deleted_in_1c (мягкое удаление).
- Файл > 100 МБ — предупредить, не глотать (защита от случайной полной выгрузки).

## Срезы
- Номенклатура: шифр, наименование, тип (деталь/сборка/покупное/материал).
- Склад: шифр, qty, склад, дата остатка.
- Входящие: номер/дата, шифр, qty, поставщик, под какой заказ.
- Запуск: производственный заказ, шифр, qty, этап, цех, плановая дата.
- Отгрузки: дата, шифр, заказчик, получатель, qty, ТН.
- Составы: родитель → дети, qty на изделие, anchor (экспертная метка-подсказка).

## Типовые запросы
- «какие держатели форм есть?» → номенклатура; «мне интересен этот» → карточка изделия (агрегат всех срезов по шифру).
- «склад / входящие / запуск, какой этап?» → свой срез.
- «кто заказывал / сколько изготовлено / куда уехало?» → отгрузки; имена — через словарь синонимов; 0 кандидатов — «не найдено», 2+ — уточнить, НЕ угадывать.
- «прогноз на полный комплект?» → составы × (склад+входящие+запуск) → дефицит с датами.

## Якорь и время
- Готовность компонента: склад → 0; в цехе → остаток цикла; в закупке → срок поставки.
- tip=standart (нет TPL_SOURCE) — ТОЛЬКО срок поставки: без производственного цикла и резервов ускорения.
- Якорь = argmax(готовностей). Называется ВСЕГДА + его долгие моменты с флагом: сжимаемо (мех, сварка, сборка) / несжимаемо (термичка, сушка, остывание, подряд). Нелимитирующие — одной строкой. Якорь ситуативен: пересчитывается из текущего зеркала.

## Термообработка (batch)
- τ_нагрева = k × S (мин), S — макс. сечение в садке, мм; k: воздушная печь 0.8–1.5, соль 0.3–0.5.
- Выдержка: закалка ≈ τ_нагрева, отпуск 1–2 ч; остывание по среде. Несжимаемо ≥ 1 дня.
- Время не зависит от количества до ёмкости печи (capacity_kg / capacity_parts); не влезло — несколько садок.
- «время в печи» и «время на деталь» (итог/qty) — разные числа, не смешивать.

## Прогноз цикла — всегда два числа
- Теоретический минимум = критический путь без очередей: сборка = max(готовностей компонентов) + сборка + ОТК.
- Реалистичный = минимум × коэффициент очередей из истории (эмпирический цикл минус чистое время).
- tech_floors (несжимаемые паузы) растёт через диалог; нет данных → «нет данных, уточнить», НЕ выдумывать.
