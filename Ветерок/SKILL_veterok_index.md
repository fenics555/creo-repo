## ГЛАВНОЕ, ЧТО НАДО ЗНАТЬ СРАЗУ (живые факты 04.10.2026)
1. **Удаление параметров — работает и пишется на диск** (`parameter:delete`).
2. **Уравнения пострегенерации через CREOSON НЕ ПИШУТСЯ НА ДИСК.** Функция
   `postregen_relations_set` снимает их в памяти, `file:save` отвечает «ок»,
   но после выгрузки модели уравнение возвращается. Проверено тремя порядками
   сохранения. Правильный метод — прямой JLINK `pfcModel.DeletePostRegenerationRelations`
   (`Creo\CREOSON\SKILL_creoson_pfc_map.md`, строка 39).
3. **Системные параметры `PTC_*` удалить нельзя** — ограничение Creo.
4. **На складе файлы версионированы**: `00080-03.asm.1`, а имя модели для Creo —
   без номера версии. Маска `*.asm` по полному имени не видит ничего.
5. **Ответ «ок» — ещё не приёмка.** Принимать надо чтением с ДИСКА: выгрузить
   модель из памяти и прочитать заново.
