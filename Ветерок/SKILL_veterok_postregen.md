# УРАВНЕНИЯ ПОСТ-РЕГЕНЕРАЦИИ: ЧТО МОЖНО И ЧТО НЕЛЬЗЯ

Тема задачи владельца 04.10.2026: «во всех файлах сборок удалить все параметры и
все уравнения пострегенерации, пусть даже в открытой сборке в Крео».

## 1. ЧТО ЭТО ТАКОЕ
Уравнения пост-регенерации — relations, которые выполняются ПОСЛЕ регенерации
модели (не обычные relations). В CREOSON две функции (живые спеки
`D:\PTC\CREO-LOCAL-SETUP\creoson\web\assets\creoson_stuff\jsonSpecs\`):
- `file:postregen_relations_get` → `{relations: [...]}`;
- `file:postregen_relations_set` → `{relations: [...]}`; в спеке прямо сказано
  **«Clear the relations if missing»** — то есть ПУСТОЙ список = очистка.

## 2. ЖИВЫЙ ФАКТ: ЧТЕНИЕ РАБОТАЕТ
На боевой сборке `Z:\PTC\Work\00080` прочитаны реальные уравнения:
```
00080-03.asm    -> mass=pro_mp_mass
00080-03.prt    -> MASS=PRO_MP_MASS
00080-03-z.prt  -> пусто
```
Читать ТОЛЬКО у ОТКРЫТОЙ модели: иначе «File ... was not open».

## 3. ЖИВЫЙ ФАКТ: ЗАПИСЬ НА ДИСК НЕ РАБОТАЕТ (главное)
`postregen_relations_set` снимает уравнения В ПАМЯТИ — чтение сразу после
отвечает пустым списком. `file:save` отвечает «ok». Но после выгрузки модели из
памяти уравнение ВОЗВРАЩАЕТСЯ — то есть на диск оно не легло.

Проверены три порядка сохранения (проба `probe_save_path.py`, копия в PROBA):
| Порядок | На диске после выгрузки |
|---|---|
| `relations_set([])` → `save` | `MASS=PRO_MP_MASS` (осталось) |
| `relations_set([])` → `regenerate` → `save` | осталось |
| `relations_set([])` → `refresh` → `regenerate` → `save` | осталось |

**ПРАВИЛО: ответ «ok» — не приёмка.** Приёмка только чтением с ДИСКА
(выгрузить модель из памяти и прочитать заново).

## 5. ЧТО РАБОТАЕТ ИЗ ВСЕГО ЗАПРОСА
| Задача | Статус |
|---|---|
| удаление параметров (`parameter:delete`) | **работает и пишется на диск** |
| удаление параметров `PTC_*` | **нельзя** — ограничение Creo, честный отказ |
| очистка уравнений пострегенерации | **не работает через CREOSON** (см. п. 3–4) |
| переименование элементов (`feature:rename`) | путь есть, на живой модели не подтверждён |
| виды на чертеже (`drawing:rename_view`) | другая функция, не сделана |

## 6. ГРАБЛИ (живые, 04.10.2026)
1. **Имя с номером версии не понимается.** На диске `00080-03.asm.1`; Creo
   называет модель `00080-03.asm`. С именем `...asm.1` → «Unknown Model Extension».
2. **Маска по полному имени ничего не находит** на версионированных файлах.
3. **`activate:true` НЕ делает модель активной** — активной становится только
   модель, открытая с `display:true` (окно создаётся, и тогда `get_active` её видит).
4. **`file:open` открывает модель ИЗ КЭША ПАМЯТИ, а не из указанной папки.** Если
   модель с тем же именем уже загружена из `Z:`, откроется она — и запись уйдёт
   в боевую модель. Ловится щитом сверки активной модели по полному пути.
5. **`Z:` — не сетевой диск** (`wmic logicaldisk`: DriveType=3, локальный).
   Сетевой в этой машине `Y:` (`\\backup\Public`, DriveType=4). Значит запрет
   «на Z: только чтение» держится правилом дома, а не системой: проверять надо
   ПО ПУТИ, а не по типу диска.
