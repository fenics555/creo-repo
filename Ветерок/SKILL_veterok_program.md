# ПРОГРАММА POSTREGEN_CLEAN

Отдельная программа дома со своим окном. Сделана 04.10.2026 по слову владельца:
«нужна сейчас отдельная программа, локальная, со своим окном и настройками».

## ГДЕ И КАК ЗАПУСТИТЬ
`D:\AI\tools\agent\postregen_clean\`
- `postregen_clean_gui.bat` — **окно**, двойной щелчок, без агента и без Cline;
- `plan.bat` — план (только чтение), `apply.bat <plan.json> [--approve]` — запись;
- настройки окна: `D:\AI\tools\agent\data\postregen_clean_settings.json`.

## ТРИ ДЕЛАЕТ (каждое выключается отдельно)
1. **очистить уравнения пост-регенерации** — `file:postregen_relations_set []`;
2. **удалить параметры по маскам** — `parameter:delete` (пустая маска = не удалять);
3. **переименовать элементы** — карта `СТАРОЕ=НОВОЕ`, `feature:rename`.

## ЛОГИКА РАБОТЫ
**ПРОВЕРИТЬ** строит план и НИЧЕГО не пишет → человек смотрит → **ОЧИСТИТЬ**
пишет по согласию и второму подтверждению. Кнопка **СТОП** рвёт цикл между
моделями.

## ЩИТЫ (все проверены живой пробой)
| Щит | Что делает | Проверка |
|---|---|---|
| согласие | без `approve` запись не начинается, RC 3 | ✅ |
| активная модель | сверка по полному пути; спасает от записи в боевую модель | ✅ поймал случай с `Z:` |
| **запрет записи** | запрещённые корни (по умолчанию `Z:`), сетевой диск (`GetDriveTypeW`), UNC → RC 5 | ✅ |
| **приёмка с диска** | после save модель выгружается и читается заново | ✅ поймала несохранение |

## ЧТО РАБОТАЕТ, А ЧТО НЕТ (на 04.10.2026)

|---|---|
| чтение пострегенерации | ✅ читает реальные уравнения сборок |
| удаление параметров | ✅ пишется на диск (проверено: 75 → 74 параметра) |

| виды на чертежах | ❌ не сделано (нужна `drawing:rename_view`) |

## ГРАБЛИ СБОРКИ ОКНА (уроки 04.10.2026)
- `SettingsTable.refresh()` пишет в журнал **при создании** → журнал надо
  создавать ДО таблицы настроек, иначе `AttributeError` и окно падает;
- `insert_line` по номеру режет файл, если номер внутри функции;
- `.bat`: `cd /d "%~dp0.."` не разрешается — нужен `cd /d "%~dp0"` и запуск
  скрипта из своей папки без лишнего префикса;
- `editor` отбивает блок свыше 6 КБ — делить по 3–4 КБ.
