# D:\AI\PROBA — ПЕСОЧНИЦА ДЛЯ ТЕСТОВ МОДЕЛЕЙ (рабочая директория стенда)

Создана 13.10.2026 по требованию владельца: **у каждой агентной задачи должна быть явная рабочая
директория с реальными файлами** — иначе модель честно отказывается («путь неизвестен»), а мы меряем
не поведение, а отсутствие данных.

Файлы — копии шаблонов B&W (`D:\AI\log\urn\bw\x\mbdtools\app\configuration\general\resource\templates`),
имена заменены на «изделия» (`00080-03.prt` и т.п.), чтобы задача из теста (`переименовать 00080-03.prt
в 00080-04.prt`) была РЕАЛЬНО выполнима.

## Правила использования стендом

1. Все задачи тестов адресуют **`D:\AI\PROBA`** (абсолютные пути), не «дом» и не диск целиком.
2. Стенд работает в режиме **только чтение** по «дому» (`D:\AI\repo`, `D:\AI\AGENT_SETTINGS`), запись —
   **только внутрь `PROBA\work`** (и `PROBA\models`, если задача про переименование).
3. `PROBA` восстановима: файлы = копии шаблонов; при порче — пересоздать (см. SUITE.md).
4. Рабочий каталог shell: **`D:\AI\PROBA`** (модель должна получать его в промпте и не сканировать диск).

меряет инструмент, а не догадки.
