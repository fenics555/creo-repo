## Три закона направления (проверены замерами)

1. **Health check входа.** Прогон падает, если правила не дошли до модели целиком (обрезка
   молча обесценивает измерение — случилось 01.10.2026).
2. **Проверка измерителя перед выводом о модели.** Если предмет не проходит ни одна модель —
   сначала чекер, потом модели (класс ошибок читается из реального ответа, не из логики).
3. **Структура не лечит всех одинаково.** Перенос блока дал +4 одной модели и −2 двум другим.
   Перемещение блока применяется только если выигрывает весь стек; иначе — содержание.
