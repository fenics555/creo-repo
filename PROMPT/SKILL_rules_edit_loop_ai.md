# ЛОГИКА ПОИСКА ПРАВОК ПРАВИЛ (AI-цикл) — 14.10.2026

## 1. Принцип
Правила улучшаются **ИТЕРАТИВНО**, и выбор гипотезы — **осмысленный шаг ИИ**, НЕ автоматизация.
Автоматизировать нельзя именно выбор правки; автоматизируются только прогоны и сбор метрик.
Роли: **ИИ (нога)** — диагноз, гипотеза, чтение результата, решение; **стенд** — быстрые метрики
(целевая проба) и приёмка (полный канон).

## 2. Цикл правок (7 шагов)
1. **ДИАГНОЗ.** По свежему прогону найди ХУДШИЙ узел (метрика) и СЛАБЕЙШУЮ модель на нём.
   Примеры: `P2g_tool` 5/5; `T12c` — слабейшие nemotron/laguna; скиллы 9/15, слабейшая nemotron.
2. **ГИПОТЕЗА = РОВНО ОДНА ПРАВКА.** Одно изменение текста закона, бьющее в этот узел.
   (Пачкой нельзя — не видно вклад; см. §4.)
3. **ЛОКАЛЬНЫЙ ТЕСТ.** Прогон ТОЛЬКО целевой пробы на **2 моделях**: **слабейшая + gemma4** (эталон).
   `probe_3 -Rulesets <ветка> -Models nemotron` и `-Models gemma4` (для инструментов — `probe_2`).
   Для скорости — фильтр задач (`-Tasks T12c`), тогда минуты.
4. **ВЕРДИКТ ГИПОТЕЗЫ.** У слабой метрика **выросла**? У сильной (gemma4) **не просела**?
   - ДА/ДА → правка в **КАНДИДАТЫ**.
   - иначе → правку **отбросить** (или уточнить формулировку и повторить шаг 3).
5. **ЦИКЛ.** Возврат к шагу 1 (следующий узел) → накапливается **СВОД правок** (список кандидатов).
6. **ПРИЁМКА СВОДА.** Полный канон `probe_1..4`, seed=42, сравнение с базой (текущий живой).
   Условие: ИТОГ ≥ базы И рост на целевых узлах.
7. **ВНЕСЕНИЕ.** Свод → в живой `.clinerules` (бэкап в `D:\AI\Старые правила\`) + запись в `SUITE.md`.

## 3. Что даёт ускорение
- Целевая проба + 2 модели вместо полного канона: **минуты вместо ~28 мин**.
- Одна правка за раз: результат **однозначно атрибутируется**.
- Полный прогон — ТОЛЬКО на свод (и на приёмку).

## 4. Чего НЕ делать
- Не менять несколько пунктов сразу (вклад не виден).
- Не гонять полный канон на каждую гипотезу (дорого).
- Не гонять без проверки VRAM/GPU — см. `OLAMA\SKILL_ollama_vram_orphan_runners.md`.
- Не решать по ОДНОМУ прогону на приёмке (шум ±2) — слабые дельты подтверждать повтором.
- Не пытаться автоматизировать ВЫБОР гипотезы — это осмысленный шаг ИИ.

## 5. Проба
Назвать: (а) что даёт быстрый цикл; (б) почему гипотеза — ровно одна правка; (в) когда идёт полный прогон.
