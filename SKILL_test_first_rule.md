# ПРАВИЛО: СНАЧАЛА TEST, ПОТОМ БЛОКИ
1. Неясно, как работает команда/связка - НЕ трогать блоки агента.
2. Создать D:\AI\tools\agent\TEST\TEST-<тема>.py - самодостаточный
   скрипт (без импортов из агента, только urllib/json), запуск в PowerShell.
3. Смотреть СЫРОЙ ответ; крутить варианты, пока поведение не ясно на 100%.
4. Только тогда переносить выверенную логику в блок агента (целым def).
5. Прогнанные тесты не удалять: в шапке "# STATUS: PASSED <дата>" -
   это живая документация по связкам.
6. Вывод теста копировать в ответ агенту/в диалог - след рассуждений.
