# РАЗВЕДКА ПЕРЕД ЧТЕНИЕМ (папки и файлы)

**Зачем:** модель лезет читать файл/папку «в лоб», упирается в лимит (обрезка вывода / таймаут / пустой результат) и начинает петлять. Лечится **предварительной разведкой**: сначала метрики («сколько»), потом точечное чтение («что»).

## 0. ГЛАВНЫЙ ПРИНЦИП
**СНАЧАЛА «СКОЛЬКО», ПОТОМ «ЧТО».** Прежде чем читать — получить дешёвые метрики и спланировать бюджет чтения.
**Признак, что разведки не было:** `read_files` вернул обрезанный/пустой результат или таймаут; `search_codebase` — пусто или `[migration] Tool result missing`.

## 1. РАЗВЕДКА ФАЙЛА (перед `read_files`)
1. **Размер в байтах:** `(Get-Item -LiteralPath <p>).Length`. Плюс число строк: `(Get-Content <p>).Count` или `Measure-Object -Line` (`Prog\SKILL_count_files_template.md` — счётчиком с диска).
2. **ВИЛКА (порог):** файл `≤ 40 КБ` **и** `≤ ~800` строк → можно читать **целиком** (но в пределах лимитов чтения — `.clinerules` §КРАСНЫЕ ЛИНИИ); файл `> 40 КБ` **или** `> ~800` строк → **целиком НЕ читать**, только **диапазонами** `start_line/end_line` по якорю (`SKILL_edit_gotchas.md` §11; карты/индексы вроде `SKILL_index.md` 28 КБ — `AGENT_index.md` L23/L38 — читать только `Select-String`).
3. **Якорь, а не весь файл:** `Select-String -Pattern <латиница>` → читать только совпавшие строки (+контекст); для `.md` — карта заголовков `Select-String '^#{1,4} '`.
4. **Кодировка/BOM:** при сомнении — первые байты (`Format-Hex` / `ReadAllBytes`), не «на глаз» (`SKILL_edit_gotchas.md` §2/§11/§15).

## 2. РАЗВЕДКА ПАПКИ (перед обходом)
1. **Ориентир в дереве — сначала окружение:** **родитель** (`Split-Path -Parent`), **дети** (`Get-ChildItem`), **соседи** (братья в той же папке). Знать их число, ПРЕЖДЕ чем нырять внутрь.
2. **Глубина 1, без `-Recurse`:** `Get-ChildItem -LiteralPath <dir>` — увидеть подпапки и файлы верхнего уровня.
3. **Счётчики, а не содержимое:** `(Get-ChildItem <dir> -File).Count`; по типам — `Group-Object Extension`.
4. **Рекурсию — осознанно и дозированно:** `-Recurse` по большому/незнакомому дереву (`Z:`, `repo`, сетевые шары) «в лоб» **запрещён**: сначала `-Depth 1/2`, либо считать по подпапкам, либо `Select-Object -First N` (`.clinerules` §4.2 — `Z:` дробить по подпапкам).
5. **Дерево — метрикой, не свалкой:** список папок с числом детей (счётчик), а не вываливание всех путей.

## 3. БЮДЖЕТ ЧТЕНИЯ (планирование ДО первого вызова)
- **Общий лимит на ход — `.clinerules` §КРАСНЫЕ ЛИНИИ «Чтение»** (главное окно `≤ 120` строк за вызов; `ДИСПЕТЧЕР` `≤ 50`; Solo-Chunked `≤ 80`). **Профильный скилл — `20–40`** (`.clinerules` LIBRARIAN п.3).
- ДО первого `read_files`: решить, сколько кусков и какие диапазоны нужны.
- **Лимиты ПО СИТУАЦИИ (не «одно число на всё»):**
  | Ситуация | Сколько читать |
  |---|---|
  | **Новый файл** (размер неизвестен) | сначала `Get-Item Length`, потом решение |
  | **Знакомый файл, точечная правка** | `20–40` строк по якорю |
  | **Индекс/карта** (`SKILL_index.md` и т. п.) | `Select-String` + `20–40` вокруг совпадения, **никогда целиком** |
  | **Большой файл (`> 40 КБ` или `> ~800` строк)** | только диапазонами; `≤ 80` при Solo-Chunked |
  | **Аудит/проверка связности** | можно больше, но **с обоснованием** («читаю §1–§4 целиком, проверяю связность») |
- Каждый крупный файл — сначала карта (заголовки/якоря), потом диапазоны.

## 4. АНТИ-ПЕТЛЯ (прямая связь)
- Уперся в лимит/пусто **2 раза** на одном пути → СТОП, смени метод (`.clinerules` §4.7): сначала метрики, потом диапазон.
- Признак петли: те же `read_files`/`Get-ChildItem` без смены диапазона/пути. Внешний сторож — `D:\AI\tools\agent\loop_watch.py`.

## 5. ПРАВКА (тот же закон разведки)
Перед правкой — та же разведка, что перед чтением: **существует?** (`Test-Path`), **размер/строки**, **BOM/EOL**, **уникален ли якорь** (`Select-String` = 1 совпадение). Затем — выбор метода по вилке: **полный маршрут — `SKILL_edit_gotchas.md` §0** (новый файл → `editor` без `old_text`; точечная правка → `editor` с одной строкой-якорем; блок > 5 КБ → `run_commands`; кириллица `.ps1` → UTF-8 с BOM; `insert_line` запрещён).
**Запуск кода/прогона — отдельная проверка:** `SKILL_edit_gotchas.md` §28 (синтаксис ДО запуска, пробный прогон, лог растёт, нет опасных режимов, лимиты влезают).
