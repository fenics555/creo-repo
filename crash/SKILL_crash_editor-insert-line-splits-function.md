does not match any outer indentation level`).
ПРОФИЛАКТИКА:
1. Новый .py писать ЦЕЛИКОМ одним вызовом (write_file), а не по частям.
2. Если файл велик — вставлять по УНИКАЛЬНОМУ маркеру-комментарию (`# ЧАСТЬ N`),
   который стоит на последней строке уже написанной части, и проверять `py_compile` в том же ходе.
3. `insert_line` по номеру строки ЗАПРЕЩЁН: номер считается от снимка и после первой вставки
   он уже не тот. То же касается правок существующего файла — только по `old_text` из свежего чтения.
4. Маркер вставки `# КОНЕЦ ЧАСТИ N` ставить так, чтобы он не съедал отступ следующего `def`.
5. Если файл уже разорван — не чинить точечно: перенести битый файл в `data\backup\pre_<метка>\`
   и пересоздать заново (правка полным текстом требует old_text на весь файл — лимит редактора).
