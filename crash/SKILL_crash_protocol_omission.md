# SKILL: crash_protocol_omission

## Описание
Инцидент: При получении триггеров краха/восрешения (встал, вылетел, петля и т.д.) исполнитель проводит диагностику и ставит якорь, но забывает выполнить обязательное требование по записи скила в `D:\AI\repo\crash\`.

## Причина
Смещение фокуса на немедленное решение задачи (Task-fixation) в ущерб протоколу документирования (Compliance).

## Профилактика (Предотвращение)
При активации блока «ВОСКРЕШЕНИЕ», исполнитель обязан проверить выполнение трёх компонентов:
1. **Диагностика:** 5 вопросов цитатами.
2. **Якорь:** Что на диске + следующий шаг.
3. **Запись:** Создание/обновление файла в `D:\AI\repo\crash\` по шаблону конституции.

**Чек-лист перед отправкой ответа:**
- [ ] Ответ содержит 5 вопросов?
- [ ] Ответ содержит якорь?
- [ ] Файл скилла создан/обновлен в `crash\`?

Если хотя бы один пункт `[ ]` не выполнен — ответ считается нарушением протокола.
