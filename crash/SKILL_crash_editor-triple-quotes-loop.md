# КРАХ: ПЕТЛЯ В THINKING ПРИ ОБЁРТКЕ MARKDOWN В PYTHON-СКРИПТ ДЛЯ EDITOR

*   **СИМПТОМ:** При попытке обойти лимит размера `editor` (~6 КБ) через генерацию Python-сборщика (`temp_builder.py`) с длинным многострочным текстом в `'''...'''` модель зацикливается в фазе `Thinking` на повторе одной мысли и не вызывает инструмент.
*   **ПРИЧИНА:** Конфликт двойного экранирования JSON-аргумента `new_text` и вложенных бэктиков/кавычек Markdown внутри Python-строки.
*   **ПРОФИЛАКТИКА:** Запрещено создавать `.py`-обёртки для записи `.md`-документов. Крупный `.md`-файл всегда создаётся напрямую через `editor` в два шага: сначала короткий каркас (шапка + заголовки разделов), затем заполнение по 1–2 раздела за вызов (≤ 3–4 КБ на вызов).
*   **ПОВТОРЫ:** 1 (фиксация 13.11.2026 при сборке `PLAN_CREO_BINARY_FULL.md`).
