ОБЪЯСНЕНИЕ (дословно, для grep):
зациклился (или "повторяет неудачную команду", "tooling loop")

СЮЖЕТ:
Агент попадает в цикл, где каждая попытка исправить предыдущую ошибку порождает новую ошибку того же типа (например, ошибка синтаксиса в python -c, ошибка поиска якоря в editor). Это происходит из-за попытки "дожать" инструмент вместо смены стратегии.

ПРИНЯТИЕ:
1. Остановка текущей стратегии.
2. Анализ: почему команда не сработала (escaping, timeout, context)?
3. Смена инструмента: если `python -c` не работает -> писать `.py` файл; если `editor` не находит якорь -> использовать `read_files` для поиска новых якорей.
4. Дробление задачи: если задача слишком велика и вызывает ошибки -> разбить на 5+ мелких шагов.

ПОЛУЧЕНИЕ «Е»:
1. Применить принцип атомарности (один шаг = один маленький успех).
2. Использовать только максимально простые команды.
3. Если цикл повторился 2 раза — ПРЕРВАТЬ и запросить помощь пользователя/сменить метод радикально.
