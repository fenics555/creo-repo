# ПЛАГИНЫ B&W (SMART-МОДУЛИ) ДЛЯ CREO

Тело скилла **ещё не согласовано**: оно опирается только на чтение архива, без установки.
Конспект и лог изучения — `D:\AI\repo\B&W\` (`STUDY_NOTES.md`, карта в `README.md` папки).
Источник истины по составу — `D:\AI\repo\B&W\INVENTORY.md` (сгенерирован чтением архива).

## ЧТО ЭТО
Набор из **15 продуктов SMART\*** от **B&W Software GmbH**, поставка отдельным инсталлятором
под **каждую версию Creo** (в архиве 73 папки версий: 4.0 → 13.4). Канал подключения к Creo —
**Pro/TOOLKIT через `protk.dat`** (тот же механизм, что у VERICUT в доме). Лицензия — FlexNet,
**один общий сервер** `BUW_Flex_Server` на все продукты, порт **6501**.

## УСТАНОВКА (4 шага, дословно из readme)
1. `BUW_Flex_Server_11.19.8_x64` распаковать в **короткий путь**, `server_install.bat`
   **от админа** → служба «BUW License Server».
2. Поставить модуль нужной версии; лицензию в setup **не настраивать**.
3. Скопировать `license.ini` в `<продукт>\bin`
   (`LICENSE_FILE 6501@localhost` + `LICENSETYPE <ПРОДУКТ>_…`).
4. Регистрация: `Common Files\text\protk.dat` — скопировать из `<продукт>\bin`, а если файл
   уже есть — **дописать** его содержимое в конец.

## ЧТО ПОДХОДИТ ДОМУ (дом на CREO13 13.4.1.0)
Под 13.4 в архиве только **3 из 15**: **SMARTHolechart 19.4.1.0**, **SmartMBDTools 13.0.5.0**,
**SmartOptics 13.0.0.0**. Остальные максимум 12.4/11.0.
- **SMARTHolechart** — работает с `.hol`-таблицами отверстий, то есть **с тем дефектом, который
  дом уже зафиксировал** (`Cannot get THREAD_DAT`, 4 битые шапки). Смысловая проверка вендора
  (RM-23710): «число колонок должно совпадать» + «заголовки должны иметь те же значения».
- **SmartMBDTools** — умеет rename элементов модели (RM-24179) и проверку/обновление relations
  (RM-14929), т.е. дублирует то, что дом уже сделал сам; полезен как внешний образец.
- **SmartOptics** — не по профилю дома; ⚠️ 13.0.0.0 меняет имена кнопок `ok_pb`→`ok_pushbutton`,
  `cancel_pb`→`cancel_pushbutton` — **mapkey могут сломаться**.

## ЗАКОНЫ (выведены из этого набора)
1. **Сторонний плагин = предупреждение о mapkey.** Вендор сам об этом пишет в Changelog.
2. **Плагин ставится на одну машину первой**, не в `Z:` (флот), и проверяется тремя руками:
   `config_audit` (RC 0, `protkdat` жив) → старт Creo без ошибок → 2–3 живых прогона mapkey.
3. **Перед правкой `config.pro` — копия в `БЭКАП\` и запись в `БЕКАП\ЖУРНАЛ.md`** (правило дома).
4. **Всё в `Z:` — только чтение.** SMARTHolechart может править `.hol`; боевую папку отверстий
   не отдавать под запись без бэкапа.
