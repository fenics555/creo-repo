# 16. ЧТО В АГЕНТЕ ЛУЧШЕ (и почему это не отговорка от переноса)

_03.10.2026, Cline. Разбор по живым инструментам и правилам дома, без скидок на плагины._

## Коротко
Агент сильнее **везде, где не нужна геометрия и графика чертежа**, и это не «слабее»,
а другая природа слоя: плагин работает **внутри** Creo (может всё), агент работает **снаружи**
(никогда не ломает Creo, всегда повторяем, всегда объясним). Для дома это часто важнее.

## 1. Чтение файлов «в лоб» — главное преимущество
**Факт дома:** `plm_reader` (V37) читает `.prt/.asm/.drw` **напрямую**, без Creo; `creo_read.py`
вложен внутрь; внешних библиотек нет. Паспорта, состав, входимость, изменения, заготовки/отливки,
модельная оснастка — всё из файлов.
**Факт B&W:** чтобы узнать про отверстия, плагин обязан быть установлен и запущен в Creo.
**Почему наше лучше:**
1. **работает всегда** — даже когда Creo не запущен, сломан или занят (а он в доме занят часто);
2. **не трогает модель** — прочитать файл нельзя случайно испортить;
3. **переносимо** — папку можно скопировать на другой ПК целиком;
4. **дёшево по ресурсам** — нет 41-МБ DLL в памяти Creo;
5. **масштабируется** — 12 000 чертежей за секунды против «открыть модель в Creo».
**Чего не хватает:** данных, которых нет в файле в явном виде (результат регенерации, фактическая
штриховка, результат построения) — там нужен Creo.

## 2. Самодостаточность (класс Р) — второе преимущество
**Закон дома:** инструмент класса Р = своя папка, свой bat-вход, свой README, свой лог,
**ничего не берёт из кода агента**, три руки (CLI / окно / витрина). 13 программ уже такие.
**Плагин наоборот:** требует установки, лицензии (порт 6501), службы Windows, `protk.dat`
в установке Creo, конкретной версии Creo (под 13.4 есть только 3 из 15) и **ломает mapkey**.
**Сравнение стоимости владения:**
| Затрата | агент (класс Р) | плагин B&W |
|---|---|---|
| установка на машину | скопировать папку | инсталлятор + Flex-сервис + `protk.dat` |
| на весь флот (5+ машин) | копированием | на каждой + служба + лицензия |
| если вендор умрёт | наш код работает | модуль перестаёт работать |
| если сломан | инструмент падает сам, Creo цел | возможен краш Creo при старте |
| отладка | наш код + логи | закрытая DLL 41 МБ |
**Вывод по надёжности:** для дома (склад, много машин, Creo не всегда свободен) класс Р
**надёжнее и дешевле в 10 раз**.

## 3. Простота там, где плагины усложняют
- Вендор: лицензия FlexNet, `license.ini`, служба Windows, версионные DLL лицензирования,
  обновление при смене версии Creo, `buw_license_check-11-*.dll` × 6.
- Дом: `python <инструмент>.bat` — всё.
- Вендор: `configure_license.exe` + `smbdt_api.exe` + `drwprog_mgr.exe` — три отдельные программы.
- Дом: один движок + одно окно + отчёт.

## 5. Честно: где плагины лучше
1. Геометрия и поверхности (диаметр, замкнутость, направление, резьба) — без Creo никак.
2. Графика чертежа: штриховка, примечания, размеры как они нарисованы.
3. Реакция на события модели в реальном времени (пересчёт правил при регенерации).
4. Своя лента в интерфейсе Creo (у нас своя витрина — но не внутри Creo).

## 6. Вывод для решения «внедрять или нет»
Внедрять **схемы** (правила, проверки, язык типов отверстий, список опций) — выгодно:
это бесплатно, в тексте, без лицензий. Внедрять **сами плагины** — невыгодно: они дают то,
что агент принципиально не делает (геометрия, графика), и ломают то, что агент делает хорошо
(стабильность, самодостаточность, прозрачность).
**Формула дома на будущее:** правила и проверки — **снаружи** (класс Р), исполнение —
**живой Creo** только там, где без него никак, через CREOSON/JLINK с согласованием.
