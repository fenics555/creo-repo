# 02. КАРТА ПЛАГИНОВ (что делает каждый)

_03.10.2026, Cline. Назначение — из Changelog архива; версии — из `INVENTORY.md` (73 папки)._

## SMARTHolechart — таблицы отверстий `.hol`
**Для дома — самый близкий модуль.** Управляет hole chart: разбор отверстий в модели,
заполнение/обновление колонок, выгрузка. Ключевые опции из Changelog:
- `SHC_LOG_TIME` — время в `holechart.log` (19.3.0.0); placeholder `SURFACEID` (19.3.0.0);
- правило валидации при обновлении: число колонок совпадает + заголовки те же [RM-23710];
- `PARAMETER_MUST_EXIST` — требовать существования параметра;
- `MARK_COS` — метка системы координат (имя CSYS, иначе `HOLECHART_x`);
- лимит строки опции 255 символов (было 32) [RM-9937];
- пережил баги: «только неизвестные отверстия» → падение; MARK_COS=YES → падение Creo 6.0;
  UDF внутри merge-фичи игнорировался [RM-20581].
Максимум: **19.4.1.0 для Creo 13.4**. Дом — CREO13 13.4.1.0 → **версия есть**.

## SMARTMBDTools — правила, цвета, параметры, PDF
Самый «инструментальный» модуль: набор правил (color rules), конфигурации/контексты,
Parameter Manager, аннотации по правилам, экспорт в PDF с выбором объектов, `ModelFromTemplate`,
SA-MetaData. Для дома важны строки:
- **переименование элементов модели (features)** [RM-24179] — аналог нашего rename;
- **проверка и обновление relations** [RM-14929] — аналог нашей конституции relations;
- allowed-value list в определении параметра [RM-24111] — аналог `make_lst`;
- баг: «Apply by rules» ронял Creo из-за неконсистентного состояния объекта [RM-22415];
- баг: удаление несуществующего материала → исключение [RM-23628].
Максимум: **13.0.5.0 для Creo 13.4**.

## SMARTOptics — оптика в Creo
Трассировка лучей по поверхностям, проверка принадлежности точки пересечения поверхности,
базы оптических материалов **SCHOTT, HOYA, OHARA**, проект в XML (с запросом подтверждения
перезаписи), прогресс-диалог, категории лучей (`diffused` → `split`).
Для дома не по профилю, но ценно как образец «плагин с физикой и внешней БД».
Максимум: **13.0.0.0 для Creo 13.4**. ⚠️ 13.0.0.0 **меняет имена кнопок**
(`ok_pb` → `ok_pushbutton`, `cancel_pb` → `cancel_pushbutton`) — **mapkey могут сломаться**.

## SmartElectrode — электроды пресс-форм
Классификация accessory-параметров на компонент, ссылочные детали, материалы, PDMLink,
`my_drawing_format.cfg` для обработки чертежа, accessory-модели в workspace.
Профиль ДОМА (пресс-формы) — прямо в точку, но максимум **18.4.2.0 для Creo 12.4**
(под 13.4 нет). Под CREO13 — риск несовместимости.

## SmartXhatch — штриховка чертежей
Pattern hatching, distribute hatching, правила с NOT/AND/OR, кодировка файлов UTF-8,
«не использовать правило fill, если это невозможно», баги с PAT-штриховкой и Windchill
([RM-21740] — не checked out solid; [RM-22053] — значения паттерна).
Максимум: **16.0.1.0 для 12.4**.

## SmartUpdate — пакетное обновление параметров/свойств
Batch-диалог (переработан в 10.3.0.0), обновление параметров по конфигурациям, семейные
таблицы, relations и properties при обновлении, «текущие единицы модели» в набор параметров,
поиск по содержимому в диалоге конфигураций, фильтр списка параметров по имени/расширению.
Максимум: **11.1.0.0 для 11.0** — под CREO13 не поставляется.

## SmartAnnotate — стандартные примечания/надписи
std-annotation, stack notes, notification center, GD&T-боксы в примечаниях, переводы
(`Translate` в Parameter Manager), **SQL-интерфейс для stack notes**, экспорт/импорт настроек
через XML, каталог последних надписей в appdata, опция открытия help в браузере Creo или CHM.
Для дома — **в тему `SKILL_drawings_eskd`**. Максимум: **11.0.2.2 для 11.0**.

## Smart3DExport — экспорт 3D/PDF
Лицензия Advanced (`_ADV_FL`). Максимум: **11.0.0.0 для 11.0**.

## SmartAssembly — сборки
Один пакет на диапазон `for Creo 4.0-12.4` (ISO 210 МБ) + AdminGuide/UserGuide CHM.
**Единственный модуль с нормальной документацией в архиве.**

## SmartDesignServer — сервер конфигураций
Один пакет на `4.0-12.4` (ISO).

## SmartPDX — прогрессивные штампы
Один пакет на `4.0-12.4` (ISO 286 МБ), тип лицензии `PROGRESSIVE_DIES_STD_LL`.

## SmartMenu — своя лента
Свой ribbon вместо/поверх стандартного; максимум **17.0.0.0 для 12.4**.
Для дома ценно как способ добавить свои команды в интерфейс, не правя стандартные mapkey.

## SmartColor — цветовая кодировка
Лицензия **DEMO** (`SMARTCOLOR_DEMO`) — то есть бесплатный демо-режим; максимум **11.0.2.1**.
Цвета поверхностей, quilts, колор-легенды; в MBDTools есть «Apply by rules» и ObjectEditDialog
для цвета.
