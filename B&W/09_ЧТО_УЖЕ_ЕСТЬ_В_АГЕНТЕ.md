## Агент = 47 блоков, 162 инструмента
Новый блок = новый файл `*_tools.py` (автоподключение). Инструменты делятся на **читающие**
и **пишущие с пометкой [СОГЛАСОВАНИЕ]** — согласие человека обязательно.

## Что уже есть (сгруппировано по делу)
### Creo живое (33 инструмента — самый крупный блок)
- `creo_ops_tools` (16): старт/стоп/килл, открыть, сохранить, регенерация, параметры,
  relations, единицы, mapkey, выгрузка из памяти, PDF, бэкап модели, сборка (assemble),
  чистка версий.
- `creo_tools` (17): статус, сессия, активная модель, рабочая папка, список файлов, поиск,
  параметры, relations, масса/объём, BOM, ошибки открытия, аудит папки, трейл.
- `creo_pdf_tools`, `creo_export_tools`: экспорт PDF/step/iges/neutral.

### PLM и изделия (реестр дома)
- `plm_tools` (7): наполнить реестр, карточка, состав, «куда входит», жизненный цикл,
  **извещение об изменении по ГОСТ 2.503**, аудит реестра.
- `spec_tools` + программа `excel`: ГОСТ-спецификация XLSX (сборка/чтение) — с картинками.

### Документы и контроль качества
- `pdf_tools` (4): страницы, свежесть PDF, миниатюра-картинка, перепечать.
- `vision_audit`: **сверка PDF-экспорта с чек-листом ГОСТ** + пакетный аудит устаревших PDF.
  (Это аналог того, что делает SmartMBDTools со своим чек-листом, но у нас — через зрение.)

### Знания, модели, память
- `knowledge_tools` (4): поиск по базе знаний, карта скиллов, чтение файла, сохранение скилла.
- `learn_tools` (2): **обучение на эталонной модели** (параметры + правила), показ правил.
- `memory_tools` (6), `similar_tools`: поиск похожих моделей по эмбеддингам.
- `study_tools` (6): изучение — конспекты, заметки, неудачи, прогресс, заготовки скиллов.

### Надёжность и диагностика
- `trail_tools` (4): разбор трейлов, диагностика, **накопленные болезни трейлов со счётчиками**,
  **прогноз деградации модели**.
- `diagnostic_tools` (7): полная самодиагностика, быстрый тест, обучение, семантика, веб-стек,
  автопрогон всех инструментов, полный тест CREOSON.

### Дом: файлы, базы, роли, флот
- `db_tools`, `scanner_tools`, `index_*`: индекс моделей, база знаний, связи, состояние.
- `purge_tools`, `backup_tools` (бэкапы/восстановление/уборка), `users_tools`, `role_tools`
  (запрет инструментов по роли), `git_tools`/`fleet_tools` (флот машин), `settings_tools`.
- `sync_tools` (5), `nightly_tools` (ночной прогон), `usage_tools` («где используется»).

### Витрина и программы
- `prog_tools` (5): список программ, запуск движка в фоне, состояние, базы, журнал работ.

## Вывод (честный)
Агент — это **система чтения, анализа, учёта и безопасности**: индексы, ПЛМ, аудиты,
прогнозы, знания, роли, журналы, окна.
B&W — это **глубина внутри CAD**: штриховка, примечания, правила, отверстия, MBD.
**Это не конкуренты, а два слоя.** Слабое место агента — ровно тот слой, где работают плагины:
геометрия и графика чертежа.
