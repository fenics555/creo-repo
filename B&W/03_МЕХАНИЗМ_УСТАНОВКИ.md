## Шаг 1. Лицензионный сервер (один на все 15 модулей)
```
1. Скопировать папку "BUW_Flex_Server_11.19.8_x64" из архива BUW_Flex_Server_11.19.8_x64.7z
   на компьютер с КАК МОЖНО БОЛЕЕ КОРОТКИМ путём.
2. Запустить ОТ АДМИНИСТРАТОРА (правая кнопка) BUW_Flex_Server_11.19.8_x64\server_install.bat
   и дождаться, пока установится и запустится служба "BUW License Server".
```
Дословно из `readme_SSQ.txt` (корневой). Требование «короткий путь» — типичное требование
FlexNet/служб Windows с пробелами в пути.

## Шаг 2. Установка модуля
```
2. Установить <ПРОДУКТ> <версия> for Creo Parametric <версия Creo>.
   НЕ настраивать лицензию в конце установки!
```

## Шаг 3. Файл лицензии
```
3. Скопировать файл "license.ini" в папку <папка установки ПРОДУКТА>\bin
```
`license.ini` берётся из `_SolidSQUAD_\` рядом с инсталлятором:
```
LICENSE_FILE 6501@localhost
LICENSETYPE SMARTXHATCH_STD_LL     (у каждого продукта свой тип)
```
Факт из архива: **все 66 `license.ini` идентичны по первой строке** (`6501@localhost`).

## Шаг 4. Регистрация в Creo — `protk.dat`
```
4. Чтобы добавить <ПРОДУКТ> в Creo Parametric:
   - если файла "protk.dat" НЕТ в <папка установки Creo>\Common Files\text —
     скопировать туда <папка установки ПРОДУКТА>\bin\protk.dat;
   - если файл УЖЕ ЕСТЬ — открыть оба в текстовом редакторе и ДОПИСАТЬ
     содержимое protk.dat продукта в конец существующего файла.
```

### Почему это важно для дома
Дом подключает VERICUT **тем же самым способом**. Боевой `Z:\PTC\CREO-START\START-STD\config.pro`:
```
protkdat D:\CGTech\VERICUT 9.0.1\windows64\proev\Creo60\protk.dat
!protkdat C:\Program Files\KeyShot7\Plugins\Creo 3.0 64bit\protk.dat
```
(вторая строка — закомментирована `!`). Сам `protk.dat` VERICUT:
```
name cgtproev
startup dll
exec_file D:\CGTech\VERICUT 9.0.1\windows64\proev\Creo60\cgtproev.dll
text_dir D:\CGTech\VERICUT 9.0.1\windows64\proev\Creo60\text
revision Wildfire
end
```
То есть формат файла известен дому фактически; B&W-овский `protk.dat` ждёт того же формата
(это гипотеза — сам файл не виден, он внутри инсталлятора).

## Риски (перечислить перед установкой)
1. **Запись в боевой `config.pro`** и в `Common Files\text` установки Creo — правило дома №1
   требует бэкапа в `БЕКАП\` и записи в `БЕКАП\ЖУРНАЛ.md`.
2. **Новая служба Windows** `BUW License Server` — держит порт 6501 и стартует автоматически;
   может конфликтовать с политиками домена.
3. **Падение при старте Creo**, если `protk.dat` битый или Flex-сервер не поднят: отказ
   инициализации на каждой машине флота (`SKILL_creostart_fleet`) — это 5+ машин.
4. **Карта ключей**: SMARTOptics 13.0.0.0 прямо предупреждает о смене имён кнопок — у нас
   есть свои mapkey-скрипты (Давыдовка, `creo_ops`).
5. **Совместимость**: 12 из 15 модулей не имеют сборки под 13.4.
6. Юридический аспект: архив помечен SolidSQUAD — установка в рабочую среду дома = решение
   хозяина, не программиста.
