# agents/ — внешние ИИ-агенты (скиллы из открытых проектов)

Здесь лежат **внешние** скиллы-агенты (не дома). Происхождение внешнее, `priority: normal`,
подгружаются по надобности. **До первой живой пробы — это внешний источник, а не закон дома.**

| Папка / файл | Агент | Зачем |
|---|---|---|
| `rag-architect/` | RAG-архитектор | проектирование и оценка RAG-конвейеров: чанкинг, эмбеддинги, векторные БД, precision@k / recall@k / NDCG |
| `skill-security-auditor/` | Аудитор безопасности скиллов | сканирование скиллов на инъекции и опасный код ПЕРЕД установкой; вердикт PASS / WARN / FAIL |
| `zero-hallucination-coder/` | Кодер без галлюцинаций | дисциплина Discuss → Map → Decompose → Execute → Verify; запрет выдуманных API и заглушек |
| `SKILL_authoring_standard.md` | Стандарт авторства скиллов | «ДНК» любого скилла дома — шаблон и правила оформления |

Каждая папка самодостаточна: `SKILL_*.md` (тело), `references/` (материалы), `scripts/` или `*.py` (инструменты).

⚠️ Файлы — из внешних источников (переведены на русский по возможности). Внутренний дом
(Creo, правила, крахи) — в корне репо (`SKILL_*.md`, `MANIFEST.md`) и в папках `Creo/`, `crash/`, `CORE/`, `AUDIT/`.
