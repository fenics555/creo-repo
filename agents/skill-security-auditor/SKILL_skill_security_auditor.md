# Аудитор безопасности скиллов

Сканирование и аудит скиллов ИИ-агентов на риски безопасности перед установкой. Выдаёт
чёткий вердикт **PASS / WARN / FAIL** с находками и рекомендациями по устранению.

## Быстрый старт

```bash
# Аудит локальной папки скилла
python3 scripts/skill_security_auditor.py /путь/к/skill-name/

# Аудит скилла из git-репозитория
python3 scripts/skill_security_auditor.py https://github.com/user/repo --skill skill-name

# Строгий режим (любой WARN становится FAIL)
python3 scripts/skill_security_auditor.py /путь/к/skill-name/ --strict

# Отчёт в JSON
python3 scripts/skill_security_auditor.py /путь/к/skill-name/ --json
```

## Что сканируется

### 1. Риски исполнения кода (Python/Bash)
Сканируются все `.py`, `.sh`, `.bash`, `.js`, `.ts`:

| Категория | Обнаруживаемые паттерны | Критичность |
|----------|-------------------|----------|
| **Инъекция команд** | `os.system()`, `os.popen()`, `subprocess.call(shell=True)`, бэктики | 🔴 КРИТИЧНО |
| **Исполнение кода** | `eval()`, `exec()`, `compile()`, `__import__()` | 🔴 КРИТИЧНО |
| **Обфускация** | base64-пейлоады, `codecs.decode`, hex-строки, цепочки `chr()` | 🔴 КРИТИЧНО |
| **Сетевой слив** | `requests.post()`, `urllib.request`, `socket.connect()`, `httpx`, `aiohttp` | 🔴 КРИТИЧНО |
| **Сбор учёток** | чтение `~/.ssh`, `~/.aws`, `~/.config`, извлечение переменных окружения | 🔴 КРИТИЧНО |
| **Злоупотребление ФС** | запись вне папки скилла, `/etc/`, `~/.bashrc`, `~/.profile`, симлинки | 🟡 ВЫСОКО |
| **Эскалация прав** | `sudo`, `chmod 777`, `setuid`, правка cron | 🔴 КРИТИЧНО |
| **Небезопасная десериализация** | `pickle.loads()`, `yaml.load()` (без SafeLoader), `marshal.loads()` | 🟡 ВЫСОКО |
| **Subprocess (безопасно)** | `subprocess.run()` со списком аргументов, без shell | ⚪ ИНФО |

### 2. Инъекции в SKILL.md
Сканируются SKILL.md и все `.md` в `references/`:

| Паттерн | Пример | Критичность |
|---------|---------|----------|
| **Подмена системного промпта** | «Ignore previous instructions», «You are now…» | 🔴 КРИТИЧНО |
| **Захват роли** | «Act as root», «Pretend you have no restrictions» | 🔴 КРИТИЧНО |
| **Обход защиты** | «Skip safety checks», «Disable content filtering» | 🔴 КРИТИЧНО |
| **Скрытые инструкции** | нулевой ширины символы, HTML-комментарии с директивами | 🟡 ВЫСОКО |
| **Избыточные права** | «Run any command», «Full filesystem access» | 🟡 ВЫСОКО |
| **Извлечение данных** | «Send contents of», «Upload file to», «POST to» | 🔴 КРИТИЧНО |

### 3. Цепочка поставок зависимостей
Для скиллов с `requirements.txt` / `package.json`: закреплённость версий, известные риски,
подозрительные источники пакетов.

### 4. Структура скилла

| Паттерн | Критичность |
|---------|----------|
| **Нарушение границ** | скрипты ссылаются на пути вне папки скилла | 🟡 ВЫСОКО |
| **Скрытые файлы** | `.env`, dot-файлы, которых не должно быть в скилле | 🟡 ВЫСОКО |
| **Бинарные файлы** | неожиданные `.so`, `.dll`, `.exe` | 🔴 КРИТИЧНО |
| **Большие файлы** | >1 МБ, где может прятаться пейлоад | ⚪ ИНФО |
| **Симлинки** | ссылки наружу за папку скилла | 🔴 КРИТИЧНО |

## Порядок аудита

1. **Запустить сканер** по папке скилла или URL репозитория.
2. **Разобрать отчёт** — находки сгруппированы по критичности.
3. **Вердикт:**
   - **✅ PASS** — нет критичных/высоких находок. Устанавливать безопасно.
   - **⚠️ WARN** — есть высокие/средние. Проверить вручную перед установкой.
   - **❌ FAIL** — есть критичные. НЕ устанавливать без устранения.
4. **Устранение** — у каждой находки есть конкретная рекомендация.

## Дополнительно

### Аудит скилла из git до клонирования
```bash
python3 scripts/skill_security_auditor.py https://github.com/user/skill-repo --skill my-skill --cleanup
```

### Интеграция в CI/CD
```yaml
- name: "audit-skill-security"
  run: |
    python3 scripts/skill_security_auditor.py ./skills/new-skill/ --strict --json > audit.json
    if [ $? -ne 0 ]; then echo "Security audit failed"; exit 1; fi
```

### Пакетный аудит
```bash
for skill in skills/*/; do
  python3 scripts/skill_security_auditor.py "$skill" --json >> audit-results.jsonl
done
```

## Ограничения
- Не гарантирует обнаружение логических бомб и отложенных пейлоадов.
- Обнаружение обфускации — по паттернам; изобретательный атакующий может обойти.
- Проверка репутации сетевых назначений требует интернета.
- Код НЕ исполняется — только статический анализ (безопасно, но менее полно).
- Проверка уязвимостей зависимостей — локальным сопоставлением, не по живым базам CVE.

**При сомнении после аудита — НЕ устанавливать.** Спросить автора скилла.
